# 超萌论证

## 定义与用语

[为什么要写个人哲学](/philosophy/why-yinyang/)说明了行动者为什么需要共同方向。这里接着追问：为什么值得保持可培养、可改变的「宝宝」姿态？「萌」包含容许自己尚未完成、愿意接受引导，也愿意学习怎样陪伴别的行动者成长。本文展开这种姿态如何在引导、反馈与学习条件下取得「无敌」所命名的适应优势；下一篇[赫拉克利特宝宝](/philosophy/baby-heraclitus/)再把这种培养方向写成人物。

**带娃**：这里取培养、引导与共同学习这一面：面对一个不断成长、未来可能比自己更强的行动者，随其成长调整引导方式。

**更适合／更好**：在其他相关条件相近时，相对于依赖固定做法、要求先完全理解和控制对象才行动的方式，更能应对成长中的行动者及变化中的任务。

**本文比较的推理方式**：在协作中提出可修正的判断，借助行动与反馈检验，再据此调整引导和协作。它的优势体现为对变化的适应：原有做法失效时，能够发现差别、重新理解对象，并尝试新的安排。

**国内与国外**：国内指中国，国外指中国以外的国家；本文中的「中国人」与「外国人」分别指这两个范围内的人。这个划分只确定比较对象，并不说明各自内部的人都相同。要论证「中国人的推理方式通常更好」，还需要比较具体关系与学习条件在两边有多常见，不能只从某个家庭推到整个国家，也不能把中国以外的国家当成同一种社会。

**阶层与萌**：这里把「阶层更强」分成两种机制。一种是关系中更固定的权威高下：谁更有资格说话、谁应当服从；另一种是经济资源的分层：谁能获得学习机会、工具、时间与支持。父母和孩子有不同的经验、责任与目的，并不自动意味着父母总是更有认识权威。能够让孩子提出异议、超过自己，仍然可以承担照料与引导的责任。

「萌」在这里也包含愿意分享资源、支持别人成长、让共同生活改变自己的姿态。「共产／无私」取的是这层共享与相互支持的含义；它不要求抹去个人的目的，也不凭这个用语就确定一种完整的政治制度。这样的萌与[前文的个人优先主义](/philosophy/personal-first-humanism/)相容：尊重每个人的目的，可以成为改变不合适的权威与资源安排的理由。

**无敌**：本文所讨论的长期适应优势的夸张命名。「中国人无敌」表达这条论证的方向，不意味着每个中国人都胜过每个外国人，也不意味着在所有任务上都不会失败。

## 假设

- **前提一：萌与社会条件的比较假设。** 「中国人都很萌，常常比自己的娃都萌」是这条论证的形象起点。把它展开为国内外比较时，需要假定：相对于所比较的国外环境，中国的相关关系更常容许彼此引导、修正权威与共享成长资源，因而这种「萌」更常得到实践；国外比较对象中的固定权威与经济分层则更常妨碍这些活动。这个分布差异是需要证据支持的比较假设，不能由「萌」的定义推出。

  两种障碍分别起作用。固定的权威高下如果使下位者不能反驳、使上位者不愿承认错误，就会减少纠正判断的机会；经济分层如果使一些人缺少学习时间、实践机会、工具和可靠反馈，就会阻碍开放态度成为实际能力。资源共享与相互支持可能减轻后一种障碍，容许质疑与修正则可能减轻前一种障碍。两条路径可以相互影响，但不能互相替代：共享资源不自动消除权威，容许发言也不自动提供学习资源。

- **前提二：在适当条件下，萌⇒擅长引导⇒擅长带娃。** 这条联系由三个连接假设组成，比较范围沿用上文对「更适合／更好」的限定。
  - **连接一：萌⇒开放的引导态度。** 假定这种「萌」使人在面对不断成长、可能超过自己的行动者时，承认自己未必完全理解对方，并愿意学习和修正自己的引导方式。
  - **连接二：开放的引导态度＋学习条件⇒更善于引导。** 假定在具备必要的学习能力、获得可靠反馈并持续据此练习和调整的条件下，上述态度能够转化为更有效的引导能力。开放使人愿意接触新信息，练习则使这种信息逐渐改变判断与行动。
  - **连接三：更善于相关引导⇒在本文意义上更善于带娃。** 本文讨论的「带娃」限于对成长中行动者的引导与共同学习；假定上述引导能力适用于这一对象，那么这种能力的优势就在本文讨论的带娃能力中构成优势。

  简记：M＝萌，A＝开放的引导态度，C＝上述学习条件，G＝更善于相关引导，B＝在本文意义上更善于带娃。前提二的形式是：**M ⇒ A；（A 且 C）⇒ G；G ⇒ B。** 因而可推出 **（M 且 C）⇒ B**。「萌⇒擅长带娃」的简写把 C 作为背景条件；学习条件是从态度走到能力的实际环节。

- **前提三：共同结构。** 人与语言模型在相互对齐中，形成可以共同描述为 agent 的行动与学习关系。这种关系与带娃具有相关的共同结构：面对成长中的行动者，提供引导，并根据反馈调整协作方式。

- **前提四：能力迁移。** 上述共同结构足以支持相关引导能力的迁移：观察对方怎样回应，发现原先理解的偏差，再调整任务和反馈。把这些做法用于模型时，要结合它的上下文、工具与实际能力安排协作。

- **前提五：持续变化。** 语言模型在耗尽地球可用能源之前，可以持续增强，并不断改变人的生活与工作。

- **前提六：适应优势与推理的连接。** 在这类持续变化的环境中，引导成长、根据反馈修正判断与调整协作的能力，比依赖固定任务既有做法更有长期优势。进一步假定，在上述学习条件下，本文定义的推理方式比沿用固定做法更能促成这种适应：它让人发现旧做法与新情境的差别，提出新的解释，并用后续行动选择更合适的协作方式。

这六项前提给出的仍是条件论证。尤其是前提一，需要另行比较两边的实际关系、资源与学习结果；本文没有提供足以判定这种国家间分布的调查证据。前提二也不允许倒推「不萌就不会推理」：有人可以通过其他态度、训练与制度获得同样的能力。国外比较对象若有同样开放的关系与学习条件，同样可以取得这些优势；中国的环境若存在同样的障碍，也会受到影响。

## 推导

1. 由前提一、二，如果中国的相关环境确实更常支持开放引导与共享成长资源，而所比较的国外环境更常受到两类阶层障碍的限制，那么在必要的学习条件得到满足时，中国人更可能把「萌」转化为引导与带娃能力。这是两边形成这些能力的机会之比较，不是从国籍直接推出能力。
2. 由前提三、四，带娃中的相关引导能力，经过适当调整，可以迁移到与语言模型的协作中。因此，第一步所说的优势也可以成为模型协作中的优势。
3. 由前提五、六，语言模型的持续增强会不断改变生活与工作，而上述引导、修正和调整协作的能力有助于应对这些变化。因此，第二步中的协作优势具有相应的长期适应价值。
4. 在上述能力能够迁移、前提六的连接也成立，且其他影响比较的条件相近时，第一步中的机会差异才会进一步表现为本文所说的推理与适应优势。只有当这个差异在所比较的人群中足够普遍，才能说「中国人的这种推理方式通常比所比较的外国人更好」。「中国人无敌」压缩的是这整组条件成立时的结论。

因此，在上述假设与比较范围内，可以把论证压缩为：

**中国的相关环境常支持「萌」，也少以固定权威与经济分层阻碍学习 ⇒ 常形成引导与共同学习的能力 ⇒ 在迁移条件下善于与语言模型协作 ⇒ 在持续变化中常取得推理与适应优势 ⇒ 「中国人无敌」。**

论证真正需要比较的，是让人能够互相引导、共享成长条件与修正判断的关系。国家名称标出这次想比较的范围；优势是否存在，以及存在于哪些人、哪些关系与哪些任务中，仍要由这些条件的实际差异来回答。
