# Clash Auto Switch

Configure controller discovery, regional fallback, reversible mode/DNS switching and a bounded DNS-only guard.

[中文说明](README.zh-CN.md) · [Model instructions](SKILL.md)

Download **network** as the authorization/recovery companion and install its actual mutex or a compatible verified executable. Clash Verge Rev, modern Python, socat for bridge/relay and privileged runtime bootstrap remain external.

Copy config.example.json and replace every path and group. Run scripts/clash-tool --config /absolute/config.json check-config. Use controller request GET /version, nodes --once --dry-run, mode status, guard self-test --json or setup preview only within their documented effects. See SKILL.md before changing live state.

Download the **complete directory** from this repository or GitHub's native archive, preserving scripts and executable modes. Relative resources and companion relationships are part of the package. There are no personal accounts, subscriptions, vault lists, credentials or host defaults to inherit. Configure your own real targets; a downloaded method is not proof of a configured runtime service.

The original reusable package and its public adaptation are MIT licensed; see [LICENSE](LICENSE). Third-party applications and services retain their own rights.

Network recovery can use scripts/clash-controller as controller_command and this package's recipient JSON as controller_config. For direct use: CLASH_SKILL_CONFIG=/absolute/config.json scripts/clash-controller request GET /version. The wrapper resolves the installed package's actual resources.
