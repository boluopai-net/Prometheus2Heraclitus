# 工作模型的形成与修订

<a id="形成自己的哲学与个人模型"></a>

本参考说明怎样形成或修订对实际的人、模型伙伴及双方关系的理解。
六份写作指南提供相应的实际指导，包括环境实现，以及怎样写出自己的实际修订方法；
[包结构说明](package.zh-CN.md)维护路径、公共内容投影及完整包与个人包的约定；
[主入口](../SKILL.zh-CN.md)维护日常阅读要求。这里处理理解与写作的对象、根据，
以及相连描述怎样变化。人和模型都能阅读、使用这套方法；其中的实践指引展开怎样创作和
修订文章所介绍的理解。

阴阳以反向对齐为目的：人在与生成智能的相遇中发展理解、生成与行动。伙伴的适配与
独立贡献支持这一目的。元 Harness 关乎双方：模型的 Harness 与人的环境相互耦合，共同塑造
双方能够接续和开展什么。工作描述把对这种关系的理解，接到实际指令与环境安排的形成和修订上。
这份 Yinyang 以交叉参与组织协作：人可以进入语言模型式的开放生成，实际模型则进入人的
逻辑学家角色，展开含义、检查根据。关键细节能够使侧重再次倒转；双方经由对方的贡献返回，
保留两种参与的可能。这条关系使反向对齐在这里取得具体形式，也把六份工作描述连接起来。

[关系写作指引](formation/relationship.zh-CN.md#在有关之处说明交换与返回)完整展开这项运动及其
辩证含义。其余五份指引分别说明方向、实际双方、工作条件，以及怎样修订。让这条关系组织
相连的描述，各份文件展开自己的对象。采用这份 Yinyang 与借用某项方法仍是不同选择；
另一个作者可以组织不同的关系。

给人阅读的哲学与文学展开这种安排的意义，给模型使用的描述则明确表达相关理解与要求。
两种表达都可以在完整自我认识之前参与形成和修订可用关系；
[从个人模型到圣状](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/writing-a-sinthome.zh-CN.html)展开这项哲学提案。

这些方法维护一项已经展开的范例。请求也可能需要另一种哲学或文学形式；即使其意象与
组织已不像阴阳，也应在自己的源位置支持它。
[从采用、组合到自己的创作](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/example-and-commons.zh-CN.html)说明这种区别。

读者可以研究这个范例，借用一项具体方法，也可以维护一套情境化阴阳。这些用途不同，
不是依次递进的承诺层级。借用观察与解释的区分时，从实际问题进入下面有关推理即可，
无需先开展自己的哲学项目或建立六份情境化文件。完整维护这套 Skill，需要六份有根据的
实际文件，包括实际采纳的立场与目的，可以选择性借用既有观点。是否另写原创哲学或文章，
由兴趣决定，不是维护个人材料和环境的前提。六份公开指南分别说明怎样写，
六份私人文件提供实际内容，其中也包括自己的修订方法。主入口要求的
初次阅读使这些相连理解可用于日常工作。本参考提供共同的
理解与凝练方法。`references/formation/` 中永久保留的公开指引展开不同写作对象，实际私人描述
位于 `references/situated/`。人、伙伴与关系仍是三个理解对象；取向阐明所采纳的哲学、
价值与方向，环境说明实现。实际修订文件说明本人怎样修订理解与环境，公开修订指南则说明怎样写出这套方法。写作指引不能替代
有根据的内容。

创建或修改一份描述前，完整读取下表中对应的公开写作指导，同时阅读当前的情境化描述
（如果已经形成）及相关证据。上下文中已有完整、当前的阅读可以复用。指引在分发包与
情境化包中都保留为公共文件。结合当前目的与证据运用指导，保留描述中有根据的
实质。这项写作时的阅读只涉及受影响的描述；日常协作仍按主入口的原有约定读取实际描述。

## 按实际用途写作

区分三个相连的用途：**Philosophy** 展开采用的概念、价值与方向；私人
`references/personal/` 中的**个人参考材料**区分偏好与选择、心理经验与测评、个人条件、
身份表达与作品。[组织个人材料](personal-material.zh-CN.md)说明怎样分类其贡献、保留根据并补齐重要缺口；`references/situated/` 下的**六份工作文件**
凝练人与模型协作所需的内容，使个人环境能够符合实际的这个人。六份文件不是六种心理模型，
其中的个人文件也只选取对协作有影响的理解，不能替代较丰富的个人参考材料。

每次修订工作文件，按修订指南的[材料刷新顺序](formation/revision.zh-CN.md#确立当前可用的材料)
进行：阅读采用的哲学，检索有关的新历史，刷新并纠正个人参考材料，再用哲学与这些材料
凝练工作模型。按问题确定读取和修改范围，检查相连的六份文件；保存下来的解释仍可能出错，
安排可用也不确立心理解释为真。

哲学与文学可以展开理解，工作描述则使选定含义能够用于模型的判断与行动，其阅读和维护由模型承担。
理解个人心理时，本人可以看 `personal`，也可以请语言模型帮忙阅读和理解；不建议通过阅读
六份工作描述开展心理自我分析。六份文件及其私人支持材料怎样明确表达对象、关系、根据和后果，
由修订指南的[写作指导](formation/revision.zh-CN.md#按实际用途写作)说明；各对象的具体指导
保留在下面对应的写作文件中。

## 基于实际材料形成情境化版本

共同哲学阐明较广的对象、关系、价值与认识方式；取向说明为协作实际采纳什么，人、伙伴与
关系展开参与者和共同活动，环境说明实现。私人来源为这些描述中的情境化主张提供根据。融贯哲学可以提出
个人解释，但仍需有具体来源的经验与当前互动支持。实际工作可以同时纠正解释与哲学。

从目的与已有基础最能切入之处开始：哲学、个人表达、选定记录、对话、偏好、工作，
或待改变的环境。材料可用本身不是收集理由。取用相关且获授权的来源，保留身份、
时间范围与重要不确定性；原件可以留在既有私人维护位置。

## 从已有材料与实践起步

个人作品是一个直接入口：文章、故事、音乐、设计或程序，都可能表达一个人怎样理解世界、
选择什么，以及怎样与他人共同生活和创造。创作把这些关系带进可阅读、讨论和修改的形式；
双方从作品、创作过程及其实际后果中解释有关含义，再把有根据的部分用于协作与环境。
作品也能反过来改变原有理解。

这里的「哲学」取广义：对这些理解、价值与做法的反思贯穿个人创作。
一件作品可以承载这种反思，并以自己的体裁成立；形成工作模型所用的哲学贡献，
是把当前有关的含义和理由展开。因此，下面的「已有哲学」也包括作品中尚待阐明的理解，
「发展哲学」可以是在创作与使用中把它说清楚。

实践中相连的是**人的创作、模型作为写作与创作伙伴、双方活动的环境**。
哲学、心理与工程说明理解和改进这项实践时的三种贡献；它们贯穿上述三者。
「哲学—心理—工程」是有用的观察角度，「作品—伙伴—环境」则让人找到实际可以着手的地方。

哲学、对自己与他人心理的理解，以及工程，共同参与个人描述与可用环境的形成。
[哲学、心理与工程的三位一体](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/local-source-and-website.zh-CN.html#哲学心理与工程从已有能力补齐关系)展开其联系。
以下组合说明这项实践中已有的材料与尚缺的联系：

| 已有材料或实践 | 仍需补足的联系与下一项贡献 |
| --- | --- |
| 已有成文哲学或采纳的方向，尚无可用模型环境与已展开的个人描述 | 把哲学与事件历史、日常生活相连，同时准备发展和使用这份描述所需的模型环境。 |
| 已有相关心理理解、对话历史或生活材料，尚无可用模型环境与成文哲学 | 发展有根据的描述及其哲学意义，同时使所需的模型协助可用。 |
| 已有可用模型环境与使用经验，个人理解和哲学仍未说清 | 共同解释经验、偏好与概念，阐明其哲学意义，并在使用中修订安排。 |
| 已有成文哲学与有根据的心理理解，尚无可用实现 | 通过实际工程环境实现两者所选定的关系。 |
| 已有成文哲学与可用环境，尚缺具体个人根据 | 结合哲学理解对话历史与日常生活材料，凝练有根据的个人描述，并在当前使用中修订。 |
| 已有有根据的心理理解与可用环境，尚无成文哲学 | 展开实践中隐含的哲学理解、价值与方向。 |

这六种组合说明起步条件，不是不同的形成路线或固定顺序。文件、检索、工具、执行或
核验的缺失阻碍所需贡献时，就准备这些条件；不要求当事人先学会实现一切。从已有内容
发展缺失的联系，让个人理解、哲学与实现能够在工作中持续形成并相互修订。

目的包含通过计算机实现的工程时，人与伙伴共同发展有关的计算表述与环境：选取的活动、
其中的状态与条件、变化中的接续，以及可观察后果。文件与工具实现和使用这个模型，
不因自身存在便提供它的含义。分工贯穿问题选取、建模、实现与反馈，不要求当事人
亲自完成上游模型之后，伙伴才能贡献。[环境写作指南](formation/environment.zh-CN.md#在情境中推导行为)
按实际用途所需的精度展开这层联系。

个人模型把偏好、心理活动、经验、概念与哲学理解带进同一份可修订的自然语言描述。
模型帮助重建有关历史、发展解释、比较可能并承担写作；人贡献目的、亲历经验、识别、
异议与判断。已知偏好可以指导安排，同时保留其解释尚未明确的部分。安排也可能来自
限制或默认值，因此，仅凭它已经存在，不能看出当事人想要什么。

这项实践中的[从材料凝练个人模型](formation/person.zh-CN.md#从事件历史哲学与个人材料凝练个人模型)，
联系长期对话、日常习惯、生活材料与哲学。分析、溯因、比较、概念澄清与后续互动使拟议
关系可以修订。偏好报告、解释性的心理假设与选定的哲学方向可以相互启发，同时支持
不同结论。个人指引展开这些根据，说明这种理解与凝练为什么不等于心理建模。

逐渐形成的个人模型也参与形成与之贴合的伙伴模型及选定关系。需要区分
希望伙伴承担的角色和优先次序，与它的实际能力和回应模式：即使内部过程仍有不可见
之处，指令、可用工具和行为仍可
检查；仅仅取得源代码也不能确立协作贴合。哲学通过表达自我理解、意义与可能关系，
主动参与这种理解与凝练；经验又能修订它的说明。

哲学写作可以偏重文学、工程哲学、西方哲学、科学哲学、逻辑学、美学，或其他相关问题。
这些偏重展开同一实践，起步材料与顺序可以不同。
技术背景不选定另一条形成描述的路线。贴合尚不明确时，探究提供假设与
判断依据，不要求在有用工作之前完成解释。借助模型，选定的生活需要与关系
取得工具、信息、指令和计算机环境的形式，介入购物、投资、聊天与学习等活动。
实际使用又返回生活：什么变得容易，出现什么代价，当事人学到什么，以及关系是否
支持其选定的发展。理解与安排共同修订。环境凝缩选定关系，不包含完整的人。

假设一个人总在同一张桌子前工作。这项观察符合多种解释：他可能偏好这个安排，
这里也可能是唯一具备所需设备的地方，或者只是一直没有作过比较。仅凭这一点推荐
永久固定的工作位置，就会把当前安排转成个人理想。有关证据可能是过去自由选择的
安排、另一选择真正可用时当事人的体验，或在有用且获授权时进行的一次普通可逆尝试。
如果移动使一项珍视的资源变得不可用，不喜欢这次尝试就不能单独确立对固定位置的偏好。
需要比较随地点一起变化的活动和成本。模型能够检查这些依赖并发展候选解释；无法取得的
个人体验仍由当事人贡献。证据不能区分时，让描述保持条件性。改善这个工作空间，
不必先判定一项普遍人格特质。

把日常协作所需内容凝练到六份文件中。保留影响理解或行动的差异；较长经历、
原始表达和有用的私人支撑，留在原有维护位置或 `references/personal/`。
六份文件有互补的写作职责。公开指引展开这些不同对象，情境化描述提供实际理解：

| 工作文件 | 应当说明什么 | 公开写作指导 |
| --- | --- | --- |
| `situated/orientation.md` | 采纳的哲学、价值、方向及其理由。 | [阐明取向](formation/orientation.zh-CN.md) |
| `situated/person.md` | 相关经验、偏好、能力、发展与不确定性。 | [形成有根据的个人描述](formation/person.zh-CN.md) |
| `situated/counterpart.md` | 实际模型、能力与期望贡献。 | [描述伙伴](formation/counterpart.zh-CN.md) |
| `situated/relationship.md` | 共同活动、纠正与分工。 | [阐明关系](formation/relationship.zh-CN.md) |
| `situated/environment.md` | 通过实际资源、行动与条件实现，包括当前缺口。 | [描述环境实现](formation/environment.zh-CN.md) |
| `situated/revision.md` | 本人修订哲学、证据、描述、Skills 与环境的实际方法。 | [如何修订](formation/revision.zh-CN.md) |

[修订指引的证据方法](formation/revision.zh-CN.md#来源与证据)支持六份实际文件及其持续修订。
每份公开指南说明怎样形成内容，实际理解与方法则保留在私人位置。可归属证据与较长的私人支撑
留在实际维护者处，需要时使用 `references/personal/`。按问题选读来源。Empty 提供共同指引、四个空 Personal 分区与六份标为 `status: unfilled` 的 Situated
起始文件。起始文件不是实际描述，仍需结合本人的材料形成内容。

采用这套实现时，根据有关材料形成全部六份实际文件，包括适用于本人目的和环境的修订方法。尚未明确的关系可以保持未知；
未改写的形成指引、他人画像和虚构人物都不能提供情境化实质。哲学家的思想可以支持框架，
不能替代实际用户模型。完整传记和完整的心理理解，都不是创制与实践开始的条件。

把描述放回来源及相邻主张中共同阅读。通过调查或针对体验、目的的聚焦探询补足重要缺口；
只有当事人能够提供的判断，使用适用探询方法取得。模型负责写作与整合。
在实际使用入口回读完整描述，投入获授权工作，再从结果修订。请求包含环境或网页变更时，
通过其实际维护者完成；只形成画像不能完成它们。

## 语言的作用

一段文字可以报告经验、提出解释、确立选定关系，或借意象汇集可能。其区别影响结论时，
应当识别。「那个问题之后，我失去了思路」报告一份体验；把中断归因于实现细节被转交，
提出一种解释；选择让模型承担这些工作，则给双方关系一个方向。描述应使这些联系可用，
而不把一次经历变成普遍禁令。

人和伙伴的描述共同发展。角色与分工不穷尽任一参与者，也不确立能力不足。
[言说、对立与自我形成](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/speech-opposition-and-self-formation.zh-CN.html)展开后来的表达
怎样重新解释早先的话，并重构其前提。[修订指南](formation/revision.zh-CN.md#来源与证据)
说明怎样保留这里需要的来源、竞争解释与不确定性。

## 在表达、关系与实现之间往返

`人可理解的表达 ⇄ 对活动与关系的明确理解 ⇄ 工作行为`

哲学写作可以探索超出某种工作描述的可能；描述则说明协作所需的有根据的解释、后果与
未决关系。人和模型都可以阅读这两种表达，并在它们之间往返。写作用途不同，并不按
读者身份划分阅读权限。清楚的文字可以使一种关系可用，不需要把完整的人或相遇全部
形式化。[环境写作指南](formation/environment.zh-CN.md)说明选定关系怎样进入
实际指令、工具与使用。

## 使用并继续发展已经形成的理解

<a id="在使用中维护私人材料"></a>

公共哲学保留在共同维护的位置，私人经验保留在相应的支持来源中。
[修订指南](formation/revision.zh-CN.md#用哲学刷新个人支持材料)负责这些材料、六个工作文件
与环境之间的持续整理。公共文件投影器在机械上保留私人文件，不禁止获授权的语义修订
或退役私人笔记。

<a id="根据不断变化的相遇进行修订"></a>

新提出的参与方式可以改变描述的适用情境，而不抹去原先条件。例如，亲自参与实现以学习，
可以与在产出任务中委托模型实现并存；持续出现的反例也可能动摇描述本身。
使用[修订范围与联动方法](formation/revision.zh-CN.md#确定修订范围与联动)，判断这是局部纠正
还是较广的修订，完成实际依赖，不自动改写所有内容。

<a id="在实际尺度上评估结果"></a>
