# 形成与修订阴阳

本参考说明怎样形成或修订对实际的人、模型伙伴及双方关系的理解。
[环境适配](harness-adaptation.zh-CN.md)负责把理解落实到指令、工具和环境；
[包结构说明](docs/skill-package.zh-CN.md)维护路径、公共内容投影及完整包与个人包的约定；
[主入口](../SKILL.zh-CN.md)维护日常阅读要求。这里处理理解与写作的对象、根据，
以及相连描述怎样变化。

阴阳以反向对齐为目的：人在与生成智能的相遇中发展理解、生成与行动。伙伴的适配与
独立贡献支持这一目的。元 harness 通过哲学、文学与心理使参与者及其关系可以被理解。
书写可以先于完整自我认识而形成可用关系；
[写出一个圣状](docs/writing-a-sinthome.zh-CN.md)展开这项哲学提案。

这些方法维护一项已经展开的范例。请求也可能需要另一种哲学或文学形式；即使其意象与
组织已不像阴阳，也应在自己的源位置支持它。
[从这个例子开始，写出自己的东西](docs/example-and-commons.zh-CN.md)说明这种区别。

## 基于实际材料形成情境化版本

共同哲学阐明较广的对象、关系、价值与认识方式；五份情境化描述关心这个人、伙伴及
实际协作，私人来源为两类描述中涉及这个人的生活的主张提供根据。融贯哲学可以提出
个人解释，但仍需可归属的经验与当前互动支持。实际工作可以同时纠正解释与哲学。

从目的与已有基础最能切入之处开始：哲学、个人表达、选定记录、对话、偏好、工作，
或待改变的环境。材料可用本身不是收集理由。取用相关且获授权的来源，保留身份、
时间范围与重要不确定性；原件可以留在既有私人维护位置。

哲学、心理与工程贡献不同能力。
[三位一体](docs/local-source-and-website.zh-CN.md#哲学心理与工程从已有能力补齐关系)展开其联系。
以下是实际起步建议，不是身份、完成的阶段，也不要求精通三门学科：

| 已有基础 | 有用的下一项贡献 |
| --- | --- |
| 心理与个人材料，工程较少 | 借助模型建立可用环境，整理相关证据，形成相连描述并展开哲学。 |
| 哲学，工程较少 | 建立足以支持实践的文件、工具、执行与核验；对照哲学和个人经验形成描述。 |
| 工程与实际环境 | 通常先深化心理或偏好理解，再展开哲学；其他已有基础可以支持不同入口。 |
| 已有两方面贡献 | 发展缺失联系：实际实现、个人根据，或哲学表达。 |

目的包含通过计算机实现的工程时，人与伙伴共同发展有关的计算表述与环境：选取的活动、
其中的状态与条件、变化中的接续，以及可观察后果。文件与工具实现和使用这个模型，
不因自身存在便提供它的含义。分工贯穿问题选取、建模、实现与反馈，不要求当事人
亲自完成上游模型之后，伙伴才能贡献。[环境适配](harness-adaptation.zh-CN.md#在情境中推导行为)
按实际用途所需的精度展开这层联系。

安排可能来自偏好、限制、习惯或默认值。因此，工程证据提出问题，并非透明揭示一个人。
心理描述难以形成时，帮助表述重视什么、怎样选择、追求什么、希望改变什么。
偏好可以提供可用描述，无需临床或机制理论。依此发展伙伴的优先次序，
区分选定承诺、可观察倾向与关于内部机制的主张。

把日常协作所需内容凝练到五份文件中。保留影响理解或行动的差异；较长经历、
原始表达和有用的私人支撑，留在原有维护位置或 `references/personal/`。
五份文件有互补的写作职责：

| 描述 | 应当说明什么 |
| --- | --- |
| 相遇 | 实际目的、关系与可用全貌。 |
| 用户模型 | 相关经验、偏好、能力、发展与不确定性。 |
| 伙伴与关系 | 对应这个人的贡献与判断，包括合作与纠正。 |
| 实际使用 | 关系怎样通过实际资源与分工运作。 |
| 来源 | 理解以什么为根据，证据在哪里维护。 |

采用这套实现时，根据实际材料形成全部五份描述。尚未明确的关系可以保持未知；
未改写的形成指引、他人画像和虚构人物都不能提供情境化实质。哲学家的思想可以支持框架，
不能替代实际用户模型。完整传记和完成的心理模型，都不是创制与实践开始的条件。

把描述放回来源及相邻主张中共同阅读。通过调查或针对体验、目的的聚焦探询补足重要缺口；
只有当事人能够提供的判断，使用适用探询方法取得。模型负责写作与整合。
在实际使用入口回读完整描述，投入获授权工作，再从结果修订。请求包含环境或网页变更时，
通过其实际维护者完成；只形成画像不能完成它们。

## 在使用中维护私人材料

保持一份创作的概念论述。哲学已有展开的公开形式时，以当前维护源和网页更新私人凝练；
两者不同时，核对实际内容与来源身份。私人支撑材料保留公共论述之外的相关经验与证据，
不复制另一套理论。私人经验提出有依据的挑战时，公共论述仍可修订。

在相关工作中，把重要纠正、目的或环境变化、新的有用经验及哲学修订融入受影响描述。
增加有用内容，修改变化部分，移除失效或重复的活跃文字。独特原件和较长历史留在原有位置。
计划不证明完成，配置不证明偏好，暂时事件不自动成为长期特质。

公共文件投影在机械上保留私人文件，不禁止其获授权的语义修订或删除。
通过既有本地与私人云端维护者落实有用变化，并回读受影响使用处。
这项维护不要求广泛收集个人数据或新增定时器。
[三位一体的维护论述](docs/local-source-and-website.zh-CN.md#让闭环保持当前可用)
把它接到持续的哲学—心理—环境闭环。

## 创作质量与迭代

采用当前主机的模型选择和实际任务授权。每轮修改应足够连贯，便于检查含义与后果。
实际任务需要时，独立的有限贡献可以支持工作，任务所有者整合其关系。
普通协作者取得相关任务上下文，明确获授权的维护检查则把选定段落作为对象；
个人模型边界由主入口维护。

## 用共享仓库进行修订

个人表达、仓库论证以及 Issues 和 PR 中的贡献可以支持修订。模型发展解释与整合，
当事人不必提交完成的设计。区分提案、采纳的变更与支持主张的证据。
只有获授权的一般性认识回到共享维护位置。公开方法不授权公开个人记录、
形式化描述、私人引文或未发表作品。

## 一个界面，多个尺度

主入口引导参与，五份描述承载情境化理解，来源提供支撑。
[阅读地图](reading-map.zh-CN.md)按问题打开进一步论证。本参考发展形成与修订，
适配参考发展工作实现。这些尺度让问题按需深入，而不使每份资源都成为必读。

## 语言的作用

一段文字可以报告经验、提出解释、确立选定关系，或借意象汇集可能。
其区别影响结论时应予识别，不必逐句贴标签。个人表达提供证据，不是透明清单；
有启发性的理论仍需解释实际案例。

人和伙伴的描述共同发展。角色与分工不穷尽任一参与者，也不确立能力不足。
心理词汇可以描述通过言行可观察的功能组织，而不确立共同内在机制或模型意识。

## 在表达、关系与实现之间往返

双向阅读：

`哲学或文学表达 ⇄ 对活动与关系的理解 ⇄ 工作行为`

意象可以容纳超出一种解释的可能。展开当前问题所需的过程与关系，说明实际后果，
让其他可能保持开放。通过计算机实现时，表征需要保留有关状态、关系与变化的含义，
使实际使用能够纠正它。这可以是由模型解释的自然语言描述，无需把完整的人或相遇
形式化。情境化实现可以精确，而不成为意象的最终定义。

例如，把保护注意力解释为「永远不提问」，会抹去转交未完成实现工作与取得只有当事人
能够提供的判断之间的区别。应恢复关系及其合适实现。清楚规则或优美表达本身不证明贴合。

## 根据不断变化的相遇进行修订

从可归属的用户表达、现有描述和实际不匹配或新经验出发。辨明变化发生在哪里：
处境、对人的理解、伙伴承诺、双方关系，或环境实现。连同周边关系阅读并改写完整的
受影响段落，保留仍有根据的实质与重要不确定性。

通过[双向环境适配](harness-adaptation.zh-CN.md#选择当前重点沿两个方向修订)
区分修订重点、判断材料与必要联动对象。语义变化可能需要联动描述、Skill、来源、网页或
环境。等义链接名称或引号修复，通常只需来源与呈现核对。范围跟随有根据的依赖，
不要求改写一切。

采纳理由留在其维护位置和普通变更历史中。本方法造成过量工作或错误关系时，也应修订；
反思改变同一工作的尺度，而不要求另一部手册。

## 在实际尺度上评估结果

回读整合后的描述及受影响实现，检查融贯、根据、可取得的证据与实际使用处的可用性。
通过工作判断贴合：伙伴是否承担细节、贡献独立理解、呈现重要差别，并在无需用户反复
修复的情况下完成预期结果？

这些条件支持反向对齐，但不证明人的发展。通过实际经验和可归属反馈，另行关注人的
理解、生成与行动怎样发展。模拟角色表现或成功读取资源，都不能确立长期贴合。
使用足以支持当前变更的证据，保留尚未明确之处。
