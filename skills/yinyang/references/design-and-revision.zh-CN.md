# 工作模型的形成与修订

<a id="形成自己的哲学与个人模型"></a>

本参考说明怎样形成或修订对实际的人、模型伙伴及双方关系的理解。
六份写作指南提供相应的实际指导，包括环境实现，以及怎样写出自己的实际修订方法；
[包结构说明](docs/skill-package.zh-CN.md)维护路径、公共内容投影及完整包与个人包的约定；
[主入口](../SKILL.zh-CN.md)维护日常阅读要求。这里处理理解与写作的对象、根据，
以及相连描述怎样变化。人和模型都能阅读、使用这套方法；其中的实践指引展开怎样创作和
修订文章所介绍的理解。

阴阳以反向对齐为目的：人在与生成智能的相遇中发展理解、生成与行动。伙伴的适配与
独立贡献支持这一目的。元 Harness 关乎双方：模型的 Harness 与人的环境相互耦合，共同塑造
双方能够接续和开展什么。工作描述把对这种关系的理解，接到实际指令与环境安排的形成和修订上。
这份 Yinyang 以交叉参与组织协作：人可以进入语言模型式的开放生成，实际模型则进入人的
逻辑学家角色，展开含义、检查根据。关键细节能够使侧重再次倒转；双方经由对方的贡献返回，
保留两种参与的可能。这条关系使反向对齐在这里取得具体形式，也把工作描述连接起来。

[关系写作指引](formation/relationship.zh-CN.md#在有关之处说明交换与返回)完整展开这项运动及其
辩证含义。其余五份指引分别说明方向、实际双方、工作条件，以及怎样修订。让这条关系组织
相连的描述，各份文件展开自己的对象。采用这份 Yinyang 与借用某项方法仍是不同选择；
另一个作者可以组织不同的关系。

给人阅读的哲学与文学展开这种安排的意义，给模型使用的描述则明确表达相关理解与要求。
两种表达都可以在完整自我认识之前参与形成和修订可用关系；
[从个人模型到圣状](docs/writing-a-sinthome.zh-CN.md)展开这项哲学提案。

这些方法维护一项已经展开的范例。请求也可能需要另一种哲学或文学形式；即使其意象与
组织已不像阴阳，也应在自己的源位置支持它。
[从采用、组合到自己的创作](docs/example-and-commons.zh-CN.md)说明这种区别。

读者可以研究范例、借用方法，或采用情境化阴阳。完整采用形成六个问题的实际描述，并使它们进入私人使用端。
简单路线由语言模型直接综合并保存在私人 Git/GitHub；可选 Hindsight 用较复杂的原生工具实现同一方法。另写原创哲学不是前提。六份公开指南规定取向、人、伙伴、关系、环境与修订六个完整功能问题及其阅读职责。
原生形成保留六者，具体行文与物理文件布局按用途安排。

这六份描述也共同支持个人递归自我改进。取向说明改进服务什么，个人说明实际参与与条件，
伙伴连接可用能力与所需贡献，关系说明贡献怎样返回并改变后来的协作，环境实现描述，
修订则使改进方法本身成为可以重考的对象。把这些连接写进各自主题，不重复六次同一宣言。
相关工作直接使用[递归改进论证](docs/literary-recursive-improvement.zh-CN.md)作为根据。
描述修订说明表达改变；后续使用才为方法及个人参与可能的发展提供证据。

## 选择实现工具，保留同一份理解

两条路线都保留采纳的 Philosophy、可归属的 Personal 理解、六个完整功能问题及相互融贯，遵循原有
[修订依赖](formation/revision.zh-CN.md#刷新选定的根据)：读哲学，检索有关新来源，刷新纠正 Personal 并保留
冲突与不确定性，再综合六份、检查整体，将必要变化落实到 Skills 与环境并实际回读。

**简单路线。** 语言模型直接阅读和综合，维护
`references/situated/{orientation,person,counterpart,relationship,environment,revision}.md`。
实际修订文件说明本人的实践，不只是文件操作。把要持久保存的私人源放在 Git，并通过实际账号与发布维护者
保存到私人 GitHub 仓库，核实私有范围、提交内容与预期取得；原件保有维护者，凭据不进入仓库。
这条路线可以独立使用，不要求安装 Hindsight、服务或数据库。

**可选 Hindsight 路线。** 用原生 retain、可修订 Observations 和 Mental Models/Knowledge Pages 实现相同责任。
[配置与实施指南](hindsight.zh-CN.md)说明怎样按实际环境配置服务、提供方、来源 missions、六个问题、原生操作与读回。
把核对后的原生内容投影到相同六路径，或通过私人 `references/situated/index.md` 明确绑定全部六个完整正文。
两种安排都保有实际处境中的修订方法。原生存储与行文可以不同，但较少分组或各页成功不能证明保留了六者。

路线选择改变工具，不改变哲学、完整问题与证据职责。Full/Empty 是另一项分发选择，不为两条工具路线
复制哲学、指南或整套包。Personal 保留本人可读的主题文章及来源链接，原生 Observations 可在后台支持形成。
两条路线都不要求完整重复改写 Personal 或强制串联摘要，但已经纠正的 Personal 理解必须影响后续综合，
并能返回原始根据。

## 基于实际材料形成情境化版本

| 功能问题与必读职责 | 完整写作指南 |
| --- | --- |
| **取向：**实际采纳什么哲学、价值与方向，为什么，怎样指引工作并接受纠正？ | [取向](formation/orientation.zh-CN.md) |
| **人：**对这个人的目的、参与、能力、条件与不确定性的哪些有根据理解，会改变协作？ | [个人](formation/person.zh-CN.md) |
| **伙伴：**实际模型在真实条件下能做什么，希望它贡献什么，独立判断与可能出错怎样影响贡献？ | [伙伴](formation/counterpart.zh-CN.md) |
| **关系：**不同参与者怎样在共同活动中生成、审查、委派、纠正与返回，承担什么责任并产生什么后果？ | [关系](formation/relationship.zh-CN.md) |
| **环境：**选定关系怎样成为可取得的指令、工具、界面与物质安排，实际使用怎样纠正它们？ | [环境](formation/environment.zh-CN.md) |
| **修订：**这个人的实际实践怎样把目的变化、来源根据、判断、共同理解与环境变化接到已核验的结果？ | [修订](formation/revision.zh-CN.md) |

规定或实质修订模型问题前，联系当前描述与有关来源，完整阅读全部六份形成指南。
直接综合指引或原生 `source_query` 都从这份相连范围中形成；表格只是入口，不能替代指南的完整内容。
保留各问题的对象与完整功能，同时说明它与其余问题的联系。人、伙伴与关系仍是不同对象，
取向、环境与修订提供方向、实现和持续变化。不把这些问题缩并成较少的原型分组，也不人为隔离来源范围。
行文可以灵活安排，简单路线保留六文件路径；原生路线若改用绑定，则须使六项完整阅读职责都可取得，包括实际修订方法。

## 通过修订使六份描述融贯

把六份完整描述作为整体，对照重要来源与实际结果阅读，检查共同前提、概念、所指、时间范围、
参与、责任与实际后果是否相互吻合。保留真实冲突与不确定性；融贯不要求补造一致，也不把不同条件
误当矛盾。采纳的目的改变时，可能同时影响个人含义、希望伙伴的贡献、关系、环境与修订方法，
不只是修改某页措辞。

相邻描述可以作为需要协调的当前解释阅读，不能互相充当独立事实证据。重要主张返回原始根据判断。
修复受影响的来源、综合指引、原生 mission/问题或实现，重生有依赖的描述，再把六者联系起来完整阅读。
共同 bank、可读相同来源或六次单页操作各自成功，都不保证这种融贯。
[实际修订方法](formation/revision.zh-CN.md#检查六份描述的融贯)把这项工作放回本人的目的、材料与环境。
不强制增加第七份总摘要：关系应当进入六份描述及其实际使用。

公开分发提供
共同指引，不附带已填或占位的私人描述。

实际读回综合后的完整描述；采用原生路线时，还要检查抽取、Observations 与生成模型，
不从保存问题或请求成功推定形成完成。
有根据的未知可以是有用内容，虚构个人或复制画像不能提供实际内容。消费者取得、获授权的工作与
后续纠正检验不同层次的结果。环境或网站变更仍由实际维护者执行，模型形成本身不完成这些工作。

## 从已有材料与实践起步

个人作品是一个直接入口：文章、故事、音乐、设计或程序，都可能表达一个人怎样理解世界、
选择什么，以及怎样与他人共同生活和创造。创作把这些关系带进可阅读、讨论和修改的形式；
双方从作品、创作过程及其实际后果中解释有关含义，再把有根据的部分用于协作与环境。
作品也能反过来改变原有理解。

这里的「哲学」取广义：对这些理解、价值与做法的反思贯穿个人创作。
一件作品可以承载这种反思，并以自己的体裁成立；形成工作模型所用的哲学贡献，
是把当前有关的含义和理由展开。因此，下面的「已有哲学」也包括作品中尚待阐明的理解，
「发展哲学」可以是在创作与使用中把它说清楚。

实践中相连的是**人的创作、模型作为写作与创作伙伴、双方活动的环境**。
哲学、心理与工程说明理解和改进这项实践时的三种贡献；它们贯穿上述三者。
「哲学—心理—工程」是有用的观察角度，「作品—伙伴—环境」则让人找到实际可以着手的地方。

哲学、对自己与他人心理的理解，以及工程，共同参与个人描述与可用环境的形成。
[哲学、心理与工程的三位一体](docs/local-source-and-website.zh-CN.md#哲学心理与工程从已有能力补齐关系)展开其联系。
以下组合说明这项实践中已有的材料与尚缺的联系：

| 已有材料或实践 | 仍需补足的联系与下一项贡献 |
| --- | --- |
| 已有成文哲学或采纳的方向，尚无可用模型环境与已展开的个人描述 | 把哲学与事件历史、日常生活相连，同时准备发展和使用这份描述所需的模型环境。 |
| 已有相关心理理解、对话历史或生活材料，尚无可用模型环境与成文哲学 | 发展有根据的描述及其哲学意义，同时使所需的模型协助可用。 |
| 已有可用模型环境与使用经验，个人理解和哲学仍未说清 | 共同解释经验、偏好与概念，阐明其哲学意义，并在使用中修订安排。 |
| 已有成文哲学与有根据的心理理解，尚无可用实现 | 通过实际工程环境实现两者所选定的关系。 |
| 已有成文哲学与可用环境，尚缺具体个人根据 | 结合哲学理解对话历史与日常生活材料，凝练有根据的个人描述，并在当前使用中修订。 |
| 已有有根据的心理理解与可用环境，尚无成文哲学 | 展开实践中隐含的哲学理解、价值与方向。 |

这六种组合说明起步条件，不是不同的形成路线或固定顺序。文件、检索、工具、执行或
核验的缺失阻碍所需贡献时，就准备这些条件；不要求当事人先学会实现一切。从已有内容
发展缺失的联系，让个人理解、哲学与实现能够在工作中持续形成并相互修订。

目的包含通过计算机实现的工程时，人与伙伴共同发展有关的计算表述与环境：选取的活动、
其中的状态与条件、变化中的接续，以及可观察后果。文件与工具实现和使用这个模型，
不因自身存在便提供它的含义。分工贯穿问题选取、建模、实现与反馈，不要求当事人
亲自完成上游模型之后，伙伴才能贡献。[环境写作指南](formation/environment.zh-CN.md#在情境中推导行为)
按实际用途所需的精度展开这层联系。

个人模型把偏好、心理活动、经验、概念与哲学理解带进同一份可修订的自然语言描述。
模型帮助重建有关历史、发展解释、比较可能并承担写作；人贡献目的、亲历经验、识别、
异议与判断。已知偏好可以指导安排，同时保留其解释尚未明确的部分。安排也可能来自
限制或默认值，因此，仅凭它已经存在，不能看出当事人想要什么。

这项实践中的[从材料凝练个人模型](formation/person.zh-CN.md#从事件历史哲学与个人材料凝练个人模型)，
联系长期对话、日常习惯、生活材料与哲学。分析、溯因、比较、概念澄清与后续互动使拟议
关系可以修订。偏好报告、解释性的心理假设与选定的哲学方向可以相互启发，同时支持
不同结论。个人指引展开这些根据，说明这种理解与凝练为什么不等于心理建模。

逐渐形成的个人模型也参与形成与之贴合的伙伴模型及选定关系。需要区分
希望伙伴承担的角色和优先次序，与它的实际能力和回应模式：即使内部过程仍有不可见
之处，指令、可用工具和行为仍可
检查；仅仅取得源代码也不能确立协作贴合。哲学通过表达自我理解、意义与可能关系，
主动参与这种理解与凝练；经验又能修订它的说明。

哲学写作可以偏重文学、工程哲学、西方哲学、科学哲学、逻辑学、美学，或其他相关问题。
这些偏重展开同一实践，起步材料与顺序可以不同。
技术背景不选定另一条形成描述的路线。贴合尚不明确时，探究提供假设与
判断依据，不要求在有用工作之前完成解释。借助模型，选定的生活需要与关系
取得工具、信息、指令和计算机环境的形式，介入购物、投资、聊天与学习等活动。
实际使用又返回生活：什么变得容易，出现什么代价，当事人学到什么，以及关系是否
支持其选定的发展。理解与安排共同修订。环境凝缩选定关系，不包含完整的人。

假设一个人总在同一张桌子前工作。这项观察符合多种解释：他可能偏好这个安排，
这里也可能是唯一具备所需设备的地方，或者只是一直没有作过比较。仅凭这一点推荐
永久固定的工作位置，就会把当前安排转成个人理想。有关证据可能是过去自由选择的
安排、另一选择真正可用时当事人的体验，或在有用且获授权时进行的一次普通可逆尝试。
如果移动使一项珍视的资源变得不可用，不喜欢这次尝试就不能单独确立对固定位置的偏好。
需要比较随地点一起变化的活动和成本。模型能够检查这些依赖并发展候选解释；无法取得的
个人体验仍由当事人贡献。证据不能区分时，让描述保持条件性。改善这个工作空间，
不必先判定一项普遍人格特质。

把有关来源与关系纳入上文的直接综合指引，或可选的原生模型问题，通过检查与修订保留
六个完整功能问题及其相互融贯。简单路线保留六份实际文件；原生路线可以投影到同样的
路径，或用明确的私人索引连接六份完整正文。实际修订方法说明本人的来源与 Personal
刷新、所选工具的处理、修复和环境实现。
在真实消费者处读回完整结果，并从使用中修订。开始创作和有用工作不需要完整传记或完整心理认识。

## 语言的作用

一段文字可以报告经验、提出解释、确立选定关系，或借意象汇集可能。其区别影响结论时，
应当识别。「那个问题之后，我失去了思路」报告一份体验；把中断归因于实现细节被转交，
提出一种解释；选择让模型承担这些工作，则给双方关系一个方向。描述应使这些联系可用，
而不把一次经历变成普遍禁令。

人和伙伴的描述共同发展。角色与分工不穷尽任一参与者，也不确立能力不足。
[言说、对立与自我形成](docs/speech-opposition-and-self-formation.zh-CN.md)展开后来的表达
怎样重新解释早先的话，并重构其前提。[修订指南](formation/revision.zh-CN.md#来源与证据)
说明怎样保留这里需要的来源、竞争解释与不确定性。

## 在表达、关系与实现之间往返

`人可理解的表达 ⇄ 对活动与关系的明确理解 ⇄ 工作行为`

哲学写作可以探索超出某种工作描述的可能；描述则说明协作所需的有根据的解释、后果与
未决关系。人和模型都可以阅读这两种表达，并在它们之间往返。写作用途不同，并不按
读者身份划分阅读权限。清楚的文字可以使一种关系可用，不需要把完整的人或相遇全部
形式化。[环境写作指南](formation/environment.zh-CN.md)说明选定关系怎样进入
实际指令、工具与使用。

## 使用并继续发展已经形成的理解

<a id="在使用中维护私人材料"></a>

公共哲学保留在共同维护的位置，私人经验保留在相应的支持来源中。
[修订指南](formation/revision.zh-CN.md#用哲学刷新个人支持材料)负责这些材料、工作模型
与环境之间的持续整理。公共文件投影器在机械上保留私人文件，不禁止获授权的语义修订
或退役私人笔记。

<a id="根据不断变化的相遇进行修订"></a>

新提出的参与方式可以改变描述的适用情境，而不抹去原先条件。例如，亲自参与实现以学习，
