# 修订

<a id="修订个人阴阳与工作环境"></a>

[English](revision-guide.md) · [哲学与模型](design-and-revision.zh-CN.md) · [环境写作指南](formation/environment.zh-CN.md)

这是第六份工作文件，说明怎样修订。在哲学、个人理解与实际工作发生变化时，继续保持它们之间的联系。持续维护的对象共有六份文件：取向、个人、模型伙伴、关系与环境这五份处境化说明，以及本修订指南。五份说明阐明参与者、方向与条件；指南解释如何修订，也根据使用情况修订自身。按各自不同的责任，共同维护这六份文件。公共指南提供可复用的方法；实际说明与个人支持材料仍由各自的私人所有者维护。

一次刷新可以从发展后的哲学、生活条件的变化、工作中的异议，或不符合预期的结果开始。恢复所要实现的结果与当前证据，再通过各自的所有者完成受影响的联系。请求刷新整个环境时，使用下面相连的三轮工作；局部修复则可以从相关位置进入，沿着发现的依赖继续。两者都不要求另建生命周期、定时任务，也不要求每改一句话就重写全部内容。

## 确定修订范围与联动

先确定要得到什么结果，以及当前哪一部分需要修复或发展。区分**这次修订的重点**、
**用来判断它的材料**与**实际需要跟着改变的部分**。读取哲学或个人描述来帮助判断，
并不因此选择重写它。按协作入口的阅读约定，从已经可用的完整六份理解出发；
实际编辑范围由请求及工作中发现的依赖决定。

| 当前重点 | 相应工作 |
| --- | --- |
| 整体刷新个人阴阳与环境 | 用哲学和当前来源整理 personal 支持材料，将六份文件连起来评估，再检查请求涵盖的 Skills 与环境，修改不再适合的部分。 |
| 修订某项哲学主张或个人解释 | 展开这段内容，检查哪些描述、方法或表征确实依赖其含义；联动修改这些部分，保留不受影响的内容。 |
| 修复某个 Skill、页面、工具或安排 | 用相关理解诊断并修复该对象；结果若暴露了前提或个人解释的错误，再返回相应的维护位置。 |

实质含义改变时，沿着真实依赖把变化落实下去。措辞、链接或呈现上的纠正，则可以在受影响的
来源和阅读处完成。整体刷新与局部修复都不要求处处修改：改动范围由预期结果需要什么来决定。
反过来，必要的依赖仍在呈现旧行为时，也不能只改完第一个文件就停下。保留用户明确给出的
停止边界，将与之相容、已经授权的工作推进到所要求的结果。

## 确立当前可用的材料

阅读当前哲学与全部六份文件，再按问题选择需要的个人支持材料。找到持续维护的原件，将其与摘要、生成副本和发布快照区分开。来源位置让材料可以被找到；直接读取当前内容，才能确定实际有什么可用。对理解或行动有影响的访问缺口，需要明确保留。

当前目的、学习或研究方向、关系及工作条件，可能已经不同于旧说明形成时的情况。比较相关来源与实际交流，不因摘要已经存在就继续保留，也不因某种更新看起来合理就将它写成事实。模型承担检索、比较与有根据的写作；个人补充现有材料中无法取得的体验与重要判断。已经提供的内容应继续使用。

## 按实际用途写作

`references/situated/` 中的五份描述、共同维护的 `references/revision-guide.md`，
以及 `references/personal/` 中的派生支撑，
是给模型使用的明确背景与指令。
用清晰的自然语言写出相关对象、关系、证据、条件、职责与后果。当体验报告、解释、选定承诺
和要求会导向不同判断或行动时，明确区分。形式是让这些关系可用于推理和工作，不要求固定
模板或符号表示。个人信息仍是有情境的证据，不因被模型读取就成为命令。

优先直接表达。直接说明仍不能使某项重要关系清楚时，再借助哲学区分或文学意象，并说明
其有关含义与适用范围；不让伙伴只能从人物或比喻中猜测实际要求。原始表达作为可归属的
来源材料保留，维护中的解释与操作后果则明确写出。完整的哲学论证留在面向读者的维护位置，
需要时引用。

## 来源与证据

证据为这六份文件提供根据；其私人索引是有独立责任的支持材料。实际入口维护在 `references/personal/sources.md`，定位各份说明及相关修订判断的根据，并给出足以知道为何查看的解释。公开分发提供方法，不提供个人来源索引。证据按问题需要取用；有用的主题材料留在私人目录或既有维护者处。

因为材料与当前理解有关，才选择可归属的表达、个人写作、对话、记忆、观察到的工作与哲学。保留来源身份、时间、有关段落或消息，以及足够判断重要主张的背景。痕迹记录经过选择的活动，解释说明其意义。原件与说明之间有持续维护的摘要时，将这个关系写清楚：摘要的选择与遗漏，可能影响有争议的理解。

人的报告支持其在处境中表达或经历了什么，不确立同时提出的所有解释。观察到的工作说明检查条件下发生了什么，动机可能仍未知。选择的承诺说明应该怎样工作，行为显示其实现。哲学提供概念、理由、可能的解释与所采纳的方向，不证明个人机制。以虚构情形为例，当事人说阅读安排更轻松，支持经验上的轻松；记录显示到达了目标段落，支持访问。两者都不确立持久学习，也不识别是哪项界面改动造成改善。后来在新例子中的参与，可以补充相应尺度的证据。几份说明重复同一摘要，不增加独立支持。

按有关尺度标注变化的条件：上个月可用的工具、暂时负担与持续承诺，具有不同范围。后来的表达可能纠正解释、描述新处境或带来未决冲突；不能单凭更新判定。保留冲突证据，不把它抹平成一致画像。用自然语言使重要推论可追溯：什么提示了这个解释，为何这样联系，什么不确定性限制其使用。能够到达不证明与主张对应；来源不可取得，留下覆盖限制。

较长经历、精确摘录与独有原件，保留在实际维护者处。共同维护说明，不要求复制原始来源。私人派生笔记按照[写作方法](revision-guide.zh-CN.md#按实际用途写作)，明确说明来源、范围、解释与相关后果。文件名跟随实际材料，不要求为每篇文章建立空伴随文件。公开哲学引用留在论证附近。淘汰重复的活跃材料，同时保留有用原件与可恢复性。维护来源不授权收集无关传记，也不授权公开私人路径、引文、画像或未发布作品。只将获授权的可复用洞见返回公开包。

## 用哲学刷新个人支持材料

先让发展后的哲学与已有个人材料相遇：它澄清了哪些解释，补出了哪些缺失的区分，又使哪些摘要显得误导？修订派生说明，让相关体验、解释、选择的方向与不确定性仍然清楚。哲学可以帮助形成理解；可归属的表达与实际使用，为这种理解如何适用于此人提供依据。

根据改变、访问失败或纠正改变解释时，使用上述来源区分。淘汰过时摘要、重复解释，以及在当前公共所有者已经提供内容时，仍被复制进私人支持材料的公共文章。保留真正私人的意义与有用证据，而不是再建一套公共理论书库。

## 用哲学与个人材料刷新六份文件

将哲学与刷新后的个人证据一起阅读，再修订五份说明。写作前，完整阅读受影响说明对应的[形成指南](design-and-revision.zh-CN.md#基于实际材料形成情境化版本)。取向说明采用的价值与方向；个人说明使对实际个人的理解有据可依；模型伙伴说明连接现有能力与期望贡献；关系说明解释共同活动；环境说明解释这些活动在实际条件下如何成为可能。相连而不同的写作责任，使五份文件各有所述，不成为同一画像的重复版本。

提炼使用所需的关系，保留足以使它们可修订的理由与证据。区分偏好与解释性假说、期望角色与已展示的能力、选定安排与实际效果。双方都可以生成、推理、反对与修订。分工改变不意味着缺乏能力，文字改善也不意味着个人已经发展。保留仍有支持的内容，重写发生变化的关系，再将各份说明连读，检查是否连贯。较长的证据仍留在支持材料的所有者处。

然后，实际使用若暴露了缺失的联系、过时的方向，或将修订落实到环境的更好方法，就修订本指南这第六份文件。检查其方法是否仍服务于哲学与有根据的说明，以及这些说明是否确实可以通过该方法持续维护。因此，完整刷新要评估全部六份文件；每份文件仅在自身含义或贡献发生变化时才需要修改。

## 用整个阴阳刷新 Skill 与环境

用整个阴阳，包括持续维护的六份文件，尤其是其中五份有根据的说明，评估请求所涵盖环境中的所有 Skill。检查每个相关 Skill 的目的、指令、例子、资源和实际行为，是否支持所需要的贡献。专门 Skill 保留自身的方法与权限；个人说明影响它们的使用，不必被复制进每个包。相连的提示词、工具和安排，在其依赖影响结果时，也进入考察范围。

修复实际的不匹配：过时的责任分配、相互矛盾的指令、无法取得的上下文、不合用的界面，或已经不再服务当前使用者的机制。移除被替代的指导，不在周围再叠一层。评估也可以发现某个 Skill 已经合适，无须修改。覆盖请求范围，比让每个文件都出现形式上的改动更重要。[环境写作指南](formation/environment.zh-CN.md)展开实现；实际实现则使用当前环境自己的写作、实施与发布方法。

## 发布前让网页修订可见

修改网页时，在对话中直接展示发生变化的图。新页面或实质修订后的页面，在发布前展示实际未发布版本的可读渲染预览，并解释有实质影响的变化。明确预览对应哪个版本。如果随后修改使其发生实质变化，在发布该版本前展示更新后的预览。源代码片段、拟议布局或已经发布的旧页面，都不能说明当前未发布版本实际呈现的样子。

这是展示顺序，不是批准或等待关卡。继续完成已经获得授权的发布与核验，不请求许可，也不等待回复。工作期间若收到反馈，将其纳入后续工作。实际授权、个人认证、同意与明确停止边界，继续保留原有范围。

## 让结果返回理解

在对应关系重要时，分别核对来源与结果：将摘要与证据比较，将生成投影与其所有者比较，将完成声明与通过真实入口到达的结果比较。同一种解释在多个文件里重复，几乎不增加独立证据。说明无法取得时，需要修复交付；说明已经被忠实执行，却产生不合适的贡献时，需要检查其含义或所选择的关系。

通过实际源所有者、受影响的使用者和发布路径，完成已经授权的变化。重新生成依赖副本，淘汰被替代的活动材料，再回读目标使用者实际可取得的版本。私人记录、引文、画像与未发布作品不进入公共投影。[包指南](docs/skill-package.zh-CN.md)负责公共与私人内容的投影规则；本指南不另建同步机制。

比较所要实现的结果与可观察的实际结果，解释仍未解决的必要差异。当使用中的证据提出挑战，让它返回个人材料、六份文件中的任何一份或哲学。一个作品可以完成，整个安排仍可继续修订；有用的产出、协作是否合适，以及个人的发展，各自保留不同的证据要求。
