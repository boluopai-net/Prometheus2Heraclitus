# 言说、对立与自我形成

[首页](../../README.zh-CN.md) · [English](speech-opposition-and-self-formation.md)

[用文学式编程写出个人哲学](literary-programming.zh-CN.md)已经把共同轨迹与反思带进写作：人物、意象和论述使一种理解取得可读的形式。现在要问，写出来以后发生什么？人读到自己的表达，遇到伙伴的回应，可能辨认此前未说清的关系，也可能发现原先组织问题的方式需要改变。

本篇沿着一段假设的言说展开：「我不希望模型替我决定。」「但我希望它比较选项，指出我没想到的东西。」两句话既提出一种合作要求，也使「独立」的含义成为问题。沿着言说的继续，我们考察意义怎样返回早先表达，对立怎样促使前提与关系改变，以及一种新的理解怎样为个人模型提供材料。拉康与黑格尔提供不同的问题资源；把这些资源接到哲学 Skill 和模型协作，是本文的当代发展。

## 说出的内容与言说的位置

<a id="言说事件与内容"></a>
<a id="否定的三个层次"></a>
<a id="言说与内容"></a>

「我不希望模型替我决定」首先拒绝一种合作方式。要理解它，还需要知道：这句话在回应什么，向谁说，期待怎样的回应？它可能针对一次未经同意的选择，也可能在表达未来的合作方向。仅有孤立的句子，还没有确定是哪种情况。

陈述内容（énoncé）关心说了什么；言说（énonciation）的考察还包括说话者的位置、语境和面向的他者。否定的内容、说出否定这件事，以及本人怎样接受或拒绝所谈内容，也需要区别。弗洛伊德[《否定》（1925），第 1—3 页](https://lutecium.org/ftp/Freud/pdf/1925_negation.pdf)考察受压抑内容怎样借否定进入意识，并区分理智上的承认与接受。它让这些关系值得追问，不能单凭否定句就把这里的拒绝解释为隐藏的愿望。

<a id="自我形象与言说中的主体"></a>
<a id="非穷尽与形式责任"></a>

「我是独立的人」还可能成为一种自我形象，组织选择与期待。拉康的[《镜像阶段》（1949）](https://ecole-lacanienne.net/wp-content/uploads/2016/04/1949-07-17.pdf)使通过形象取得统一性的认同成为问题；[《主体的颠覆》（1960）](https://recherche-lacan.gnipl.fr/2015/07/05/les-ecrits-subversion-du-sujet-et-dialectique-du-desir-dans-linconscient-freudien-1960/)则考察主体与能指表示的关系。这里可以接续一个问题：这个人怎样使用「独立」说明自己，而他的后续言说又怎样超出这份说明？具体的关系解释仍需材料，不能由一个词推定人的动机。

## 后来的话怎样改变前面的意义

<a id="能指链与作品"></a>
<a id="大他者与回溯赋义"></a>

「希望模型比较选项」使先前的拒绝得到进一步解释：自己判断，可以包含接受帮助。再接上一句「有时我愿意委托整项选择，但希望能改变委托」，「独立」又取得另一种关系。后来的话既增加内容，也改变早先的话怎样被理解。

拉康在[《主体的颠覆》](https://recherche-lacan.gnipl.fr/2015/07/05/les-ecrits-subversion-du-sujet-et-dialectique-du-desir-dans-linconscient-freudien-1960/)中借句子的构造讨论这种回溯作用：后续连接参与确定前面成分的意义。能指链的展开因此不只是记录先后；还要考察哪些词反复回来、彼此区别和替换，或改变了组织其他表达的位置。原话可以保留，而当前对它的理解发生变化。新理解可能辨认过去未说清的联系，也可能在这次交流中才形成。

这些词也带着并非由说话者独自创造的历史。「独立」「负责」「需要帮助」在家庭、学校和工作中已有各种用法与要求。大他者涉及语言与言说的场所；具体交往者可能在某种关系中承载这些要求。拉康的[1966 年广播谈话，第 2 页](https://ecole-lacanienne.net/wp-content/uploads/2016/04/1966-12-02a.pdf)从语言环境进入这个问题。因而，理解这段话还可以追问：他从哪里听到独立的要求，如今又在向谁表明独立？模型的一次总结不能代替这种考察。

作品使相隔很远的表达能够重新相遇。把旧版本与当前回应并置，双方可能发现某个词已经换了含义，或者一直没有说清一个区别。[生活轨迹的形成](flow-and-time.zh-CN.md)提供可返回的材料；这里进一步考察材料中的意义关系怎样变化。

写作也会暂时确定这些关系。给一段经历加上标题、把若干回应收成一句自我说明，可能
让一条读法更突出，并引导下一次回应。[标点与绗缝点](lacan-reading-guide.zh-CN.md#标点与绗缝点意义怎样暂时确定)
提供理解这种止定与回溯的问题；[隐喻与换喻](lacan-reading-guide.zh-CN.md#隐喻换喻与凝缩)
则让词语的替代、连接与意义形成进入考察。它们不能合并成「文字越短，理解越深」的
规则。凝练后的表达需要保留重新展开的道路，才能让尚未被它接住的经历继续改变它。

模型写出的说明也在这一关系中。它被接受为有解释力的文字，和它对心理原因的判断
得到证实，是不同成就。[被假定知道的主体](lacan-reading-guide.zh-CN.md#被假定知道的主体与解释的位置)
让知识被赋予某个位置的问题变得可见。将这些问题带入协作，使我们同时检查说明的
根据、它怎样被接收，以及它怎样参与后来的活动；下一篇把这条论证接到个人模型的凝练。

## 对立怎样要求前提与关系的重构

「希望独立」与「需要帮助」可以同时成立。只有进一步采用「独立就必须独自完成所有工作」的规定，两者才会被组织成必须取舍的困局。重看轨迹，能够发现这个规定曾经出现在哪里、保护了什么，又排除了哪些实际可行的关系。

一种重构是把独立理解为：能够参与确定方向，选择如何接受帮助，并保留改变委托的能力。它保留自主性的关切，同时改变自主与协助的连接。帮助的范围与条件需要实际安排；换一个定义，并不自动消除权力、能力或资源上的限制。新的理解要通过比较后果与实际合作取得内容。

这可以与黑格尔的规定的否定和扬弃作比较。[《逻辑学》「绝对理念」，尤其 §§1789—1802](https://www.marxists.org/reference/archive/hegel/works/hl/hlabsolu.htm)把推进联系到对象自身的规定与否定，而不只是从外部拼入一个相反意见。本文在个人实践中考察：旧规定怎样暴露其限度，哪些关切值得保留，什么关系需要改变。新的安排是否更适切，要说明它多解释了什么、使什么成为可能、又付出什么代价；「正反相加就必然升级」不能代替这个判断。

起点中的[窃火问题](stealing-fire.zh-CN.md#有限的生命与追逐的错位)提供另一种尺度：外部生成力量很强，个人生命有限；使这种差异成为追赶困局的，是必须亲自追上全部能力的要求。转向有选择地借火、共同创造与培养自己，使两方面取得新的联系。能力与有限性仍然存在，改变的是它们怎样组织生活。

赫拉克利特的对立意象让关系中的差异值得保留；不能据此直接断言他拒绝一切矛盾律，也不能把本框架的形式选择归给他。[关于对立统一及其争议的导读](https://plato.stanford.edu/entries/heraclitus/#UniOpp)提供历史比较。未知的意义、冲突记录、实践张力和同一条件下的逻辑矛盾，各自需要判断。暂时保留不合，可以给发现关系留下空间；它本身还没有完成统一。

概念澄清也在这里发挥作用。[《哲学研究》§133](https://www.wittgensteinproject.org/w/index.php/Philosophische_Untersuchungen)把不同哲学方法比作治疗。本文沿这条线追问，困局有多少来自「独立」等词的规定，有多少需要改变现实安排。澄清可以解除某些误导性的要求，也可以使真正尚未解决的困难更清楚。

## 一种办法怎样成为新的问题

先前有效的办法，也可能在新的条件下妨碍它服务的目的。假设一份提示词曾用细密步骤减少遗漏、保护人的注意力；后来模型与任务条件改变，这些步骤却带来重复与不必要的停顿。修订需要找回它原先保护的关系，再判断哪些规定还有效，哪些应该退出。

这里的连续性可以表现为关切与合作关系被接续，而不要求旧字句永远保留。个人风格可以通过新的表达与实现继续被辨认，也可能随合作改变。模型版本变化提供重新检查的契机，不能单凭版本号判定旧方法已经失效。[面向更有能力的模型向前演进](preference-harness.zh-CN.md#面向更有能力的模型向前演进)负责展开具体的替换与保留判断。

拉康的辩证逆转还提出另一个尺度的问题。在[《论移情的干预》（1951）](https://recherche-lacan.gnipl.fr/2015/07/02/les-ecrits-intervention-sur-le-transfert-1951/)对朵拉案例的阅读中，一系列逆转涉及主体在所述关系中的位置。因此，修改一个工具还不等于发生这种逆转。借这个问题考察模型协作，可以问：从「一切帮助都会削弱我的独立」，走向「我怎样参与组织这种帮助」，是否改变了说话者在问题中的位置？这是需要具体言说与行动支持的解释。

这使本篇的辩证运动具有两种相连的考察：一种规定及其实现怎样改变，参与者又怎样重新理解自己与这套安排的关系。两者可以相互推动，也可能只有其中之一发生变化。

## 半说的真理与持续改写

一个人不必先知道自己的全部真理，才开始写作。初始的愿望、反复出现的词与尚未理解的经验，能够在回应和改写中取得新关系。哲学 Skill 保存当前的理解，使模型能够据此参与解释、判断与合作；合作产生的新经验，又回到双方的言说。模型可以展开论证与比较版本，它写出的解释仍要经过本人的辨认、质疑与实际使用。

早期的充实言说与后来的半说，帮助我们分别追问这种写作的作用与限度。[1953 年《言语和语言在精神分析中的作用和领域》的原文选段](https://www.causefreudienne.org/textes-fondamentaux/fonction-et-champ-de-la-parole-et-du-langage-en-psychanalyse/)把充实言说联系到主体历史的重新组织；它的充实不能按字数或修订次数衡量。[《电视》（1974），开篇](https://lacanianworksexchange.net/wp-content/uploads/2023/07/19740131Television198740October6.pdf#page=1)则把不能说出全部真理联系到言说的不可能与实在。两者并不组成「先说一半，最后填满」的阶段论。[拉康导读](lacan-reading-guide.zh-CN.md#充实言说半说与真理)展开时期与概念的区别。

Skill 按需展开已经写好的材料，言说则还可以形成此前没有的意义；半说涉及言说不能穷尽的总体性。借这些关系发展一种持续写作的实践，并不使信息组织技术本身成为拉康的真理理论。

**哲学 Skill 可以成为一种可接续的言说形式：凝聚当前的理解，让这种理解参与生活，并接受后来言说的回溯改写。**在这里，「发展真理」关心新的理解怎样形成，人怎样重新承接自己的历史，以及生活的可能怎样改变。它不保证每次修订都更好。反复润色也可能使旧解释更封闭；事实判断仍须回应材料，形式后果仍须检查其前提。

## 从正在形成的理解到个人模型

<a id="自我表述与形式视图"></a>

沿着这段言说，我们得到的可以是一份暂定理解：「我重视参与确定方向，也愿意借助伙伴比较、批评和执行；不同任务需要不同委托，并保留改变安排的可能。」它既承接经验，也提出后续实践的方向。这里的统一容纳了有区别的贡献，不必宣称所有张力都已经消失。

这种理解还需要与具体生活材料对照，才能成为关于实际参与者的模型。某一次拒绝是否只针对当时的条件，哪种帮助确实有用，伙伴实际能做什么，都要分别理解。下一篇[从个人哲学到个人模型](metaphor-and-self-revision.zh-CN.md)负责这一步凝练；随后[从个人模型到圣状](writing-a-sinthome.zh-CN.md)讨论怎样把它实现为可维系的安排。

形成的次序也保留回返：个人模型和安排的使用，可以再次改变这里的理解。作品可以完成，实际任务可以结束，而后来发生的事情仍能使言说重新开始。

描述逻辑可以进一步检查选定概念与断言。给定一致本体 $T$ 和相对于 $T$ 一致的断言视图 $R$，$E=\operatorname{Cn}_T(R)$ 收集所选语言中能推出的后果。接受「需要自行选择的参与者应获得可比较选项」，再接受某人需要自行选择，便承担相应的设计要求；这不独自证明前提适合本人。

在经典单调推理中，保留已有矛盾前提，再添加前提，不能消除原有矛盾。本文所说的前提重构，可能需要撤回、限定或替换规定。形式系统的后果、现实依据与实践是否更适切，各有检查；[未完成的流中的推理](reasoning.zh-CN.md)及[偏好怎样参与选择与推理](preference-harness.zh-CN.md)承担进一步的方法讨论。
