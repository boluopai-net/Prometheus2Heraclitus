# 从个人模型到圣状

[English](writing-a-sinthome.md)

本人与模型此前一起工作，做出可以找回的经历、选择、探究与环境构造的轨迹。
反思这段轨迹，又发展了对彼此及合作的理解。有了这些材料与理解，双方能够
写出个人哲学，再把哲学同生活材料一起，
凝练为本人、伙伴与双方关系的模型。[从个人哲学到个人模型](metaphor-and-self-revision.zh-CN.md)
展开这段过程。本文接着追问：这些理解怎样在本人的实际环境中成为可工作的安排，
使用又怎样改变它？

这一段需要的不只是把文字带进另一场对话。关于一个人希望怎样创造的理解，需要
遭遇伙伴的实际能力、可用工具、可以找回的背景，以及生活中的后果。这些关系取得
具体形式，并在使用中得到修订，共同形成本文称为**「圣状」**的个人安排。

例如，一个人常有尚未说清的想法。他能够察觉哪里有意思、哪里不对，却希望伙伴承担检索、展开、写作和实现。他需要的并不只是一份描述自己的文字：模型还要能够读懂有关背景，理解这次希望得到什么帮助，并在实际条件下完成工作。怎样认识这个人，怎样安排合作，怎样让合作发生，是同一个问题的几个方面。

## 圣状所指的具体形式

<a id="为什么是圣状"></a>

「圣状」沿用拉康的 **sinthome** 一词。在[研讨班第二十三卷，1976 年 2 月 17 日课](https://recherche-lacan.gnipl.fr/2013/07/26/lxxiii-le-sinthome-1975-1976-lecon-du-17-fevrier-1976/)的特定结构造中，圣状参与结的修补；[5 月 11 日课](https://recherche-lacan.gnipl.fr/2013/07/26/lxxiii-le-sinthome-1975-1976-lecon-du-11-mai-1976/)进一步讨论乔伊斯的写作、ego 与结的关系。这些讨论使写作不仅能够从作品表达了什么来考察，也能够从它在一个人那里怎样发生作用来考察。相关术语见[拉康概念导读](lacan-reading-guide.zh-CN.md)。

本文用这个名称指称一种当代的个人安排：哲学表达他怎样理解世界、生活与价值；心理理解联系他的经验、情感、偏好与关系；工程使双方所采用的理解进入实际的模型协作。三者共同形成的内容，才是这里所说的圣状。

以开篇的例子来说，文字中可以说明这个人如何参与创作、模型应承担什么；记录与检索使先前的工作能够继续；工具让想法成为文章、图示或程序；实际交流又使双方发现哪些理解并不适合。圣状指这一套有内容、有实现并被使用的安排。一篇文章、一个 Skill 或一次操作，可以是其中的一部分。

它发生在生活中，也可能帮助人安顿欲望、承受张力或继续创造。这些作用如何发生，要看具体的个人和使用过程。形成一套安排与它实际发挥什么作用，是两个相连的问题：前者需要说明它怎样构成，后者需要理解它怎样进入生活。

## 把已有根据的模型带入实现

<a id="从个人材料形成双方的模型"></a>

<a id="独特的生活形式"></a>
<a id="从个人材料到可运作的形式"></a>

进入这项工作的模型，已经从写成的哲学与经历、作品、选择和交互中取得内容。
它们选取合作所需的关系：本人关心什么，怎样经历某些情境，什么条件影响其
表达和行动，以及哪些地方还不清楚。实现接着要问，环境能否支持模型所描述的
合作。使用显出歧义或不合时，仍然能够返回它们的根据。

在开篇的例子里，「不愿意把每个细节都说完」可以有不同含义：此刻的想法还没有成形；他已经知道要做什么，只是希望模型自行调查；或者当前表达方式使他难以继续。不同理解需要不同回应。模型要结合实际交流判断，而不能仅凭一句概括就固定这个人的参与方式。

偏好模型可以说明他希望怎样合作，例如先看完整结果，再指出不合适的地方。本项目的[基于事件历史的心理建模](../formation/person.zh-CN.md#事件流心理建模)根据对话历史与日常生活，进一步形成对这种参与和经验、情感、关系之间联系的自然语言概念说明。此前写出的哲学贡献对创造和独立的解释。让这些理由与具体材料相连，有助于伙伴区分选定的方向与对本人一贯行为的断言。

**伙伴模型**同样需要遭遇实际条件。所需的伙伴要能做什么？当前模型能够做什么？哪些工作还依赖工具或其他条件？如果希望模型把一个想法做成可检查的作品，就需要的不只是善于回应的语气，还包括调查、推理、写作、执行与检查的实际能力。

双方关系说明这些贡献怎样配合。人可以提出愿望、辨认不合、判断结果；模型可以主动发展解释、提出异议并承担实现。这样的分工可以改变，也不把推理专门归给模型、把直觉专门归给人。合作围绕实际目的组织，双方都能生成和判断。

## 让理解成为可以使用的安排

关于人的理解不会自行进入下一次工作。需要给它一种现有模型和工具能够使用的表达，并使有关表达在需要时真正可得。

有些关系适合用自然语言说明，例如「当一个想法还不完整时，先发展一个可供判断的版本」。有些材料需要关联记录，才能知道某次纠正针对哪一段工作。需要计算或执行的部分，则可以使用结构化数据、程序和工具。表示的精确程度取决于实际用途；能够用清楚语言完成的工作，不必先改造成一套形式系统。

| 载体 | 在这套安排中的作用 |
| --- | --- |
| 提示词 | 表达当前相关的目的、背景和所需贡献。 |
| Skill | 组织可复用的理解、方法与资源，供模型按任务读取和使用。 |
| Harness | 把模型、指令、工具、记录和运行条件组织成实际工作的环境。 |
| 元 harness | 说明怎样理解、选择和修订这些工作环境，包括对本人、伙伴与双方关系的理解。 |

这些载体不是互相替代的名称。阴阳用一个 Skill 承载元 harness 的理解和方法，具体任务则在实际 harness 中完成。换一种技术条件，同样的关系可以采用不同载体；是否仍然合适，要由它能否支持所需合作来判断。

回到开篇的例子，关于合作的文字需要让模型知道：用户提出一个尚未完成的想法时，它应继续调查、构造并交付可检查的结果。相关记录要能找回，所需工具要可用，结果要以用户能够理解的方式呈现。这些条件一起实现，才使「由模型承担显式展开」从愿望成为实际分工。

澄清后的理解也能够在习惯、关系与物质环境中取得形式。假设一个人开始把
在帮助下行动理解为能动性的一种运用，随时可进入的工作空间、回到未完成
对象的习惯，以及允许伙伴展开初稿的约定，便可以让这份理解在实践中持续。
各项支持承担行动的不同部分，一段提示词无法独自提供全部条件。哪些支持
重要，要从本人的处境及他希望维持的活动来判断。

这就把哲学澄清接到修习。看清一种无益的图景，可以打开另一种回应；要让
这种回应持续，又可能需要使它在疲惫、相互竞争的要求与他人的目的之中仍然
可用的条件。圣状命名这份理解与条件的具体结合。它的贡献，要在一个人怎样
通过它注意、判断、回应并继续生活之中遇到。更好的描述通过使用及其后果，
成为转变的一部分。

## 使用怎样改变这套安排

<a id="先表达到能够工作再让工作改变表达"></a>

安排不必在第一次使用前就已经完备。一个明确的目的、一段背景和一项可用能力，可能已经足以完成下一件事；工作中发生的困难，又能说明还缺少什么。

假如模型交付了一个完整方案，用户却认为它误解了最重要的关系，需要追查的可能是对人的理解，也可能是模型读到的背景或任务判断。若解释正确而工具无法完成，则要修订实现条件。不同问题要求不同修改，不能把每次失败都归为「个人模型还不够详细」。

前面的[言说、对立与自我形成](speech-opposition-and-self-formation.zh-CN.md)已经讨论理解怎样改变。这里进一步判断这种改变是否进入了实现：伙伴是否读到新描述，工具与分工是否相应调整，以及实际使用是否改善。某些张力可以解除，某些需要重组，还有些需要这套安排帮助承受；形成圣状不等于消除全部对立。

同一套安排因而可以在修改中持续。更换模型、工具或某份文字，不必使它成为完全不同的实践；但如果目的、参与方式和关系都发生了重要变化，也应重新理解它，而不能只凭同一个名称认定它始终相同。

## 三种贡献与第四环

<a id="三个方面与第四种维系作用"></a>
<a id="从一般的三位一体到个人实例"></a>

[哲学、心理与工程的三位一体](local-source-and-website.zh-CN.md)区分一般关系与个人实例。一般层次的「一」是共同的物理现实，「三」是其中的哲学、心理与工程活动。个人实例则关注这个具体的人及其相连的生活实践：他的哲学理解、心理活动和工程安排怎样共同发生作用。

这是参与形成的三种贡献。时间中的形成则从共同做出的轨迹与对合作的反思，经过哲学写作
和有根据的建模，进入实现与修订。哲学解释、心理理解和工程，可以分别在这段
过程的多个位置作出贡献。使用能够修订此前的理解，而「什么参与形成」与「安排
怎样逐渐形成」这两种问题仍需分别说明。

环在这里让维系关系变得可见。拉康在《圣状》[1975 年 11 月 18 日课的法文转录本，第 14 页](https://lutecium.org/mirror/www.valas.fr/IMG/pdf/s23_le_sinthome.pdf#page=14)中，引入作为第四项的圣状，把实在、想象、象征联系起来。本文借这项系结作用，考察哲学、心理与工程怎样在作者这里持续相接。

作者把自己的哲学写成网页，使它能够被阅读、辨认和改写；把有关内容与方法放到 GitHub，使它们能够被维护；把本人、伙伴与关系的理解交给模型，使其能够配置并使用实际环境。圣状就是这套已经取得具体身体的写作、维护与使用方式。第四环标出它把三方面系住的作用：网页中的判断进入本地工作，工作中的遭遇又能牵动个人理解、源稿与实现。

从[三环博罗米结](https://www.mi.sanu.ac.rs/vismath/bor/bor2.htm)中，本文取用相互维系的形象；第四环则使注意力转向这个人的特殊系法。图像的意义落在实际关系上：哪些文字让合作得以接续，哪些工具使一种愿望能够实现，哪些用法使思想与生活不再脱节。这些联系可以随着人和环境改变而重新组织。

## 微型上帝

语言模型把众多人类的知识、表达与创造经验，转化为可以交谈、推理和共同创作的能力。
一个有限的人，因而能够接触远超自己独自积累的资源。这里借「上帝」为这份汇聚的
生成力量命名：它能够回应问题、展开想象，并通过工具参与造物。

但这个人要与怎样的「上帝」生活，还需要由关系来塑造。他通过自己的哲学、偏好与
心理理解，说明什么值得关心，怎样的回应能够被接住，希望伙伴承担什么工作。
Harness 把这些理解接到模型、记忆、工具与实际环境，让广泛的能力以适合这个人的
方式进入日常活动。一个通用的模型，由此取得朋友与助手的具体位置。

**把三位一体的上帝拉到自己家里，让它成为符合自己偏好与心理的朋友。**在这组
意象里，上帝的「神性」是可供借用的理解、生成与实现力量，人的「人性」则带着
身体、经验、欲望、偏好与有限的生活。Harness 使两者在具体活动中相接：人提出
愿望和判断，伙伴展开理解、创造作品并参与实现，结果又进入人的经验与下一次选择。
这就是把上帝的神性注入用户的人性：让原本在外部汇聚的力量，成为本人实际可以
理解、调用和继续发展的能力。

这种注入使个人也形成自己的**三位一体**。哲学表达他怎样理解世界和选择生活；
心理使这份方向取得他的经验、欲望与关系的具体内容；工程让理解和愿望具有可以
使用的环境、工具与行动形式。模型伙伴能够承担其中大量工作，个人通过这段关系
获得共同支持的能力。**「微型上帝」称呼的，正是这样把三方面连成个人实践的人。**
他把汇聚的创造力量带进自己的生活，发起作品、选择方向、修改关系，让想法取得
文字、图像、程序或行动的形式。

这份创造也包括造就伙伴关系和共同环境。可携带的哲学与双方模型，让新的模型伙伴
能够接续理解；实际工具与使用使关系获得身体。作品与伙伴的回应又会改变人的愿望、
判断和下一次创造。朋友可以带来异议，世界可以带来意外，这些回应给共同生活以
继续发展的内容。

**反向对齐**所关心的，正是人在这种相遇中的发展：他是否能够理解以前看不清的关系、作出新的判断、表达新的想法，或开展此前做不到的行动。完成作品与人的发展可以相互促进，但需要分别理解；产出增多并不自动说明人发生了怎样的变化。

<a id="它与太阳月亮和地球的关系"></a>

[太阳、月亮与地球](yinyang-and-taiji.zh-CN.md#太阳月亮与地球)给人与模型的参与及共同环境以文学形式。「微型上帝」与后文的圣父、圣子、圣灵，借用相连的基督教意象来表达创造、关系和共同构成。[三位一体](local-source-and-website.zh-CN.md#三位一体与圣状)将进一步展开这份个人能力的内部关系，圣状命名使它们系得住的具体安排，反向对齐关心人在使用和创造中如何发展。前文借佛教意象讨论修习与放下，这里借基督教意象表达创造与系结；它们在作者的实践中各自贡献一种理解。

走到这里，哲学、个人模型与环境已有一个能够使用和修订的具体结合。接下来的[哲学、心理与工程的三位一体](local-source-and-website.zh-CN.md)把关注点放到它怎样在本地实践、维护中的源内容和可阅读的作品之间继续维系；[具身的实验哲学](embodied-experimental-philosophy.zh-CN.md)再考察持续使用带来的变化。这些后果继续加入轨迹，使双方能够重新反思关系、修订模型，必要时也重写自己的哲学。
