# 心理：材料、量表与实际帮助

模型可以寻找、审阅相关材料，整理记录，核对量表计分，并帮助准备下一步。你可以直接说：「帮我整理有关材料；如果量表有用，找合适的，让我完成，再解释结果能说明什么。」不必先写出一套关于自己的心理解释。

这页讨论证据、测量和实际帮助。学习心理学的资源见[科研与学习](research-and-learning.zh-CN.md)；哲学解释另有自己的位置。

## 寻找和保留相关材料

从眼前的困扰和希望得到的帮助开始。模型可以寻找原始研究、公开指南，以及你授权读取的相关记录，比较其中的主张，连同来源、日期和情境保留有用材料。记录或原话与后来的解释应当分开；不确定之处、相互冲突的证据也要留下。能用少量材料回答的问题，不必扩展成完整人生档案。

个人记录留在原有的私密存放处，公开页面不需要这些细节。使用 YinYang 时，理解个人心理的入口是 `personal`：你可以自己看，也可以让语言模型帮忙阅读和理解。无需把它变成自我分析的任务。六份工作描述供模型理解协作，不建议你通过重读这些描述、分析自己的幻想或辩证逆转自己的心理来获得这种理解。

<a id="questionnaires"></a>

## 选择并完成量表

量表应当服务于具体问题。可以让模型核查它测量什么、适合哪些人、由谁作答、语言版本、题目内容，以及支持当前用途的证据。[HealthMeasures 的选择指南](https://healthmeasures.net/select-measures/how-to-select/)提供了这些方面的参考。多做量表，不自动等于对一个人的理解更完整、更准确。

模型应找到实际量表与说明，核实版本和适用的获取、使用条件，说明回顾时段与局限。例如，[WHO-5](https://www.who.int/publications/m/item/WHO-UCN-MSD-MHE-2024.01)以五个自评题目了解过去两周的幸福感，并提供官方中文版。它说明一种明确的测量用途，不是人人都应先做的默认测试。

实际题目由你按说明作答。模型可以解释不熟悉的说明，但不能改变题意、从叙述猜答案或替你完成自评。不清楚或漏答的地方应保留，不用猜测补齐。

<a id="scoring"></a>

## 核对和解释分数

模型可以按准确版本的规则计算，并另行核对。[HealthMeasures 的计分指南](https://healthmeasures.net/implement/scoring/calculate-scores/)说明了量表与计分方法的重要性。反向题、缺失值、分数转换和各维度须按相应手册处理，不能随意相加。跨版本比较需要已有的可比性依据或校准说明。

在适当的私密记录中，一起保留版本、语言、作答日期、回顾时段、原始答案、缺失情况、计算过程与结果。使用 YinYang 时，把这些材料纳入 `personal`，使后续理解能够依据实际记录，而不只依赖模型的文字解释。可以让模型用简表呈现可复核的计算，解释分数方向、参照人群与解释范围。阈值及后续建议须有相应量表指导依据；一个分数，包括较低的幸福感分数，都不能确立诊断。

<a id="statistics"></a>

## 理解统计与变化

少量清楚的表格或趋势图，可以呈现变化和不确定之处。数字旁边应保留生活功能、重要事件、处境变化与相关照护。复测间隔根据量表和问题选择，不把每日追踪当成普遍要求。

[有意义的变化](https://healthmeasures.net/interpret-scores/meaningful-change/)取决于情境，也取决于讨论的是个人还是群体。一个人的多次记录不是来自人群的独立样本。时间趋势、相邻记录的关联和延续效应会影响比较；[AHRQ 的单人试验指南](https://effectivehealthcare.ahrq.gov/products/n-1-trials/research-2014-1)讨论了这些问题。普通前后对比或相关性本身不能说明变化由什么造成。模型应解释这些局限，不必把一小组个人记录做成复杂研究。

<a id="support"></a>

## 获得实际支持

可以请模型帮助处理实际困难：让活动更容易开始，调整令人负担过重的环境，查找可靠的一般身心健康信息，或整理一个可承担的下一步。帮助是否合适，要看你的实际体验；增加负担时就调整。量表结果不应自动变成训练或治疗方案。

困扰持续、加重或影响日常生活时，模型可以协助寻找当地合格的专业服务、准备就诊。材料可以包括简短时间线、当前困扰、对生活功能的影响、想问的问题，以及你选择分享的有关记录。临床评估还需考虑持续时间、功能和情境，而不只数症状，见 [NICE 的评估指南](https://www.nice.org.uk/guidance/ng222/chapter/recommendations#recognition-and-assessment)。

若有迫在眉睫的危险、严重伤害、中毒或其他紧急需要，应及时寻求当地急救或专业紧急帮助，不要等量表完成。量表不能用来决定一个人是否应获得照护或预测自杀；[NICE 的自伤指南](https://www.nice.org.uk/guidance/ng225/chapter/recommendations)明确反对风险量表的这些用途。

<a id="scope"></a>

## 明确用途与边界

模型承担大量查找、审阅、保存、计算和准备工作。答案与体验仍属于你；你可以纠正解释、拒绝量表，也可以不接受某种个人画像而直接请求实际帮助。

这些协助让证据更清楚、照护更容易取得，但不使语言模型成为临床人员，不把一组量表变成全面诊断或画像，也不证明哲学能够提供心理评估或治疗。临床评估与治疗由具备相应资质的专业人员承担。这里希望得到的是更清楚的问题、可信的记录、有用且可理解的测量结果，以及适合当前处境的下一步。
