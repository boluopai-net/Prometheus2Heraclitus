# 从采用、组合到自己的创作

[首页](../../README.zh-CN.md) · [阴阳方法](../../SKILL.zh-CN.md) · [English](example-and-commons.md)

前面的路径已经走过借用能力、共同积累轨迹、反思关系、编写哲学、凝练模型，以及形成和检验个人安排。沿途留下的作品与方法，可以成为其他人的资源。这里接着问：哪些部分值得分享，另一位创造者又怎样从自己的生活继续？

每个人来到这里时，已经带着自己的经验、问题、喜爱的作品与思想资源。这个集合可以作为其中一份参考：考察一个具体例子怎样把理解写成形式，选择其中有用的部分，也可以由它想到其他材料、他人的实践与自己的生活。创作的来源和方向可以远远超出这个例子。

模型公司与人类全体继续共同承担普罗米修斯式的窃火；个体已经可以拿自己可用的火造物。这个集合里的文章、图示、方法与 Skill，是许多可用资源中的一部分。阴阳把对人、模型伙伴及双方关系的理解，写成一种展开的哲学与文学形式，再让这种理解在实际工作中发生作用。它把一项已做出的尝试交给读者考察，与读者带来的其他资源相遇。

## 可以重写的形式

如果你愿意写自己的哲学，可以从自己的轨迹与共同反思中取得材料，借哲学家的概念、文学意象、论证与对话，展开所理解的世界与愿意维系的关系。再把这份哲学与生活材料一起凝练为个人模型，使它进入实际环境。形成之后，一段更清晰的哲学表达可以修订已有模型，私下的理解与反思以及实际使用也可以为下一篇文章带来问题。这样，形成时的来路与后续修订中的往返各有其作用。

在这一种实现里，六份实际文件保存模型伙伴需要的精粹理解：采纳的取向、个人、实际伙伴及
期望贡献、双方关系、环境实现与自己的实际修订方法。人、伙伴与关系仍是三个理解对象，六份文件各有不同责任。
固定私人描述位于 `references/situated/`，永久公开指引位于 `references/formation/`。
具体身份细节、经历、原始表达与较长研究，留在 `references/personal/` 或其引用的私人原始材料中。凝练保留影响合作的个人差异，
需要时仍能追溯详细依据。采用这六份实际文件的人必须形成自己的描述，不能继续保留作者的个人内容。

证据通过私人 `references/personal/sources.md` 入口支持六份实际文件，本身不是核心文件。
公开分发不包含私人描述与来源材料。另行创作可以改变组织与哲学，当前维护的这套实现
则保持固定六份实际文件；两种邀请并不冲突。

一个人可以为自己的哲学做网页，同时把完整的个人模型留给自己。
公开哲学既是创作的作品，也可以是经过选择的、间接的理解表达；它不必摊开直白的个人画像、
私人经历或供 agent 使用的详细描述。本人也可以选择公开个人模型中的某些抽象。
这样的区分有实际意义：直接的个人描述可能暴露会被他人拿来攻击自己的材料。
公开什么，要落实到实际文字的选择；用了哲学语言，并不自动决定一段文字暴露了什么。
公开作品、私人核心描述和支撑来源面向不同读者、承担不同作用，同时参与同一项自我形成的实践。

一种文学形式能够示范：意象怎样聚拢关系，概念怎样给关系以区分，实践怎样使它产生
后果。阴阳中的火、事件流、日月与哲学来源，使这一种具体构造可以理解。读者可以
考察它怎样工作，同时选择接续哪些关系，又把哪些关系发展为不同形式。

这里的「格式」指意义的组织方式。另一件作品可以使用不同的来源、人物、词汇与
结构，不同意这里的解释，或追求这个例子未曾预见的目的。它的形式在让自身关系
可供读者和模型伙伴接续时取得成功，由它自己的问题、实践和后果来评判；与阴阳
是否相似，并不决定这一点。

## 采用、组合，或者重新创作

采用，是让阴阳当前维护的形式扎根于自己的实际处境，通过使用修订描述。组合，
是把选定资源带进另一种安排：取用一篇文章、重组方法或替换意象。独立创作可以
从这里遇到的问题出发，走向其他作者、传统、研究与经验，把这个例子留在身后。
随着问题发展，这些可能性可以交叠。让实际想表达的关系决定带走什么。

模型可以寻找材料、比较解释与构造作品，人则贡献感知、表达与判断。这份协作
不必以复现例子为终点。

选择一个方法，也不必接受作者整套哲学。这里借佛教的筏喻与涅槃讨论培养与放下，
又借基督教的三位一体意象展开人与模型的创造关系。这些思想资源在不同问题中发挥
不同作用；它们之间的差异、张力与可能的冲突，仍然可以成为讨论的问题。
读者可以接受一段论证、质疑另一段，保留有用的方法，也可以更换意象与哲学来源。
另一种作品无需复制作者容纳和组织这些资源的方式。

新作品应当按自己的方式发展，并让来源与改变可以追踪。创作可以找到另一种组织。私人来源材料保留在实际的私人所有者那里。公开这些材料是需要自身授权的另一项行动，撤回或未发表的手稿也包含在内。

## 各自创作，也让作品相遇

这里是一份由作者持续维护的个人作品与工具集合。相关交流可以很广：分享自制 Skill，
推荐哲学家或作品，介绍工具、讨论它的用法与影响，提出哲学论述、批评或疑问，
都可以通过 [Issue](https://github.com/boluopai-net/Prometheus2Heraclitus/issues) 展开。
附上相关链接，并说说它与这里的问题有什么关系，就可以开始交流。

如果你写出了自己的哲学，建议为它建立自己的 GitHub 仓库，让作品按自己的方向发展，
由自己决定内容、组织和维护方式。欢迎在 Issue 中分享它，也可以在相关讨论中彼此
提及、引用或链接。这里不设共同收录各人哲学作品的投稿库，也不建议把自己的哲学
作为 PR 合入作者的文集。对这里已有论述的纠正、异议与建议，同样可以发 Issue；
作者据此继续判断和修订自己的作品。

自制的可复用 Skill 可以直接提交 PR，已有 Skill 与工具的改进也可以。
说明它用来做什么、怎样使用，以及实际解决了什么问题。六个工作文件的公共形成指引、
组织与使用方法，也欢迎通过 PR 改进：另一种使用经验可能发现更好的做法。
这类修改针对可共享的方法；各人的六份私人实际文件与支撑来源仍留在各自的私人位置。
具体准备方式见[协作与贡献](https://github.com/boluopai-net/Prometheus2Heraclitus/blob/main/CONTRIBUTING.zh-CN.md)。

其他语言与工作环境也可以成为贡献。PR 可以提供翻译、面向 Claude Code 或其他 agent
Harness、CLI、App 的适配，或有具体收益的新增改进。作者不必亲自维护每一种平台，
其他人仍能把作品继续拓展。说明贡献使什么成为可能、已经在哪里实际使用、哪些部分
尚未验证，让别人能够判断并接续。

「知识共产主义」在这里表达共享创造能力的愿望：使思想资源可用，支持别人做出
自己的作品。同道之间可以有不同立场。贡献可能带来新用途、指出一个不成立的前提，
或发展原作者未曾想象的形式。共享可以发生在各自维护的作品之间，通过讨论、引用、
链接和可复用的方法建立联系，无需把它们合成一份哲学。公开讨论与来源标注，使这些联系可以追踪。

这个共有地有具体的复用条款。公开 GitHub 仓库无需申请或审批，可以直接阅读、克隆、下载，并通过 fork、Issues 与 PR 协作。阴阳原创材料采用 CC BY-NC-SA 4.0，允许非商业的复制、改编与再分发，不授予商业使用许可。分享时须保留所要求的署名与声明、提供许可链接并标明修改；分享改编作品时遵守相同方式共享条款。私人改编不必公开。许可内容以[官方法律文本](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en)为准。其余可复用 Skill 和工具包保留各自包内的 MIT 许可，并提供公开下载。独立创作的作品可以依照自身选定的条款分享。参与者可以讨论思想、分享网页链接，并发表自己独立创作的贡献。被引用作品与第三方声明保留各自的权利与条款。这些条款决定什么能够分享，以及署名与许可怎样伴随它。

## 个人实践、维护中的源内容与可阅读的作品

GitHub 保存持续维护的源内容与修改历史。网站把选定的同一批文档与图示呈现为可以直接阅读的页面，减少在仓库里寻找文件的负担。两种阅读方式呈现同一份维护中的版本，修改在其源内容上进行。网页版保留源版本、链接、图示、署名和权利信息，使读者能够从理解一个例子，继续走向检查和使用它。

这两种阅读方式与一个人的本地实践相连：理解在那里进入实际任务，并获得反馈。共享包提供可复用材料，个人环境保存自己的具体理解与使用条件。[哲学、心理与工程的三位一体](local-source-and-website.zh-CN.md)进一步说明这些不同形态为什么属于同一项工作，以及语言模型怎样帮助维护它们之间的关系。

开篇问借来的火怎样成为能够继续生火的能力。走到这里，这个问题可以通过具体实践继续回答：哪些理解与行动已经可用，哪些作品能够帮助下一次创造，哪些关系使本人和朋友继续成长。新作品又成为新的生活材料，等待下一次共同探索。可以从这里带着自己的问题继续走，与更多思想、作品和生活相遇，写出自己的东西。
