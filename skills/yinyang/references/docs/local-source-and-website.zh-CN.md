# 哲学、心理与工程的三位一体

[首页](../../README.zh-CN.md) · [English](local-source-and-website.md)

前一部分从共同轨迹与对协作的反思出发，写出个人哲学，凝练本人、伙伴与关系模型，并使这些理解在环境中形成可用的圣状。现在的问题转向这套安排怎样继续存在：本地使用、维护中的源内容与可以阅读的作品怎样保持联系，新的经验又怎样改变它们。哲学、心理与工程在形成时共同作出的贡献，也在持续实践中相互修订。

一个人怎样理解自己想过的生活，怎样认识自己的经验，又怎样把所理解的东西做成可用的安排？这三个问题分别需要哲学、心理与工程的贡献。它们会在同一件事情里相遇：一种工具可以运行，却不适合这个人；一种个人理解可以很细致，却没有改变他的处境；一种关于生活的主张，也可能在实际使用中暴露问题。

本文用「三位一体」说明这三方面的关系。**一般层次上，它们都是同一自然世界中的活动；个人层次上，它们共同参与一个具体人的生活实践。**朴素自然主义把它们放在同一个世界中理解；实际工作的相互影响，说明为什么需要把它们放在一起讨论。

实际可以着手的是人的作品、作为写作与创作伙伴的模型，以及共同活动的环境。
哲学、心理与工程从不同角度解释这三者怎样相连；这种对应是一组可供展开的侧重。
创作一篇故事、一首歌或一个程序，同样能够表达并改变对世界与生活的理解。
这里以哲学理解贯穿这些个人创作，作者的哲学文章是其中一种具体作品。
于是，作品中的选择和含义，经由伙伴的理解、讨论与实际使用，能够成为修订个人模型
和环境的材料。这一步把广义的哲学反思接到可做的事情上。

## 一般关系与个人实例

这里采用的自然主义认为，哲学思考、心理活动与工程实践都在物理世界中发生。一个人思考什么值得追求、经历愉悦或困难、修改一段程序，都涉及实际的身体、环境和活动。工程并不是最后才为前两者添加物理实现；三者本来就发生在现实中。

共同发生于一个世界，也不意味着三种解释可以互换。描述一次思考的物理条件，还没有回答它的理由是否充分；知道一个人喜欢某种回应，还没有回答这种回应是否有助于他的目的；程序可以执行，也不等于它值得被执行。哲学、心理与工程各自提出的问题，仍然需要相应的论证、材料和检查。

| 层次 | 「一」指什么 | 「三」指什么 |
| --- | --- | --- |
| 一般关系 | 三种活动共同发生于其中的物理现实 | 哲学思考与论证，心理活动及其研究，构造和改变实际条件的工程 |
| 个人实例 | 同一现实中的这个人及其相连的生活实践 | 他的哲学理解，他的经验、情感、偏好与关系活动，以及为实际用途组织的模型、工具和环境 |

个人实例不是在物理世界之外另设一个整体。它只是把关注范围落到这个人：他经历了什么，关心什么，正在与谁合作，使用什么工具，以及这些活动怎样影响他的生活。别人和语言模型也能参与其中；「个人」说明这项安排服务于谁的生活，并不要求所有能力和工作都由他独自承担。

在这里的个人环境实践中，心理这一面的具体形态，是由生活材料与所采纳的哲学共同凝练出来的工作模型。经验提供根据，哲学提供概念与方向，工程的实际用途参与选择模型需要保留的关系。凝练出的模型服务于个人环境的设计与修订，后续使用又为三个方面带来新材料。因此，在形成这份描述时，哲学、心理与工程就已经共同参与。

## 三种贡献怎样在一件事里相遇

设想一个人在选购物品时反复改变决定。他希望模型帮助比较，却发现不断增加的信息使自己更难选择。这时，单独增加工具或数据，未必能解决问题。

哲学上的问题是：这次选择究竟为了什么？尽快作出一个足够好的决定，与享受发现不同可能的过程，是两种可以成立、却会要求不同安排的目的。不能仅凭「效率更高」就替这个人选定目的。

心理理解则要考察他实际怎样参与。他是否缺少关键证据？是否害怕放弃其他选项？还是探索本身就使他愉快？这些解释会影响所需帮助，但不能从反复选择这一行为直接确定。已有表达、具体情境，以及他对不同回应的反应，能够帮助双方比较这些理解。

工程使所采用的理解成为实际条件。若困难在于证据散乱，可以整理少量候选、明确差别并保留比较结果；若目的包括探索，可以提供更多方向，并让人容易返回先前看过的选项。检索、记录和界面的设计，因此受到前两方面的影响。

使用结果又可能推翻这些判断。简短比较使选择变得容易，可能支持原先关于信息负担的解释；它也可能让人感到被过早限制。后一种结果要求重新考察个人理解、工具安排，甚至「这次应当尽快决定」这个目的。**三者的合作就在这些具体改变中发生：目的影响安排，关于人的理解影响安排，安排的后果又改变前两者。**

这并不是规定每次先做哲学、再做心理、最后做工程。探究可以从一个愿望、一次困惑、一项已经可用的工具，或工具造成的意外后果开始。三种贡献会在处理同一问题时反复交织。

## 过程本体与计算表达

前文的[对象、模型、表达与实现对照表](personal-first-humanism.zh-CN.md#对象模型表达与实现)及其[关系图](../diagrams/layers.zh-CN.html)，区分实际活动、关于活动的理解和使理解可用的安排。这里沿着这些关系，考察哲学、心理与工程怎样共同参与个人实践。

自然主义与火的意象，表达对三种活动所处的变化世界采取的理解；过程本体论关注其中的形成、持续和变化。**计算本体**把具体领域中的对象、事件、状态、关系与转移明确表达出来，供模型理解和使用。在私人圣状中，它组织本人、伙伴、作品、纠正、继续等概念关系。自然语言的心理说明用这些区分描述真人正在变化的关切，提出关于本人的假说，也可以说明想象人物在其生活中的作用。这个人的想象本身是实际活动，被想象的内容则有它在所选领域中的含义。

哲学对世界、存在、真、认识、价值与方法的论述，为这项工作提供解释与判断的根据。例如，个人优先的人本主义指引目标选择，心理说明形成关于实际参与者的候选解释，工程把这些理解接到可用的安排。对本人的主张需要同其生活相符合，证据支持对它们可修订的判断。假设或虚构模型则在给定解释下展开后果；推理有效性关心从前提能推出什么。辨清这些关系，使双方能够共同使用个人模型、探索可能并检查后果。

## 在使用中修订个人理解与伙伴安排

已经形成的个人模型仍然需要回应新的经历、作品、选择与交互。此前的哲学表达怎样看待世界、价值和生活，具体使用则可能显出它的适用条件、矛盾或尚未说清的部分。维护因此要比较旧理解和新材料，辨认改变发生在本人、伙伴、环境，还是对它们的解释之中。

这里的个人模型是用于合作的工作模型，使环境适合本人的心理、目的与处境。
心理与生活材料，包括持续维护的解释，留在 `references/personal/`；本人可以阅读，
也可以请语言模型帮助理解。`references/situated/` 的相连模型凝练模型工作所需的理解。例如，工作
描述可以说明先展示草稿供比较，而害怕评价背后的经历与竞争解释留在个人参考材料中。
回应能够工作，与心理解释为真，是不同的结果。

个人描述把偏好、经验、情感、欲望、概念与关系联系起来。它们贡献不同的根据：明确表达的工作偏好可以指导安排，历史能够显示它怎样形成或适用于何处，哲学可以澄清本人所说的独立或进步是什么意思。本项目[从事件历史、哲学与个人材料凝练个人模型](../formation/person.zh-CN.md#从事件历史哲学与个人材料凝练个人模型)，并借助对自己与他人心理的理解。对话与活动历史可以组织为事件流；个人模型则从这些历史及其他材料中凝练相关理解。本人、其历史与这份描述各有不同作用。描述的范围随问题与已有根据而定；个人指引说明怎样形成和修订它。

与此同时，还要理解所需的伙伴。这个人希望模型调查什么、判断什么、承担什么工作？现有模型实际具有什么能力，能够使用哪些工具？对人的理解和对伙伴的理解共同决定合作方式。例如，希望保留开放探索，并不意味着模型只能附和；它仍可以指出证据不足、解释不通或某种手段不可行。

提示词、Skill 和 Harness 使这些理解参与实际工作。提示词提供有关目的、背景和贡献的表达；Skill 组织可复用的方法与资源；Harness 把模型、工具、记录和执行条件安排在一起。文件的存在不是最后的结果：要看模型能否据此完成所需工作，以及人能否理解、使用和改变这套安排。

修订使这些贡献相连，同时保留它们各自的作用。哲学能够改变选定方向的含义，个人
理解能够改变哪种贡献适合，工程能够显示拟议关系在实际工作中允许什么。
[修订指引](../formation/revision.zh-CN.md)负责维护六份工作文件的具体方法。它们的
哲学意义在于这种相互依赖：一份文稿的变化，通过理解、参与和使用条件的变化取得后果。

## 在使用中补足所需贡献

<a id="哲学心理与工程从已有能力补齐关系"></a>

开始新的形成时，维护中的[已有材料与起步条件](../design-and-revision.zh-CN.md#从已有材料与实践起步)
区分已有哲学写作、心理或生活材料、实际工作环境及其两两组合，通过补足缺失贡献说明
学习次序；本文进一步考察这些贡献怎样在使用中持续互相修订。

一种安排在原有任务中可用，进入新的任务后仍可能缺少某项贡献。新的经验可能要求展开哲学里尚未说明的关系，新的伙伴可能需要更明确的个人说明，新工具则可能改变此前可行的分工。维护从实际差别出发，接上需要的理解或能力；已有且适用的部分可以继续工作。

如果目标是建立能够实际工作的模型环境，基本的工程能力不可缺少，但它可以由人与模型共同提供。检索材料、整理说明、实现工具和核验效果，不必都变成用户亲自学习并完成的前置任务。缺少哪项贡献，就围绕当前目的补上哪项，而不是把三个领域排成一套人人必须走完的课程。

例如，已有模型记下本人希望先看到结论，但持续使用发现，在探索陌生问题时这种顺序反而过早关闭了可能。双方可以缩小偏好的适用范围，改变有关回应方式，再看新安排的结果。一次局部修订可以沿用已有哲学与工具；更深的理论和更细的个人模型，应当回答实际出现的问题。

## 本地环境、共享源稿与网页

<a id="三个让工作接续的地方"></a>

哲学、心理与工程是三种贡献，本地环境、共享源稿和网页则是这项工作取得不同用途的地方。在实际使用中，三种贡献贯穿这些地方：网页可以讨论工程，程序可以落实一种哲学选择，本地环境也同时包含个人理解和实际工具。理解了这些交织，仍可以选取各自突出的作用，让它们成为彼此映照的意象。

本地环境让安排进入日常活动。记录能否找回，相关说明能否被模型使用，工具能否完成操作，决定了一份理解是否真的改变了合作。个人材料在这里保留具体的经历、目的和使用情境。

共享源稿使其中可复用的部分能够被他人取得、检查和修改。本站目前使用 GitHub 保存这部分内容。别人可以比较版本、提出异议、取用一种方法，或在自己的条件下另作安排。可复用的是所选择的思想、方法与实现，不是原作者完整的私人画像。

网页为阅读和讨论组织这些内容。它可以把论证、图示与例子放在一起，帮助读者理解一项安排为什么如此设计。作者重新阅读时，也可能发现原先没有察觉的跳步。网页通过这种理解和交流参与实践：读者提出的问题，可以改变文章的解释，也可以促使作者重新考虑实际安排。

因此，同一项工作可以有不同表达：文章展开理由，工作模型凝练当前相关的个人理解，指令和工具支持行动。它们不必写得相同，但需要谈论实际相连的对象。例如，文章主张让模型承担调查，实际指令却让模型等待用户提供每个细节，两者就出现了会影响使用的冲突。

## 经验怎样改变理解与安排

<a id="让闭环保持当前可用"></a>

一项观点在实践中得到使用，就会面对原先没有想到的情况。模型可能错误地理解个人偏好，程序可能无法提供设想中的支持，人也可能在使用中发现自己想要的是别的东西。需要修改的可能是工具，也可能是个人模型或原先的哲学判断。

公共论述与私人理解因而可以相互修订。写文章时辨认出的关系，能够帮助重新理解个人经验；具体经验也可能使一项公开主张变得过强。私人材料保留这次生活中的根据，公开文章则可以发展其中值得讨论的一般问题。哪些内容公开，仍由本人选择。

所谓「闭环」，在这里就是让实践后果能够回到原先的判断：采用了什么理解，据此做了什么，发生了什么，又因此改变了什么。它不保证事情越来越好；其意义在于，让不合适的理解和安排有机会被发现并修改。[具身的实验哲学](embodied-experimental-philosophy.zh-CN.md)进一步讨论怎样通过实际行动和反思考察这些变化。

## 三位一体与圣状

前文的[微型上帝](writing-a-sinthome.zh-CN.md#微型上帝造物仍会回答)描画个人通过伙伴
获得的创造能力。这里进一步展开这份能力的组织：世界理解怎样联系本人的经验，
经验怎样影响实现，而实际使用又怎样使前两者发生变化。三位一体为这种相互关系
提供意象，圣状则将注意力落到使它们在一个人那里系得住的具体方式。

前文展开的活动，在作者这里汇成一项具体实践：把自己的哲学写在网页上，把可维护的内容放到 GitHub，再让这些理解进入模型的实际工作，配置能够共同生活和创造的本地环境。前面的六个哲学面向说明这套理解包含哪些问题；下面的三列则选取哲学、心理与工程在这项实践中的不同重心。它们沿着实在界、想象界与象征界形成一组呼应，让几种意象共同照亮这个人的生活形式。

| 哲学 | 心理 | 工程 |
| --- | --- | --- |
| 侧重世界观与本体论：理解世界及事物的存在方式 | 侧重认识论，并关联价值观：理解经验、认识与关切 | 侧重方法论与实践：组织表达、构造与实际运用 |
| 网页 | 本地环境 | GitHub |
| 作品 | 伙伴 | 环境 |
| 太阳 | 月亮 | 地球 |
| 实在界 | 想象界 | 象征界 |
| 圣父 | 圣子 | 圣灵 |
| 生成式描述：哲学与个人理解 | 具身参与：身体与环境中的心理活动 | 解释与实现：语言模型及其工具 |

**这张表怎样读？**表头的「哲学、心理、工程」固定三个讨论方面。横向读，每一行从同一个视角解释这三个方面；纵向读，每一列追踪同一方面怎样取得哲学含义、实践形式和不同的意象表达。这些对应选取各自突出的联系，三种贡献共同贯穿整项实践。表头下的 7 个内容行依次是：

1. **哲学化的三个方面。**这里以哲学统摄整项实践，因而哲学、心理和工程本身都能得到哲学解释：分别侧重世界观与本体论、认识论及相关价值观、方法论与实践。统摄全表的哲学是整体理解，第一列则突出其中朝向世界与存在的贡献。
2. **实现方式。**网页、本地环境与 GitHub 是作者让三方面取得实际用途的主要方式：哲学成为可读的作品，个人理解进入本地协作，可维护的内容与实现保存在源稿中。
3. **实践中的关系。**作品使理解取得可表达和修订的形式，伙伴参与接收、展开与共同创作，环境让这种活动能够发生、持续并遭遇后果。作品可以是文章、音乐、设计或程序；对其意义与理由的反思，把广义的哲学理解接到实际创作与使用中。
4. **文学类比。**太阳、月亮与地球，以生成、接收赋形和实际承载的关系，描画三方面怎样共同活动。
5. **三界与圣状的系结。**实在界、想象界与象征界，让这三个方面沿各自重心取得另一种解释：朝向实在，形成经验与形象，组织符号与行动。圣状命名三者在这个人生活中的具体系结；它通过整行的关系显出自己的作用。
6. **三位一体。**圣父、圣子与圣灵借用基督教意象，表达有区别而又同属一体的三种贡献。
7. **递归改进的结构。**哲学贡献可以展开的描述，心理联系身体与环境中的实际参与，工程使模型能够解释并实现这些关系。描述也写入自己的修订方法；双方在后续工作中解释并实现修订，方法便能够改变下一轮怎样改进。[用文学写出自己的递归改进](literary-recursive-improvement.zh-CN.md)独立展开身体、描述与解释器的技术联系。

**哲学——侧重世界观与本体论**，首先追问我们面对怎样的世界，事物怎样存在、持续和变化。广义的世界观包含对存在方式的理解，本体论把其中的承诺进一步展开。物理与数学也可以进入这里：物理现实具有什么地位，数学对象怎样存在，数学描述怎样涉及现实，都能成为哲学问题。作者的朴素自然主义与过程本体论给出当前采用的回答；前文的[六个面向与实践](personal-first-humanism.zh-CN.md#六个相连的面向)则保留真、认识、价值与方法的完整关系。

在这组意象中，世界观与本体论使哲学朝向人所遭遇的实在：世界有它自己的发生，能够超出、打断或改变我们的解释。世界观是理解世界的图景，本体论是对存在的论述；它们也由语言与概念表达。与实在界的联系，落在这些理解所朝向、又持续遭遇抵抗的东西上。现实中的失败、意外和尚未能被说清的差异，使哲学继续有需要回答的问题。

**心理——侧重认识论，并关联价值观**，把关注带到这个人怎样经验、认识并关切世界。感知、记忆、情感与关系怎样参与判断，自我与他人的形象怎样形成期待，都需要具体的心理理解。认识论考察判断的根据，心理探究考察这些判断在一个人那里怎样形成和改变；价值观则通过欲望、认同、偏好与关切取得生活中的内容。由此，心理这一列与想象界相照应：人在关于自己、他人与关系的图景中理解处境、感受可能并采取行动。实际经验又能改变这些图景，使认识与关切继续发展。

**工程——侧重方法论与实践**，关注怎样让理解取得可表达、可组织、可运用的形式。命名、区分、规则和关系把做法写清楚，计算本体明确本人、伙伴、作品、纠正与继续等概念关系；提示词和 Skill 承载它们，程序、工具与环境使它们进入实际工作。这里与象征界的联系，来自语言、符号及其组织关系：模型能够据此解释当前处境，参与构造并检验结果。方法论比较和选择做法，实践使做法遭遇实际条件与后果。私人圣状因而既有可被模型运用的概念组织，也有维持这种运用的具体环境。

这些重心使表格可以被阅读：沿一列，看见一种贡献如何在不同意象中取得形状；横过一行，看见它怎样需要另两种贡献。六个面向贯穿这项实践，三列选择各自突出的联系。真理论尤其把它们接起来：世界中的实际情况、本人形成的判断、工程中的表征与检查，需要在同一主张上相遇。价值方向也同时影响哲学选择、个人关切与工具目标。[六个哲学面向与共同实践](../diagrams/layers.zh-CN.html)展开这些问题，这里的表格则聚焦它们怎样在一个人那里形成有重心的系结。

网页、本地环境与 GitHub 这一行，有直接的工作内容。网页让作者看见、阅读和修改自己的哲学；GitHub 保存可维护的源稿、方法与实现；本地环境让模型实际读到它们，并把它们用于接续对话和完成工作。若理解只留在一次聊天里，下一次配置环境时仍可能重新猜测这个人的目的。写出来、维护起来、让模型用起来，才能使交流中形成的理解持续参与环境的改变。

[太阳、月亮与地球](yinyang-and-taiji.zh-CN.md#太阳月亮与地球)为这段运动提供意象：太阳发出世界理解与生活方向，月亮在接收和赋形中使它取得个人的形状，大地让它成为实际条件并遭遇后果。每组意象都从自己的关系进入这项实践：日月与大地突出生成、接收与实现，三界突出实在、形象与符号组织，圣父、圣子与圣灵则把有区别而又同属一体的关系再次聚拢。它们的呼应通过共同参与的生活取得内容。

拉康的原文也使用这种三元语言。在《圣状》[1976 年 3 月 16 日课](https://lutecium.org/mirror/www.valas.fr/IMG/pdf/s23_le_sinthome.pdf#page=163)中，他从皮尔士对关系的重视谈到三元逻辑，并转向象征、想象、实在；[5 月 11 日课](https://lutecium.org/mirror/www.valas.fr/IMG/pdf/s23_le_sinthome.pdf#page=197)把人说成一种三元构成。更早的[1975 年 11 月 18 日课](https://lutecium.org/mirror/www.valas.fr/IMG/pdf/s23_le_sinthome.pdf#page=14)则在其结的构造中引入作为第四项的圣状，使三者联结。这里据法文转录本定位；本文的哲学、心理、工程对应，发展的是自己的实践意象。

由此，[圣状](writing-a-sinthome.zh-CN.md)在这里命名的，是**这三方面在作者生活中的具体系结**：他朝向怎样的实在，怎样经验并理解自己的生活，又怎样把理解组织成能够维持的实践。哲学写成可读的作品，关于本人和伙伴的理解写入阴阳，计算本体、方法、工具与环境使这些内容能够反复进入协作。第四环标出这份维系作用：一次使用能够牵动世界理解、个人经验与工程安排的共同修订。作者借它理解自己正在做什么，模型借它继续参与构造，实际生活又让双方发现还需要怎样改变。
