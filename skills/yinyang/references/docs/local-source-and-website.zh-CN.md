# 三位一体：哲学、心理与工程的共同实践

[首页](../../README.zh-CN.md) · [English](local-source-and-website.md)

一个人怎样理解自己想过的生活，怎样认识自己的经验，又怎样把所理解的东西做成可用的安排？这三个问题分别需要哲学、心理与工程的贡献。它们会在同一件事情里相遇：一种工具可以运行，却不适合这个人；一种个人理解可以很细致，却没有改变他的处境；一种关于生活的主张，也可能在实际使用中暴露问题。

本文用「三位一体」说明这三方面的关系。**一般层次上，它们都是同一物理现实中的活动；个人层次上，它们共同参与一个具体人的生活实践。**物理上的共同基础，使它们属于同一个世界；实际工作的相互影响，说明为什么需要把它们放在一起讨论。

## 一般关系与个人实例

这里采用的自然主义认为，哲学思考、心理活动与工程实践都在物理世界中发生。一个人思考什么值得追求、经历愉悦或困难、修改一段程序，都涉及实际的身体、环境和活动。工程并不是最后才为前两者添加物理实现；三者本来就发生在现实中。

共同发生于一个世界，也不意味着三种解释可以互换。描述一次思考的物理条件，还没有回答它的理由是否充分；知道一个人喜欢某种回应，还没有回答这种回应是否有助于他的目的；程序可以执行，也不等于它值得被执行。哲学、心理与工程各自提出的问题，仍然需要相应的论证、材料和检查。

| 层次 | 「一」指什么 | 「三」指什么 |
| --- | --- | --- |
| 一般关系 | 三种活动共同发生于其中的物理现实 | 哲学思考与论证，心理活动及其研究，构造和改变实际条件的工程 |
| 个人实例 | 同一现实中的这个人及其相连的生活实践 | 他的哲学理解，他的经验、情感、偏好与关系活动，以及为实际用途组织的模型、工具和环境 |

个人实例不是在物理世界之外另设一个整体。它只是把关注范围落到这个人：他经历了什么，关心什么，正在与谁合作，使用什么工具，以及这些活动怎样影响他的生活。别人和语言模型也能参与其中；「个人」说明这项安排服务于谁的生活，并不要求所有能力和工作都由他独自承担。

## 三种贡献怎样在一件事里相遇

设想一个人在选购物品时反复改变决定。他希望模型帮助比较，却发现不断增加的信息使自己更难选择。这时，单独增加工具或数据，未必能解决问题。

哲学上的问题是：这次选择究竟为了什么？尽快作出一个足够好的决定，与享受发现不同可能的过程，是两种可以成立、却会要求不同安排的目的。不能仅凭「效率更高」就替这个人选定目的。

心理理解则要考察他实际怎样参与。他是否缺少关键证据？是否害怕放弃其他选项？还是探索本身就使他愉快？这些解释会影响所需帮助，但不能从反复选择这一行为直接确定。已有表达、具体情境，以及他对不同回应的反应，能够帮助双方比较这些理解。

工程使所采用的理解成为实际条件。若困难在于证据散乱，可以整理少量候选、明确差别并保留比较结果；若目的包括探索，可以提供更多方向，并让人容易返回先前看过的选项。检索、记录和界面的设计，因此受到前两方面的影响。

使用结果又可能推翻这些判断。简短比较使选择变得容易，可能支持原先关于信息负担的解释；它也可能让人感到被过早限制。后一种结果要求重新考察个人理解、工具安排，甚至「这次应当尽快决定」这个目的。**三者的合作就在这些具体改变中发生：目的影响安排，关于人的理解影响安排，安排的后果又改变前两者。**

这并不是规定每次先做哲学、再做心理、最后做工程。探究可以从一个愿望、一次困惑、一项已经可用的工具，或工具造成的意外后果开始。三种贡献会在处理同一问题时反复交织。

## 过程本体与计算表达

本站的过程本体论关注生成与变化：人、作品和关系怎样形成、持续并改变。它所讨论的是世界，不是一套组织文件的技术。一个人今天的选择与昨天相连，但这种连续不要求他的每个判断都保持不变。

计算本体表达的是，为某个问题从现实中选取的对象、事件、状态和关系。在前面的例子里，可以表示某次选择、看过的选项、改变决定的时点，以及当时取得了什么新信息。选择这些对象，是为了让计算机能够保存、比较或处理与问题有关的关系；它没有把人的全部经验转换成数据。

两者的联系在于如何理解被表示的事情。如果把一次改变决定只当作两条互相冲突的属性，就可能忽略它们发生于不同时间、回应不同信息。把它理解为一个过程，则需要说明前后发生了什么，又是什么发生了变化。这样的区分可以进入自然语言记录，也可以进入结构化数据或程序。

人和语言模型共同提出问题、选择需要表达的关系，并检查表达是否有用。过程本体论没有自动给出一个正确的个人模型，计算表示也没有自动解释记录中的人。它们的具体联系由所选对象、解释与使用来建立。[世界、过程与表达](world-and-expression.zh-CN.md#物理基础与计算抽象)进一步讨论这层关系，并用冷却实验说明表示、模拟和观察的区别。

## 个人理解与模型伙伴

个人哲学、经历、作品、选择与交互，可以共同参与对一个人的理解。个人哲学表达他怎样看待世界、价值和生活，也是他的实际表达；具体材料则能使这些主张受到检验，显出适用条件、矛盾或尚未说清的部分。

这种理解可以具有不同深度。偏好模型先说明他喜欢怎样的选项、回应与工作方式；心理模型进一步提出经验、情感、欲望和关系怎样影响其参与的解释。前者可以已经足够支持一项安排；后者在需要解释反复出现的困难或变化时，可能提供帮助。选择哪一种，取决于当前问题。

与此同时，还要理解所需的伙伴。这个人希望模型调查什么、判断什么、承担什么工作？现有模型实际具有什么能力，能够使用哪些工具？对人的理解和对伙伴的理解共同决定合作方式。例如，希望保留开放探索，并不意味着模型只能附和；它仍可以指出证据不足、解释不通或某种手段不可行。

提示词、Skill 和 harness 使这些理解参与实际工作。提示词提供有关目的、背景和贡献的表达；Skill 组织可复用的方法与资源；harness 把模型、工具、记录和执行条件安排在一起。文件的存在不是最后的结果：要看模型能否据此完成所需工作，以及人能否理解、使用和改变这套安排。

## 从已有能力发展实践

<a id="哲学心理与工程从已有能力补齐关系"></a>

一个人不必先掌握三个领域，才能开展这种实践。已有哲学，可以把它与具体经验对照，考察什么安排符合自己主张的生活；已有心理理解，可以尝试把它写成伙伴和工具能够使用的说明；已有工程环境，也可以从一次使用的不合返回目的和个人理解。

如果目标是建立能够实际工作的模型环境，基本的工程能力不可缺少，但它可以由人与模型共同提供。检索材料、整理说明、实现工具和核验效果，不必都变成用户亲自学习并完成的前置任务。缺少哪项贡献，就围绕当前目的补上哪项，而不是把三个领域排成一套人人必须走完的课程。

这也使实践能够从较小的已知内容开始。知道自己希望先看到结论，可以先据此调整回应；不必先解释这个偏好怎样形成。后来如果发现这一安排在某些情境里妨碍理解，再调查具体原因。更深的理论和更细的个人模型，应当回答实际出现的问题。

## 本地环境、共享源稿与网页

<a id="三个让工作接续的地方"></a>

哲学、心理与工程是三种贡献，本地环境、共享源稿和网页则是这项工作取得不同用途的地方。它们不能一一对应：网页可以讨论工程，程序可以落实一种哲学选择，本地环境也同时包含个人理解和实际工具。

本地环境让安排进入日常活动。记录能否找回，相关说明能否被模型使用，工具能否完成操作，决定了一份理解是否真的改变了合作。个人材料在这里保留具体的经历、目的和使用情境。

共享源稿使其中可复用的部分能够被他人取得、检查和修改。本站目前使用 GitHub 保存这部分内容。别人可以比较版本、提出异议、取用一种方法，或在自己的条件下另作安排。可复用的是所选择的思想、方法与实现，不是原作者完整的私人画像。

网页为阅读和讨论组织这些内容。它可以把论证、图示与例子放在一起，帮助读者理解一项安排为什么如此设计。作者重新阅读时，也可能发现原先没有察觉的跳步。网页通过这种理解和交流参与实践：读者提出的问题，可以改变文章的解释，也可以促使作者重新考虑实际安排。

因此，同一项工作可以有不同表达：文章展开理由，工作模型凝练当前相关的个人理解，指令和工具支持行动。它们不必写得相同，但需要谈论实际相连的对象。例如，文章主张让模型承担调查，实际指令却让模型等待用户提供每个细节，两者就出现了会影响使用的冲突。

## 经验怎样改变理解与安排

<a id="让闭环保持当前可用"></a>

一项观点在实践中得到使用，就会面对原先没有想到的情况。模型可能错误地理解个人偏好，程序可能无法提供设想中的支持，人也可能在使用中发现自己想要的是别的东西。需要修改的可能是工具，也可能是个人模型或原先的哲学判断。

公共论述与私人理解因而可以相互修订。写文章时辨认出的关系，能够帮助重新理解个人经验；具体经验也可能使一项公开主张变得过强。私人材料保留这次生活中的根据，公开文章则可以发展其中值得讨论的一般问题。哪些内容公开，仍由本人选择。

所谓「闭环」，在这里就是让实践后果能够回到原先的判断：采用了什么理解，据此做了什么，发生了什么，又因此改变了什么。它不保证事情越来越好；其意义在于，让不合适的理解和安排有机会被发现并修改。[具身的实验哲学](embodied-experimental-philosophy.zh-CN.md)进一步讨论怎样通过实际行动和反思考察这些变化。

## 三位一体与圣状

三位一体说明哲学、心理与工程如何共同参与实践；[圣状的形成](writing-a-sinthome.zh-CN.md)则命名它们在一个人这里共同塑成的具体安排：对本人、模型伙伴与双方关系的理解，以及使这种合作得以进行的表达、工具和使用方式。

两篇的对象由此相连。一般关系在这个人的生活中取得具体内容；具体安排又能改变他的理解、体验和工作条件。它的个人性来自所服务的生活、所依据的材料和实际参与，而不只是文件上写了某个人的名字。

哲学、心理与工程既有各自的问题，也能够改变彼此的工作。把它们放在一起，是为了让关于生活的理解与实际生活发生联系：一项主张可以影响行动，一次经验可以改变判断，一种实现可以使此前做不到的事情成为可能。
