# 科研与学习

**大部分时候关注全局与整体，少部分时候深入熟悉重点与细节，并知道什么时候应当检验它们。**学习先把握一个领域的问题、概念与关系，形成整体感，再按需要深入局部。优先学「最泛」的东西，也就是能够跨具体任务使用的理解和方法。

设计就是一个例子：判断要做什么、为什么做、怎样组织整体，以及什么结果才算合适。AI 承担实现后，人可以把主要学习精力放在这些问题上。设计两次甚至多次，是提出和比较不同方案，必要时重新考虑问题、前提和评价标准。更进一步，连组织实践与反思的框架本身也可以改变；这就是这里所说的[在当前双环之外推理](https://boluopai.net/philosophy/embodied-experimental-philosophy/)。

## 1. 从兴趣到课程、资源与笔记

### 探索兴趣，比较培养方案

从一个感兴趣的方向开始，例如「人因」。和 AI 聊聊自己更想理解人的认知、人与机器的配合，还是产品和工作环境的设计，用具体问题逐渐明确方向。

让 AI 搜索国内哪些学校在相关方向上比较有积累，查找**近几年的硕士培养方案和相应招生专业的考研参考书目**。人因相关内容也可能以工效学、工程心理学、人机交互等名称出现，应结合实际研究团队和课程判断。提取课程、主要内容、先修要求与书籍，保留学校、院系、年份和原始链接。

如果不同学校分别偏工程、心理或设计，或者设在计算机、心理、人工智能、设计等不同院系，就选几份有代表性的方案，让 AI 解释它们各自关注什么问题、重视哪些知识与方法。

### 以一个方案为主，组合课程体系

让 AI 根据你感兴趣的问题、对课程的反应和想做的事情，判断哪个方案最适合，并说明理由，供你选择或修正。**以最感兴趣的方案为主，用其他方案查漏补缺**：合并重复课程，补足基础与方法，安排先修顺序，区分核心课和按兴趣深入的课。最终得到一套有主线的课程体系，每门课都能说明为什么学、与其他课有什么联系。

### 找到对应资源，下载整理

拿着课程体系，主要寻找**主题或课名对应的国外网课，并选择最新的可获得版本**。核对课程大纲和授课年份；名称不同但内容相近时说明对应关系，只有旧版时注明版本。国内考研参考书，以及培养方案或课程材料提到的书籍，也可以一起寻找。

让模型下载找到的全部可获取资源，包括视频、讲义、课件、字幕、作业、代码和书籍，按课程整理并检查完整性。模型无法完成的下载，列出材料、原始链接和原因，由本人手动补齐。目录中标明哪些已下载、哪些只有在线入口、哪些仍待补齐。

### 让 Dot 用 Teacher Skill 准备笔记

把课程体系和资料交给 **Dot**，让它使用 **Teacher Skill** 写学习笔记：按课程解释概念与关系，配上术语表、例子和必要图示，保留原始章节、讲次或页码，并给出清楚的阅读入口。

需要训练材料时，可以先按课程整体范围准备题目、解答与评估依据，核对答案并把题目和解答分开保存。这样以后有材料可选，不要求现在就全部练习。**资料和笔记先备好，心情好、想学的时候再打开。**

## 2. 开始学习，按需要深入

平时通过阅读、图示、讨论和实际例子理解整体，让老师帮助连接新旧知识、比较不同解释。遇到不熟悉的术语，可以随时查回；不必每次都中断阅读，把所有细节彻底学完。

### 什么时候需要检验重点与细节

当一个细节可能改变整体判断、结果与预期不符、理解出现矛盾，或准备把方法用到新情境时，就回到相关概念、条件与证据。先和老师判断究竟卡在哪里，再用例子、反例、推演或实验检查。例如，从相关关系走向因果解释时，需要弄清多加了什么假设，以及证据是否支持它。

**实际练习应删去预备材料中的大部分，只留下当前真正必要的极少数关键点。**对这些点，增加图示、具体例子和小步练习，必要时反复做、换情境再检验，直到足以支持眼前的理解与判断，然后返回整体。未选中的材料仍可保留，遗忘或以后需要时再取用。

练习帮助形成理解；测试提供表现证据；评估则据此决定哪里还需改进。解释、回应反例和实际作品也能提供证据，不必都变成考试。判断个人理解时，要区分自己完成的部分和模型提供的帮助；一次答对或模型产出正确答案，都不能单独证明自己已经掌握。

### 科研还需要检验成果

学习可以为了兴趣和理解世界，不必服务于科研；科研则围绕尚未解决的问题形成可论证、可检验的成果，并在过程中继续学习。**个人理解与研究成果的可靠性要分别判断。**让模型回到原始来源核对引文与主张，检查论证前提、计算和代码，并用不同方法、反例或重现结果交叉核验。人需要看懂关键假设、证据与局限，判断成果是否回答了问题；发现知识缺口时，再回到相应课程。

## 3. 选择一个方便使用的老师

| 老师 | 使用侧重 |
| --- | --- |
| [本地老师（Local Teacher）](https://github.com/boluopai-net/Prometheus2Heraclitus/tree/main/skills/local-teacher) | 在本地 Codex 中读教材与论文、复习，也能结合文件、代码和实验边学边做。 |
| [云端老师（Web Teacher）](https://github.com/boluopai-net/Prometheus2Heraclitus/tree/main/skills/web-teacher) | 在 Web 对话中探究问题、比较理解、探索相邻知识，并组织课程材料与学习接续。 |

两者共享教学方法，可以从当前方便的入口开始。直接说「带我读这篇论文」「解释这个概念与我原来理解的关系」或「帮我讨论这个研究想法」即可。老师也可以调用下面的学科资料与科研方法；下载、安装、连接和具体选用交给模型。通用工具与文件安排见[工具使用](https://boluopai.net/getting-started/)。

## 4. 补充学科参考与科研方法

把这两个资源库交给模型，让它下载并接入教学与研究环境：

| 资源库 | 用途 |
| --- | --- |
| [K-Dense Scientific Agents](https://github.com/K-Dense-AI/scientific-agents) | 不同学科的专家思考资料，给概念解释和跨学科讨论提供专业参考。 |
| [K-Dense Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) | 文献检索、实验设计、统计分析、机器学习、科学绘图和引用管理等科研方法。 |

前者补充学科理解，后者支持具体工作。老师按问题选择有用的部分，你不必逐个阅读专家文件或指挥工具调用。

## 5. 论文写作与发表

需要读论文、发展论证或准备投稿时，可以让模型取用这些公开方法：

| 仓库 | 用途 |
| --- | --- |
| [Academic Writing Skills](https://github.com/WenyuChiou/academic-writing-skills) | 发展论证、组织文章和修订稿件。 |
| [Research Hub](https://github.com/WenyuChiou/research-hub) | 用文献比较矩阵并列研究问题、方法、发现与局限。 |
| [Paper Lifecycle](https://github.com/M1n-n9/paper-lifecycle) | 理解审稿意见、组织修订并说明回应。 |
| [Academic Publishing Skills](https://github.com/yaotingsun/academic-publishing-skills) | 选刊、投稿信、修回回应与校样检查。 |

采用其中的方法，不等于启用整个仓库附带的服务；模型根据实际写作问题选取和连接即可。
