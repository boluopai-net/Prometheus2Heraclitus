# Source owners and provenance

This distributed copy provides writing guidance. The situated version is a
small navigable index of what grounds the core accounts and where to check a
claim: attributable user input, selected originals, and precise source notes
under [personal](personal/README.md). Personal records, chats, memory notes,
authored philosophy, and observed work can contribute in different ways.

Preserve author, time, message identity, and coverage needed to assess
attribution, distinguishing original expression from later interpretation.
Keep raw records with their existing owners; detailed histories, excerpts,
provenance, and private detail belong there or in topical notes. Link rather
than duplicate them or the common philosophy. Public bibliography stays with
the common essays. State unknown or inaccessible evidence explicitly instead
of inventing support to make the accounts look complete.
