# Read by the work being done

For the collection's invitation to adopt, combine, or write a different
philosophy and form, read [Begin with this example, and make something of your own](docs/example-and-commons.md).
The following routes describe the maintained YinYang example.

For ordinary work, the main conversational model reads the common
[entrypoint](../SKILL.md), [encounter](encounter.md), [user model](models.md),
[counterpart and relationship](relationship.md), [situated use](usage.md), and
[source index](sources.md) completely, reusing current readings. These five
accounts are the primary working model. Follow their links into philosophy or
[private provenance and materials](personal/README.md) when the question needs depth.
When authoring philosophy or its website, give the affected argument and page
the sustained attention that task needs, then carry supported changes back to
the core accounts; do not substitute the core summary for the work itself.
These are formation guides in the distributed package and actual grounded
accounts in the situated package, at the same paths.

For formation or revision, read [design and revision](design-and-revision.md).
For changes to the actual environment, read
[harness adaptation](harness-adaptation.md) with the affected personal passages
and target. The common methods and resources remain the same in both packages.

This package's essays develop the cultural and philosophical background.

For a first conceptual reading, follow purpose → core views → creation method,
then consult the other texts where the question needs them. Formation begins
with the usable method and actual materials; it need not wait for completion
of a philosophical syllabus. The Sun–Moon–Earth relation belongs within the
YinYang and Taiji image; it is not an independent theoretical prerequisite.

These links resolve within the complete YinYang directory. Keep its `references/docs/`
and `references/diagrams/` resources with the entrypoint and references when distributing
the package; identify any missing material rather than claiming to have read it.
The common map remains here; the private index in
`personal/README.md` routes to provenance and private supporting materials,
without duplicating the common philosophical accounts.
