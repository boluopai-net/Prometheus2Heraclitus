## 本包提供什么

阴阳帮助一个人发展自己的哲学，并通过写作和实践凝练个人模型。模型可以贡献探索、
创作、实现和纠正；当事人不必从完成的哲学或自我画像开始。共同思想、私人理解与实际
工作可以一起发展。

作者选择的目的是**反向对齐**：人在与生成智能的相遇中发展理解、生成和行动。agent 对人的
适配支持这种发展。双方模型都重要：服务谁的什么目的，以及这个伙伴能够理解、贡献、
质疑和承担什么。选定角色不穷尽任一参与者，也不确立相同的机制和内在体验。

阴阳是一项承载**元 harness** 的 Skill，即理解和修订实际提示词、Skills、角色、工具与
环境的哲学和关系框架。记忆可以保留证据，模型组织其关系与可能后果；专门的 Skills
保有自己的方法。[哲学、心理与工程的三位一体](references/docs/local-source-and-website.zh-CN.md)把哲学、
心理与工程连接在同一物理现实之中，同时区分各自的解释与实践工作。

它连同自己的文学形式，是一项已经展开的范例。你可以采用、组合资源，也可以创作
概念、意象与组织方式都不同的作品。
[从采用、组合到自己的创作](references/docs/example-and-commons.zh-CN.md)说明这份邀请。
维护这套实现与创作另一部作品，是不同选择；固定文件路径适用于前者。

本目录是 **Prometheus2Heraclitus** 集合中完整的阴阳成员。文章和图示是配套资源，
不是独立 Skills；集合的其他成员保有各自的目的和方法。

## 怎样使用并理解阴阳

可以为哲学问题阅读论证，为具体任务取用形成或适配方法，也可以完整采用持续维护的 Skill。
这些用途能够重叠，不是每个人都要经过的阶段。取用方法不要求写个人哲学、采用作者的
本体论或意象，也不要求形成持续维护的情境化版本所需的六份实际文件。

完整采用时，通过实际 Skill 机制把完整包交给模型。模型根据相关、获授权的材料形成或
修订描述，在目的需要时实现工作环境。模型承担有根据的写作、调查、判断和实现；
当事人贡献模型无法取得的经验、目的与决定。下载指引本身并不形成个人关系。

按当前问题选择入口：

| 目的 | 入口 |
| --- | --- |
| 理解形成与使用自己的阴阳这项实践 | [实践说明](references/docs/creation-method.zh-CN.md)。 |
| 理解哲学与个人模型怎样相接 | [哲学与模型](references/design-and-revision.zh-CN.md)，通向六份文件的写作指导。 |
| 让六份文件在日常协作中发挥作用 | [使用阴阳](SKILL.zh-CN.md)，包含初始阅读约定与使用路径。 |

文件与更新见[包结构说明](references/docs/skill-package.zh-CN.md)，论证与来源见[阅读地图](references/reading-map.zh-CN.md)。

这套包区分**六份公开「如何写」指南**与**六份私人实际文件**。两组对应取向、个人、模型伙伴、
关系、环境与修订。指南位于 `references/formation/`，说明怎样写出位于
`references/situated/` 的对应实际文件。修订也有同样区分：[如何修订](references/formation/revision.zh-CN.md)
帮助使用者在 `references/situated/revision.md` 写出自己的实际修订方法。

完整采用时，形成并读取全部六份实际文件。公开分发提供六份指南，不提供某个人的实际内容。
人、伙伴与关系仍是三个建模对象，其他文件分别阐明方向、实现与修订。相关私人证据通过
`references/personal/sources.md` 取得，原件保留在既有维护者处。包结构说明解释路径与共同更新。

形成可以从哲学、个人经验、偏好、实际工作或待修订环境开始。工程尚不可用时，借助模型
建立可用基础，让文件、工具、执行和核验能够支持工作。已有环境可以为个人建模提供线索，
但默认值和限制也能解释安排。设计参考展开这些条件性路径，不要求先精通三门学科或
完成画像再创制。

可以保留六份实际文件结构而替换哲学，也可以重新组织作品。哲学家的思想可以提供框架，
不能代替实际用户的描述。独立改写的哲学保留在自己的来源处，不接受公共文件投影覆盖。
选择跟随本仓库公共更新的副本，则保持公共内容字节一致，同时保留私人描述。

## 哲学基础

作者的世界观以同一变化的物理现实为基础，用当代火一元论表达其生成；过程本体论
关注对象怎样形成、持续与变化。计算本体明确表达选定领域中的对象、事件、状态、
关系与转移，供模型解释、推理和使用。在私人圣状中，自然语言可以组织本人、伙伴、
作品与合作过程，形成可被模型使用的概念关系。它可以表征
实际的人与心理活动、假设情境，也可以表征虚构对象。物理基础关乎表征活动及其载体，
所表征的内容则有各自的存在地位。人和语言模型共同发展问题、模型、实现与反馈，按实际能力与目的
分工。表征需要可使用的含义；事实主张的真在于符合实际情况，表征中的满足与推理则
依赖其解释和前提。由模型解释的清楚自然语言可以服务于这些使用。
[世界篇](references/docs/world-and-expression.zh-CN.md)展开这层联系。活动历史可以表征为
事件流，关于人与伙伴的概念模型则从这些历史与其他材料中构造。参与者保有各自的
能力与机制。融贯的工作概念支持稳定，证据与竞争解释则仍向纠正开放。

日月表达有区别的生成、接收与赋形。人与模型参与这些运动，可以保留或交换侧重；
地球是能够回应的物质环境与共同生活环境。模型公司、研究者与更广泛的集体继续窃火，
有限的人借火，通过实践培养理解、判断与生成。小火人强调能够继续生火，赫拉克利特宝宝强调
这个生成者自己也仍在变化，其中的可能也会冲突。能力可以内化，也可以由可靠条件支持；使用 AI、意见一致和产出本身，都不确立成长。
文章在各自尺度展开这些意象与主张。

## 维护与贡献

[MODEL.md](MODEL.md)维护解释与发布边界，[AGENTS.md](AGENTS.md)是维护入口。
英文读者文本有完整中文对应。公共材料在共享源维护，情境化描述在实际私人位置维护。

通过 [Issues](https://github.com/boluopai-net/Prometheus2Heraclitus/issues) 分享相关内容、讨论哲学。
自制的可复用 Skill、工具改进、翻译、其他 Harness 或 App 适配，以及六个工作文件的公共指引或使用方法，可以提
[PR](https://github.com/boluopai-net/Prometheus2Heraclitus/pulls)。自己的哲学放在自己的仓库，欢迎分享链接。
[创作邀请](references/docs/example-and-commons.zh-CN.md#各自创作也让作品相遇)说明这些参与方式。
个人记录、形式化画像、私人引文和未发表手稿都不进入公开分发。
