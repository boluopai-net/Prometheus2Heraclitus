# 阴阳形成 Skill

**写出哲学，为人及其 agent 伙伴形成有根据的模型，让双方协作取得可用的工作环境。**

[English](README.md) · [阴阳方法](SKILL.zh-CN.md) · [模型执行入口](SKILL.md) ·
[文档与图示](https://boluopai.net/repositories/prometheus/)

## 本包提供什么

阴阳帮助一个人发展自己的哲学，并通过写作和实践凝练个人模型。模型可以贡献探索、
创作、实现和纠正；当事人不必从完成的哲学或自我画像开始。共同思想、私人理解与实际
工作可以一起发展。

它的目的是**反向对齐**：人在与生成智能的相遇中发展理解、生成和行动。agent 对人的
适配支持这种发展。双方模型都重要：服务谁的什么目的，以及这个伙伴能够理解、贡献、
质疑和承担什么。选定角色不穷尽任一参与者，也不确立相同的机制和内在体验。

阴阳是一项承载**元 harness** 的 Skill，即理解和修订实际提示词、Skills、角色、工具与
环境的哲学和关系框架。记忆可以保留证据，模型组织其关系与可能后果；专门的 Skills
保有自己的方法。[三位一体](references/docs/local-source-and-website.zh-CN.md)把哲学、
心理与工程连接在同一物理现实之中，同时区分各自的解释与实践工作。

它连同自己的文学形式，是一项已经展开的范例。你可以采用、组合资源，也可以创作
概念、意象与组织方式都不同的作品。
[从这个例子开始，写出自己的东西](references/docs/example-and-commons.zh-CN.md)说明这份邀请。
维护这套实现与创作另一部作品，是不同选择；固定文件路径适用于前者。

本目录是 **Prometheus2Heraclitus** 集合中完整的阴阳成员。文章和图示是配套资源，
不是独立 Skills；集合的其他成员保有各自的目的和方法。

## 怎样使用并理解阴阳

通过实际 Skill 机制把完整包交给模型，请它根据相关、获授权的材料形成或修订你的
个人哲学。目的包含环境适配时，也应取得相应的工作成果。模型承担写作和实现；
下载包得到的是指引，并非现成的个人关系。

按当前问题选择入口：

| 目的 | 入口 |
| --- | --- |
| 参与日常协作 | [SKILL.md](SKILL.md) 维护初始阅读约定与路径；另有[中文阅读版](SKILL.zh-CN.md)。 |
| 形成或修订相连的个人描述 | [形成与修订](references/design-and-revision.zh-CN.md)。 |
| 改变实际环境的运作方式 | [环境适配](references/harness-adaptation.zh-CN.md)。 |
| 理解文件、个人内容与公共更新 | [包结构说明](references/docs/skill-package.zh-CN.md)。 |
| 探索论证或来源 | [阅读地图](references/reading-map.zh-CN.md)。 |

这套实现的五份情境化描述分别说明相遇、人、伙伴与关系、实际使用和证据维护者。
分发指引应在私人情境化版本中成为有根据的描述，他人画像和虚构替代不能提供这些内容。
未知处应如实说明。私人支撑材料跟随实际证据，适合时让原件留在已有维护位置。
包结构说明提供准确路径、完成证据和同步命令。

形成可以从哲学、个人经验、偏好、实际工作或待修订环境开始。工程尚不可用时，借助模型
建立可用基础，让文件、工具、执行和核验能够支持工作。已有环境可以为个人建模提供线索，
但默认值和限制也能解释安排。设计参考展开这些条件性路径，不要求先精通三门学科或
完成画像再创制。

可以保留五份文件结构而替换哲学，也可以重新组织作品。哲学家的思想可以提供框架，
不能代替实际用户的描述。独立改写的哲学保留在自己的来源处，不接受公共文件投影覆盖。
选择跟随本仓库公共更新的副本，则保持公共内容字节一致，同时保留私人描述。

## 哲学基础

框架从同一变化的物理现实出发，以当代火一元论的过程本体论阐明它。工程本体则给
选定过程以计算模型：持续的对象、状态、关系、约束与变化，使计算机能够表示，
并在有用时模拟。人和语言模型共同发展问题、模型、实现与反馈，按实际能力与目的
分工。表示需要可使用的含义及与观察的对应，由模型解释的清楚自然语言可以服务于这种
使用。[世界篇](references/docs/world-and-expression.zh-CN.md)展开这层联系。相互作用
的事件流并不意味相同机制。融贯的工作概念支持稳定，证据与竞争解释则仍向纠正开放。

日月表达有区别的生成、接收与赋形。人与模型参与这些运动，可以保留或交换侧重；
地球是能够回应的物质环境与共同生活环境。模型公司、研究者与更广泛的集体继续窃火，
有限的人借火，通过实践培养理解、判断与生成。小火人强调能够继续生火，赫拉克利特宝宝强调
这个生成者自己也仍在变化，其中的可能也会冲突。能力可以内化，也可以由可靠条件支持；使用 AI、意见一致和产出本身，都不确立成长。
文章在各自尺度展开这些意象与主张。
