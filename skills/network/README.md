# network

Diagnose connected request paths and repair through real owners, with configured proxy scans and profile recovery.

[中文说明](README.zh-CN.md) · [Model instructions](SKILL.md)

Download **clash-auto-switch** as a required companion for its controller/switch/guard methods. The actual mutex and profile recovery implementation are included. Recipient baselines, Colima and runtime configuration remain external inputs.

Install PyYAML into your chosen Python environment. Copy the two JSON templates, replace all paths, then run scripts/proxy-purity --config /absolute/proxy.json check-config and scripts/network-repair --config /absolute/repair.json --files-only status. Help is available before configuration.

Set colima_profile to your existing named Colima VM; the scanner never chooses an author's or implicit default profile. The shipped value recipient-profile is a placeholder.

Download the **complete directory** from this repository or GitHub's native archive, preserving scripts and executable modes. Relative resources and companion relationships are part of the package. There are no personal accounts, subscriptions, vault lists, credentials or host defaults to inherit. Configure your own real targets; a downloaded method is not proof of a configured runtime service.
