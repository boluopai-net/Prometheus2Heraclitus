# Local attention-path binding

Resolve `local_learning_path` through [recipient configuration](configuration.md)
to the recipient's maintained current attention map. This package supplies no
current course order, learner history or execution task. Preserve an existing
owner/name instead of creating a parallel route.

This record selects which accepted relation, course depth or project encounter
to enter now, what question motivates it and where to return. It consumes the
[global path](learning-path.md) and relevant Global/Course State but is neither
the stable target nor evidence of arrival, mastery or completed execution.
Keep its attention selection distinct from the course guide's source progression
and the actual project's execution records.

Inspect affected cards, sources and recovery evidence before a bounded repair;
retain the current question, return condition and material unresolved choice.
Read back a permitted saved change at the actual owner. A teacher's local
teaching move does not automatically become a durable path edge. If no attention
map is configured, use the current task's supported scope without claiming a
whole route or silently creating one.
