# web-teacher

Explore unsettled questions and teach from actual sources. This package owns
the full shared Web/Local Course method: teaching, philosophical text study,
conceptual and chronological maps, recursive traversal, material preparation,
technical training, course workspaces, path governance and evidence-bounded
recovery State. The exact identifier is `web-teacher`.

Web and Local are complementary emphases, not exclusive theory/practice roles.
Web usually broadens models and adjacent possibilities; Local usually sustains
lessons and actual project work. Both retain the same conceptual depth. The
teacher carries source recovery, formal reasoning and checked details while
supporting worthwhile learner intuitions, objections, predictions and revisions.
Keep the whole intelligible through maps and connected explanations; open its
needed relations using words, diagrams, notation, concrete cases or operations.

Examples: “Compare these explanations and what would distinguish them”; “Teach
this philosopher's later problem and recover the earlier concepts it changes”;
“Prepare the selected book's glossary and connected argument/research guide”;
“Resume from the actual source and evidenced State without testing mastery first.”

Install the complete sibling directories in the host's supported Skill location
or upload/register them together through its actual package mechanism. Load
[SKILL.md](SKILL.md) and the branch selected by the work. The optional compatible
interface manifest is `agents/openai.yaml`; no provider, connector, CLI, account
or coordination service is hardwired into the teaching method. A host must
actually expose source/file tools before the teacher can inspect or save records.
Without writes, an explanation or exact unsaved proposal remains possible, but
the teacher cannot claim persistence. Local execution follows its project owner.

Use [recipient configuration](references/configuration.md) for actual corpus,
language, reading surface, global/local paths, work plan and Global/Course State.
The three bundled path files are reference slots with ownership instructions;
they contain no example recipient goals or history. Existing records remain
at their owner. Obsidian Markdown is the source method's documented reading
profile; optional [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus) enables
exact selection/highlight/backlink checks. Ordinary source locators and math
remain usable without it, with unavailable checks stated explicitly. No package
install supplies a corpus, current learner profile, access grant or progress.

The source method is preserved rather than compressed into a generic tutor:
philosophy keeps per-book glossary plus argument/research guide, historical study
writes chronologically and teaches recursively across units, technical study
keeps distinct written and experimental training, and State distinguishes
prepared support, exposure, learner contributions and untested understanding.
Private path bodies were not read or copied; private research-direction history,
host mappings and personal course exceptions were replaced with recipient bindings.
Original package material is [MIT licensed](LICENSE); companions, Obsidian/PDF++
and supplied sources retain their own rights. No third-party code is bundled.

## 中文说明

本包从实际来源教学并探究未定问题，拥有 Web／Local 共用的完整 Course 方法：
教学、哲学文本研究、概念和时间结构、递归讲解、材料准备、技术训练、课程工作区、
路径治理和有证据边界的接续 State。准确标识为 `web-teacher`。

Web 和 Local 是互补侧重，不是理论／实践的排他分工：Web 通常拓展模型和邻近
可能性，Local 通常承担持续教学与实际项目工作，两者保留相同概念深度。Teacher
承担来源恢复、形式推理和细节核查，支持有价值的直觉、质疑、预测和修正。用概念图
和连贯讲解保留整体，再用语言、图示、符号、具体情境或操作打开需要理解的关系。

示例：“比较这些解释及区分它们的证据”；“从这位哲学家的后期问题恢复它改变的
早期概念”；“准备选定书籍的术语表与连贯的论证／研究指南”；
“从实际来源和有证据的 State 接续，不先以掌握测试阻挡讲解”。

把完整包作为同级目录安装到宿主支持的位置，或通过宿主真实的包机制一同上传／
注册。加载 [SKILL.md](SKILL.md) 及任务所需分支；兼容宿主可使用
`agents/openai.yaml`。方法没有固定的服务商、连接器、CLI、账号或协调服务。
宿主确实提供来源／文件工具后才能检查或保存记录；不能写入时仍可讲解或给出准确的
未保存建议，但不能宣称持久化。实际本地执行仍受项目负责人和权限约束。

按 [接收方配置](references/configuration.md) 绑定真实材料库、语言、阅读界面、
整体／局部路径、工作计划与 Global／Course State。三个路径文件是保留职责的
引用槽，不含接收方目标或历史；现有记录留在其原有负责人处。Obsidian Markdown
是源方法记录的阅读配置，可选 [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus)
支持精确选择、高亮与反向链接验证。不安装时仍可使用普通来源位置与公式，但需说明
无法完成的验证。安装包不提供材料库、当前学习者画像、访问授权或进度。

保留方法深度：哲学使用每本书的术语表及论证／研究指南；历史研究按时间书写、跨单元
递归讲解；技术学习区分书面训练与实验；State 区分准备、接触、学习者贡献和未验证
理解。私人路径正文未读取或复制；私人研究方向历史、主机映射和个人课程例外改为
接收方绑定。原创内容采用 [MIT 许可](LICENSE)，配套包、Obsidian／PDF++ 和提供的
来源保留各自权利，本包不附第三方代码。
