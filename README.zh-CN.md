# Prometheus2Heraclitus · 从普罗米修斯到赫拉克利特

**一套辅助个人进行递归自我改进（RSI）的哲学，以及使它进入实践的模型、方法与工具。**

阴阳展开这项工作的哲学：人与生成式模型及支持环境共同改善理解、判断、创造与行动，
也改善产生这些改进的方法。可读的描述让目的、关系与修订方式成为能够考察的对象；
共同工作使它们获得实际形式，后果再返回并改变它们。发展的中心是这个人及其实际支持关系，
其价值由他希望维系的生活与活动来判断。

文章展开论证，可复用的 Skills 与工具支持实现，并保有各自的专门用途。
可以从[窃火](skills/yinyang/references/docs/stealing-fire.zh-CN.md)开始，
选读[基本观点](skills/yinyang/references/docs/core-views.zh-CN.md)，
或通过[递归改进一章](skills/yinyang/references/docs/literary-recursive-improvement.zh-CN.md)
理解描述、解释、实践与方法改变之间的联系。

[网站首页](https://boluopai.net/) · [文档与图示](https://boluopai.net/repositories/prometheus/) · [English](README.md)

阴阳阅读版：[下载中文 PDF](https://boluopai.net/reading/yinyang.zh-CN.pdf) · [Download English PDF](https://boluopai.net/reading/yinyang.en.pdf)。适合离线阅读与批注，含可点击目录、章节跳转和图示。

## 用途与心理健康说明

阴阳的哲学观点用于配置适合人与模型协作的个人环境，包括协作方式、指令和工具。对个人的理解可以为配置提供依据；这套哲学不提供修订心理材料的方法。

阴阳不能用于心理自助工作、自行诊断、心理健康评估或治疗，也尚未经过针对这些用途的系统性实证评估。需要专业评估或照护时，应寻求合格专业人员；项目文字与模型输出不替代这种服务。作品、模型与处境会变化，个人经验或版本历史也不能确立普遍的心理效果。

独立的[心理页](skills/yinyang/references/docs/psychological-support.zh-CN.md)说明模型如何协助个人材料、量表、计分、统计和实际帮助，保留各自的证据与专业照护边界。这不从哲学推出心理练习，也不把工作描述变成自我分析课程。

## 选择怎样阅读与使用

**非文史哲背景的读者，可以先从[核心观点](skills/yinyang/references/docs/core-views.zh-CN.md)中挑选与自己问题有关的部分。**
了解它们的理由与适用条件，再考虑用来配置符合自身目的与条件的个人环境。
想进一步理解论证时，再沿链接阅读相应文章；不必通读全书或接受全部立场。

是否写自己的哲学、文章或个人网站，取决于兴趣。你可以取用观点、维护环境，
而不另开一个写作项目；愿意写时，[例子与知识共有地](skills/yinyang/references/docs/example-and-commons.zh-CN.md)
提供这条创作路径。实际起步可沿[工具使用](https://boluopai.net/getting-started/)。

完整采用阴阳 Skill 时，保留取向、人、伙伴、关系、环境与修订六个完整功能问题。简单路线由模型直接
综合原有六份实际文件，并将需要保存的私人源持久放在 Git 与私人 GitHub 仓库，不要求安装 Hindsight。
[可选原生实现](skills/yinyang/references/hindsight.zh-CN.md)为相同问题、步骤与融贯整体配置 Hindsight，
不把六者换成较少原型分组。Full/Empty 版本选择独立于工具路线。Personal 保留可读主题文章与原始来源，
是否另写原创哲学仍由兴趣决定。

[个人模型的凝练指引](skills/yinyang/references/formation/person.zh-CN.md#从事件历史哲学与个人材料凝练个人模型)
展开这些材料怎样成为本人、所需模型伙伴及双方关系的描述，再让共同工作进入现实，
由实际后果继续修订理解。记忆保留材料和来路；凝练组织有关意义、条件与关系，
使已有理解能够参与下一次判断和行动。

哲学在这里是可继续书写的整体。文学、历史、美学、计算机与工程都可以成为理解与凝练的材料；
不同观点可以保留、比较或组合，不要求先加入同一学派。容纳冲突仍需区分保留的材料、
当前采用的理解及其后果。具体方法和工具给这份理解以可用形式；另一个人也可以
由此写出完全不同的哲学与环境。

[文档与图示](https://boluopai.net/repositories/prometheus/)直接呈现持续维护的文档与图示，
并保留通往源内容的链接。

## 哲学、心理与工程：从已有能力补齐三位一体

**哲学展开理解与方向，心理理解具体的人，工程让关系成为可用环境。**三方面相互支撑。
从已有材料与实践进入，发展缺失贡献，不要求当事人先独立修完三门学科。

**缺少可用工程环境时，与模型共同建立它。**文件、检索、工具、执行与核验，使形成与
持续使用成为可能，不要求人先精通工程。维护中的
[已有材料与起步条件](skills/yinyang/references/design-and-revision.zh-CN.md#从已有材料与实践起步)
区分实际已有的哲学写作、心理或生活材料、可用环境，以及两两组合，指出下一项贡献，
不把形成变成封闭阶段。配置可能来自限制、习惯或默认值，不能单凭工具清单推断个人。
哲学、有根据的描述与环境继续互相修订。[阴阳包说明](skills/yinyang/README.zh-CN.md#怎样使用并理解阴阳)
说明原生工作模型及其使用，包括本人的实际修订方法。

阴阳提供文化、思想与推理形式；个人内容来自获授权的实际材料，以及使用模型与
这个人的协作。采用持续维护的阴阳时，形成六份有根据的完整实际描述及本人实际修订方法。
简单独立路线保留 `references/situated/{orientation,person,counterpart,relationship,environment,revision}.md`
六路径，由模型直接综合并持久保存在私人 Git/GitHub。Hindsight 为可选，其核对后的输出可使用原路径或明确绑定
全部六者的索引。两条路线都保留 Personal 纠正与六份整体融贯。公开分发不提供私人画像，安装本身不形成实际描述。
[使用指南](skills/yinyang/README.zh-CN.md#怎样使用并理解阴阳)说明形成与核验。

论述与图示都属于 `skills/yinyang/references/` 内的阴阳配件。
其他成员保留各自的用途与专业方法；进入这个集合，不会使它们变成阴阳参考，
也不要求使用它们时采用阴阳的哲学。
组合使用时，阴阳是用户哲学的一个例子，其他 Skills 用具体能力补充它。
读者可以选择自己的组合，并围绕它写出另一种哲学。

公开包保留实际本地方法的结构和有用的配套关系。先读各包的依赖与配置说明，按任务下载
需要的配套 Skill，再绑定自己的工具与环境。配套 Skill 提供方法，不会自动授予认证、
设备访问或运行服务。它们不包含私人参与者描述、凭据、个人记录或作者的主机绑定配置。

## 在 Codex 中使用

[安装与更新说明](docs/codex.zh-CN.md)

集合中的 Skill 均可从 **boluopai** 插件市场独立安装。把下面的命令交给 Codex，
即可安装阴阳 Full，无须手工下载或解压 ZIP：

```bash
codex plugin marketplace add boluopai-net/Prometheus2Heraclitus
codex plugin add yinyang@boluopai
```

安装 Empty 时，把第二条命令中的名称换成 `yinyang-empty`；其他能力换成目录中需要的 Skill 名称。
市场只需添加一次，之后安装其他插件只需
`codex plugin add <包名>@boluopai`。安装后开启新对话使用。
阴阳个人版应保存在私人源目录中，不能写进会被更新替换的插件缓存。
