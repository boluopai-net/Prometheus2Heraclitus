# singing

Treat the studio as a responsive practice partner: the singer gives a phrase
its intention, a reference supplies an audible musical example, and playback
makes the next attempt concrete. Carry software operation and analysis so the
singer can concentrate on singing. Technical observations serve the musical
purpose; a list of accurate notes alone does not establish expressive impact.

This specialist method can work within a broader user/model relationship such
as [YinYang](https://github.com/boluopai-net/Prometheus2Heraclitus/tree/main/skills/yinyang).
That Skill owns its philosophical account and any separately maintained private
model; this package owns the singing method and imports no personal portrait.
For substantial accompaniment-source investigation, compose with
[research](https://github.com/boluopai-net/Prometheus2Heraclitus/tree/main/skills/research)
when available, retaining singing's responsibility for audition and practice.
Neither Skill is required to use supplied recordings or run this method.

## Establish the music and available route

Resolve the selected song, exact reference version, phrase or full-song scope,
and what the singer wants to hear differently. Use their current preferences
for style, key, language, budget, and session length. Original key is a useful
starting point for reference imitation; retain or change it according to the
actual request. Do not infer range, skill level, or a gendered vocal role from
the speaking voice. Challenging music and an expressive first pass can be useful
without a prerequisite curriculum.

Keep separate identities for the original reference, clean accompaniment,
synchronized lyric video, raw microphone take, and optional performance mix.
These can share a timeline but serve different purposes. Identify the version,
offset, and attempt before comparing them; duet roles remain identifiable.

Inspect the current tool inventory and host capabilities. This package installs
no recorder, downloader, DAW, or MCP server. Use [tools and setup](references/tools.md)
for optional routes, and [audio evidence](references/audio-evidence.md) for
analysis. If only supplied files are available, compare those files and prepare
the next musical attempt. Report an unavailable recording or playback capability
as a precise gap, rather than claiming the session ran.

## Find reusable accompaniment and lyrics

Prefer an existing accepted asset or a ready-made freely obtainable karaoke
video with readable synchronized lyrics. Search by song, artist, exact version,
and terms such as karaoke, instrumental, KTV, 伴奏, or 卡拉 OK. YouTube and Bilibili
are possible discovery sources, not guarantees of export permission or quality.
Use a supported acquisition route within the source's rights and access terms;
free viewing does not establish permission to download or redistribute. A free
accompaniment budget excludes paid tracks and subscriptions. An app cache or
performance downloader does not prove portable accompaniment export.

Audition sung sections, especially later choruses. Distinguish competing lead
vocals, intentional backing harmonies, and processing artifacts. Labels such as
“official instrumental” and waveform similarity do not establish cleanliness.
If the agent cannot listen, state that limit and use the singer's actual audition
as evidence; never invent an acceptance judgment. Source separation is an option
for a genuine material gap, with artifacts checked afterwards, rather than a
routine replacement for an accepted karaoke file.

After authorized acquisition, inspect duration, audio/video streams, several
lyric frames, lead-in, and timing continuity. The display should show upcoming
words early enough to prepare the entrance. Preserve an accepted video's lyric
presentation; audio alone does not satisfy a request for synchronized lyrics.
If the DAW needs separate audio, extract the same stream without another lossy
encode where compatible, retaining the full timeline and start offset. Record
source URL, creator, version, acquisition date, rights information if available,
and acceptance limitations with the local asset. Media rights stay with their
owners; keep recordings and library metadata outside this public package.

## Run the practice loop

For unfamiliar music, provide the original vocal in headphones for guided
attempts while it helps locate melody, words, and entrances. Verify the actual
lyric display and output route. Check alignment and drift if the guide and KTV
come from different versions. Move to clean accompaniment when the singer can
follow the passage, keeping the guide available for difficult phrases.

Record the microphone separately from accompaniment and guide audio. A mono
microphone track is sufficient; preserve the original reference channels and
raw take. Use headphones or another verified route that avoids guide leakage.
Check the intended track, input, record-arm state, monitoring, and useful signal
before starting. Distinguish microphone capture from loopback capture. Preserve
existing project material and use identifiable attempts on separate tracks or
regions as appropriate.

Use a substantial continuous passage, often about a minute or the whole song,
when that serves its expressive arc. Short phrase work is useful for a specific
difficulty: retain a complete sentence or gesture, enough context to enter,
and breathing space. Practice joins as well as cuts: A, B, then A+B; add C with
B+C and the larger passage. The agent carries locating, cutting, playback,
recording, stops, and retrieval when the available tools support them.

Read back transport after stopping; verify that a new audio file or region
exists and contains the intended microphone signal. Restore the prior armed
state when appropriate. An empty, truncated, clipped, or accompaniment-dominated
file is a recording problem to resolve, not evidence of singing ability.

Return that specific attempt promptly as playable audio/video or through
verified playback on the established output. Identify song, section, and attempt.
Include the untouched vocal; a labelled voice-plus-accompaniment mix can accompany
it. Keep headphone guide vocals out of the performance mix. A saved filename,
waveform, or analysis is not a substitute for accessible listening. If the host
cannot embed media, use a supported accessible file/playback route and state
what remains unavailable. Let the singer hear the take before asking for
self-evaluation; their recollection is not the recorded sound.

## Compare and make the next attempt useful

Compare corresponding phrases with actual reference and performance audio.
Use pitch trajectory, onset/offset timing, note duration, intensity contour,
slides, vibrato, syllable clarity, or ornaments where the tools and signal
support them. A score or MIDI file helps identify intended notes, but does not
encode all reference timing, consonants, or expression. Keep measurement,
listening interpretation, and the singer's report distinct.

Anchor feedback to a timestamp or lyric and connect the difference to its
musical effect. Offer a concrete attempt inside the music, such as sustaining
the phrase through its last word or matching the reference entrance after the
breath. An audible model or coherent expressive intention may work better than
many independent controls. Compare the next take with the reference and prior
attempt to see whether it helped. A satisfying completed performance need not
become another correction task.

State confidence and extraction limits. Preserve raw timing when alignment is
used, so time warping does not conceal rushing or dragging. Do not reduce a run
to one median pitch, confuse an octave error with a correct match, or equate
being in-key with reproducing the reference. Text transcripts cannot establish
vocal sound, and acoustic measurements cannot diagnose physiology or support
clinical claims. This method does not synthesize or clone a singer's voice.

At completion, identify the playable take, consequential observations, what
was tried, and the observed result or precise remaining capability gap. Keep
take-specific findings in the session; adapt reusable methods from actual use
without creating a standing personal profile from one recording.
