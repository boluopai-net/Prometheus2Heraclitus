# Global learning-path binding

This is a reusable reference slot, not an active learner path. Resolve
`global_learning_path` through [recipient configuration](configuration.md) to
the recipient's single maintained path before selecting, auditing or revising
course mappings. Its actual title/location may differ from this filename.
Do not write the recipient's choices or private records into this package.

The maintained path owns the current target selection, proposed course/material
mappings, source spine, retained depth, prerequisites/interfaces, exit evidence,
mapping-failure conditions and return triggers. The
[governance branch](learning-path-governance.md) owns the formal distinction
between target, mapping hypothesis and execution path; it does not select a
specialization for the recipient. The actual path need only represent relevant
relations clearly, not reproduce a fixed schema or template.

Read affected mappings and direct source/learner evidence before a judgment.
Course State owns observed exposure and contributions, not this path. Preserve
current course order and distinctions unless the authorized change affects them.
Maintain bounded evidenced corrections under the shared contract; stable-target
changes and broad restructuring follow the recipient's explicit request.
Read back changes at the maintained owner. If the binding or access is missing,
state the affected path decision as unresolved and continue independent
exact-source teaching; do not infer goals or fill an example path from memory.
