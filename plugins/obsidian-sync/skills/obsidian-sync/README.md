# Obsidian Sync

Share explicitly selected Obsidian configuration with File Provider-safe cloud copies and local symlinks.

[中文说明](README.zh-CN.md) · [Model instructions](SKILL.md)

No executable companion Skill is required. Python 3.12+, macOS and Git are external dependencies. Chezmoi is optional for durable installation.

Copy config.example.json, replace every recipient path, then run scripts/obsidian-sync --config /absolute/config.json --print-config and --dry-run. See SKILL.md for checks, seeding, backup and watch registration.

Download the **complete directory** from this repository or GitHub's native archive, preserving scripts and executable modes. Relative resources and companion relationships are part of the package. There are no personal accounts, subscriptions, vault lists, credentials or host defaults to inherit. Configure your own real targets; a downloaded method is not proof of a configured runtime service.
