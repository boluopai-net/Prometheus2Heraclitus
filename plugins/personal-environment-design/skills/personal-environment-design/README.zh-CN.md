# 个人环境设计 · personal-environment-design

[English guide](README.md)

设计并配置人与模型能够共同工作的连贯环境。本 Skill 把提示词、Skills、MCP、
插件、应用、自动化、本地或云端服务与实际使用体验连接起来，一起考虑能力、
理解和操作负担、资源使用、可靠性与维护。

## 使用与能力

将完整目录复制到智能体宿主支持的 Skill 位置。本包没有必需的软件依赖或配套
Skill。可以从已提供的描述开始调查；观察或改变真实环境需要接收方实际拥有的
浏览器、桌面、应用或实现工具，以及已有权限。本 Skill 不创建这些能力。

安装、连接、配置、替换或实质重组环境时使用。普通使用已经配置的工具，不必再做
一次环境设计；小修复也保持在受影响的依赖范围内。方法从指令或用户动作出发，
沿能力发现、连接、执行追踪到可观察结果。相关专业方法保留各自的方法与交付责任，
配套 Skill 只在实际可用时采用。

例如，可以要求接入一项 MCP 能力，比较直接连接、共享本地后端或已有托管服务，
判断哪种适合实际客户端、状态边界与成本；也可以要求检查从启动器进入项目的路径，
实现更清楚的工作恢复方式。前者需要代表性客户端调用，以及支持资源节省主张的证据；
后者需要回读受影响的使用路径与实际效果。保存了配置或界面好看，本身都不足以
证明已经实现预期改善。

## 包内容与调整

`SKILL.md` 是供模型使用的英文入口。按受影响的部分读取资源：

- [人的使用](references/human-use.md) 保留理解、操作、协调与恢复的路径设计方法，
  并区分模型走查与实际测量的人类使用。
- [MCP 与服务](references/mcp-and-services.md) 说明兼容传输、执行位置、安全共享、
  实测成本与替代方案验证。
- [设计依据](references/design-basis.md) 说明可复用的区别与保留的公开设计参考，
  区分这些参考对可用性的支持与依赖具体实现的工程证据。

含义一致的中英文指南解释采用方式。这份独立公开适配将本地工具选择和配置取舍
通用化，以独立说明替代私人原始引文与对话标识，不包含个人历史、私人来源、
预先配置的服务或凭据。
