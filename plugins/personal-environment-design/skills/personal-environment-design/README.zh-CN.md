# 个人环境设计 · personal-environment-design

[English guide](README.md)

设计人理解、选择、行动并返回工作的相互连接的界面。本 Skill 检查网站、桌面、
启动器、应用、文档与自动化中的理解和操作负担，在减少不必要协调的同时保留
有意义的区别。

## 使用与能力

将完整目录复制到智能体宿主支持的 Skill 位置。本包没有必需的软件依赖或配套
Skill。可以从已提供的描述开始调查；观察或改变真实环境需要接收方实际拥有的
浏览器、桌面、应用或实现工具，以及已有权限。本 Skill 不创建这些能力。

请求示例：“我从启动器打开项目看板，然后要搜索三份文档才能想起下一步。
检查这条路径，并实现更清楚的项目恢复方式。”方法会沿真实路径检查，区分已观察
的阻碍和假设，比较已有控件与新界面，通过系统实际维护方实现，并验证受影响的路径。

它一起考虑理解、操作、协调和恢复。更少的点击或更稀疏的界面不足以证明改善。
有用的结果会说明人需要查找、记忆、决定、输入、切换、等待与恢复什么，以及负担
是否转移到别处。模型走查与实际测量的人类使用始终区分。
