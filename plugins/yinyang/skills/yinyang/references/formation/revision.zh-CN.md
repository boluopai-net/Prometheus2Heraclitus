# 如何修订

<a id="修订"></a>
<a id="修订个人阴阳与工作环境"></a>

[English](revision.md) · [哲学与模型](../design-and-revision.zh-CN.md) · [环境](environment.zh-CN.md)

作者用这套方法，让 Yinyang 的核心[交叉参与与返回](relationship.zh-CN.md#在有关之处说明交换与返回)
始终接受实际相遇的检验。哲学、个人理解与实际工作通过这条关系发展。修订可以从发展后的思想、
变化的处境、一个异议，或不再合适的安排开始。找到什么发生了变化，展开它的后果，再让
结果纠正引导这项变化的理解。

按自己的目的、材料与环境调整这套方法。你可能在写另一种哲学、修订某项个人解释，或改变
一个工具。下面的联系帮助辨认哪里需要关注；更新六份个人工作文件时，按下文先刷新材料、
再凝练的顺序，检索范围取决于受影响的问题。经验揭示了更好
的做法时，方法自身也可以修订。

## 写出自己的实际修订方法

在私人包的 `references/situated/revision.md` 中，写出适合自己的实际修订方法。
本指南说明怎样写；下面作者的做法提供可调整的参考。

说明什么会触发修订，怎样取得有关哲学与个人材料，如何判断局部范围及必要联动，怎样完成
环境变化并核对结果。写入你实际能够使用的材料与路径，以及哪些判断需要本人参与。已有
新哲学、没有网站或不同的工作条件，都可能改变做法。让实际方法表达这些条件，而非照搬
另一位作者的环境。

## 确定修订范围与联动

确定所要得到的结果，以及需要发展的部分。区分**修订重点**、**用于判断的材料**与
**实际需要联动改变的部分**。读取哲学来判断接口，不因此选择改写哲学。

| 当前重点 | 相应工作 |
| --- | --- |
| 刷新个人阴阳与环境 | 用哲学和当前来源重新理解个人材料，评估相连的描述，再检查相关 Skills 与安排。 |
| 修订哲学主张或个人解释 | 发展这段内容，把含义变化带入依赖它的描述、方法或表征。 |
| 修复 Skill、页面、工具或安排 | 诊断并修复该对象；结果若暴露了前提或个人解释的错误，再返回相应位置。 |

沿真实依赖落实实质变化。措辞或呈现上的纠正，可以在来源与阅读处完成；参与分工改变，
可能还要改变实现它的指令。保留明确的停止边界，说明仍未完成的必要后果。

## 确立当前可用的材料

私人 `references/personal/` 材料与 `references/situated/` 下的六份文件承担不同用途。
`personal` 保留与心理有关的经历、来源记录及可修订的解释；理解自己的心理时，主要从这里
进入。六份文件则凝练**人与模型协作的个人工作模型**：采用什么方向，需要理解本人哪些情况，
伙伴怎样贡献，双方怎样合作，环境怎样实现，以及如何修订。它们共同服务于让个人环境符合
实际的这个人，不合起来构成一份本人的心理模型。

每次更新这六份工作文件，都先刷新根据，再重新凝练：

1. **先读个人 Philosophy。** 阅读本人采用的哲学表达及有关的展开论述。当前工作文件帮助
   定位哪些关系受影响，但旧的凝练不能替代哲学或支持材料。
2. **查找有关的新 Reference。** 从当前对话、可用的 Computer History、对话历史、工作与
   版本历史或其他来源记录中，寻找与受影响理解有关的新材料。重要判断需要完整背景时，
   沿有用摘要返回原始来源。不同历史覆盖不同部分；观察到一项行为，不等于知道它的心理原因。
   使用实际可取得且获授权的来源，说明影响判断的缺口。
3. **刷新 personal 中的参考材料。** 将有用的新证据连同来源和背景纳入维护；已有原件可通过
   链接定位，不必重复复制。结合新材料与哲学，检查 `personal` 中既有解释，纠正、限定、重组
   或退役不准确及已经过时的部分，保留可归属原件和重要不确定性。补材料不等于追加一条特征。
4. **用 Philosophy 与刷新后的 Reference 凝练工作模型。** 修改六份文件中受影响的内容，并检查
   与其他工作文件的联系。选取会影响协作或环境设计的理解，保留返回较丰富个人材料的路径。
   描述说明伙伴需要理解什么、怎样贡献，不试图写出完整心理画像；随后将必要变化落实到环境，
   检查实际使用。

这项顺序说明更新工作模型的依赖，不要求每次都收集新的个人事实或重写全部六份文件。
一次局部纠正可以以当前交流作为新来源；按问题检查相关历史，无需遍查整个人生。没有发现
有关的新材料时，如实保留这个结果。当事人贡献来源里没有的体验与判断，模型承担检索、
参考材料维护和凝练；后续反馈仍可使工作返回前面的解释。

## 按实际用途写作

用清楚的语言说明相关对象、关系、证据、条件、职责与后果。体验报告、解释、选定承诺与操作
要求若会导向不同判断或行动，就明确区分。个人信息提供有情境的证据，不因出现在描述中就
成为命令。

直接表达。哲学区分或文学意象能够使关系清楚；关系需要指导工作时，说明它的含义。将原始
表达保留为可归属材料，同时明确写出维护中的解释与实际后果。较长的哲学论证留在自己的源
位置，有用时连接它。

## 来源与证据

因为材料与当前问题有关，才选择个人写作、对话、记忆、观察到的工作与哲学材料。保留来源
身份、时间、相关段落，以及足够判断重要主张的背景。摘要处于原件与读者之间时，把这个
联系说明白：摘要的选择与遗漏，可能影响解释。

不同材料支持不同主张。人的报告为其在处境中表达或经历了什么提供根据，同时提出的解释
仍需判断。观察到的工作说明检查条件下发生了什么，选定承诺说明方向，哲学贡献概念与理由。
以虚构的阅读情形为例，报告更轻松，支持经验上的轻松；到达正确段落，支持访问。持久学习
与改善原因，需要进一步证据。

让时间范围与不确定性清楚。后来的表达可能纠正解释、描述新处境，或引入未决冲突。说明
重要推论：什么支持它，为何这样联系，什么限制其使用。几份摘要来自同一来源，不增加独立
支持。

较长经历与独有原件留在既有维护者处，派生描述提供可用定位与根据。作者的包以
`references/personal/sources.md` 作为私人来源入口，[包结构说明](../docs/skill-package.zh-CN.md)
解释其位置。淘汰重复摘要，同时保留有用原件。为修订而取得访问，不授权收集无关个人材料，
也不授权公开私人引文、画像或未发表作品。

## 凝练与重新展开

凝练使有关理解能够在下一次协作中使用。保留会改变解释、回应或修订的关系：表达在
回应什么、适用于哪些条件，谁报告经历、谁提出解释，以及什么反例或替代解释仍然
重要。将这些关系写成连贯描述，按需要带上来源；不要求每条内容填写同一组字段。
只有措辞本身承担意义时，才把原话带进工作描述，完整原件仍由来源维护。

从本人提供的经验、可观察的互动与实际结果形成说明，让模型提出的解释保持可辨认。
被引用多次的摘要不会增加独立证据。区分叙述中的模式、选定的协作方向与已经验证的
因果解释；不为了描述完整而补造内部心理状态，不将模拟人物的状态分数用于实际个人。
这些区分可以在同一份自然语言模型中表达，无需拆成互不相通的档案。

新材料到来时，判断它纠正了旧读法、反映了条件变化，还是提出仍未解决的不合。
据此限定、撤回或重组有关描述，而不只追加特征；保留原事件与解释形成的时间。
用当前相关来源检查重写后的理解，避免连续改写摘要时把推断变成事实。反复出现的
词可以成为检索入口，频率本身不确定其关系意义。较新的表达也不因时间较晚就覆盖
全部旧材料。

在有用的维护节点，检查下一位伙伴是否仍能从凝练描述中辨认适用范围、实际目的、
重要未决问题与返回根据的路径。改变这些判断的遗漏需要补回；不影响当前用途的
细节可以留在来源。模型回应及其被接受、拒绝或修改的过程，也可能成为后续材料，
但不能自动当作模型先前解释正确的证明。哲学论证见
[凝练怎样保留可修订的关系](../docs/metaphor-and-self-revision.zh-CN.md#凝练怎样保留可修订的关系)。

## 让返回的材料改动组织它的描述

区分作品发生了什么与参与发生了什么。改好一段文字确立了文本变化；人接过审查时仍保留
开放生成，或模型的再次生成受到先前审查所显出条件的重组，才为角色返回赋予具体内容。
写清选择了什么、观察到什么，以及仍有什么不确定。前面的材料刷新顺序为判断提供根据，
不规定每次交流都必须依次完成的参与程序。

阴阳的[纠偏反馈](../docs/yinyang-and-taiji.zh-CN.md#转动与纠偏反馈)给修订增加一个问题：来源、
异议或使用结果，能否真正改变接收它的理解？把每个相反案例重新解释为确认，会以失去可纠正性
为代价保住原有描述。找到新材料涉及的前提、范围、关系或实现，将有根据的变化落实到那里。
相关目标本身也可能需要修订；纠正并不总是恢复上一种安排。

区分解释哲学家、借概念表达个人经验，以及独立发展的论证。没有根据的原意归属需要纠正；
有用的新构造可以作为作者自己的贡献保留，并提出自身理由。这样，来源保有不同意的能力，
也不把每次创造性的转用都当成错误。

修订选定的角色交换时，检查各个受影响对象的含义：为何重视它、人怎样参与、伙伴贡献什么、
双方关系怎样变化、什么使其成为可能，以及怎样纠正描述。这些是相连的责任，不是同一段话的
六份副本。只在反馈改变贡献的地方纳入它。改写描述确立了写作上的修订；效果与发展主张仍需
后续使用提供根据。

## 用哲学刷新个人支持材料

让发展后的哲学与已有个人材料相遇：它澄清了哪些解释，补出了哪些缺失的区分，又使哪些
摘要显得误导？修订派生材料，让体验、解释、选定方向与不确定性仍然清楚。哲学帮助形成
理解，可归属表达与实际使用为其个人应用提供根据。

公共论证已经在别处持续维护时，连接它，保留这份描述所需的私人意义与证据。这样，哲学
变化时，支持材料仍然有用。

## 用哲学与个人材料刷新工作描述

按[上述顺序](#确立当前可用的材料)刷新个人参考材料，再与哲学共同阅读。六份文件是服务于
合适个人环境的工作模型，心理理解是它们的根据之一。在作者的阴阳中，取向阐明采用的价值与方向，个人
使对实际人的理解有据可依，模型伙伴连接现有能力与期望贡献，关系解释共同活动，环境说明
其实现。[写作指南](../design-and-revision.zh-CN.md#基于实际材料形成情境化版本)展开这些不同责任。

保留有支持的内容，重写变化的关系。区分偏好与解释性假说、期望角色与已展示的能力、选定
安排与观察到的效果。联系相邻描述阅读，使修订保持连贯。双方都能生成、反对、推理与修订。

也重新考虑自己的实际修订方法。如果它反复制造多余工作、遮蔽判断，或无法让变化进入使用，就修订
相关指导，检查新做法是否有帮助。另一个人的实践，可以采用不同的对象、组织与方法。

## 重读个人材料，检查工作模型

理解自己的心理体验时，主要从相关 `personal` 材料及其来源进入：经历、表达、关系、本人
报告的体验，以及暂时的解释。模型帮助定位与整理，本人可以认出适切或不合、提出例外，
或重新理解一项读法。保留这些文件提供了理解的材料，并不保证其中的解释正确。

重读六份工作文件则回答相连而不同的问题：这份理解是否导向合适的伙伴、分工与个人环境？
即使 `situated/person.md` 也只选取日常协作所需的内容，不能替代较丰富的个人材料。
工作方式变得合适，可以说明适配有所改善，不因此验证某个心理解释。

一条路径用已经写出的哲学考察个人参考材料及其实现：这些解释怎样理解自己和他人，
安排支持了什么生活，哪些价值与概念也需要修订。另一条路径从重复经历进入，比较
当时发生了什么、本人怎样理解对方、期待怎样的回应，以及自己的行动怎样参与了
随后形成的关系。让实际的要求、条件与依赖同提出的关系解释一起接受考察。

两条路径都保留可修订的解释，个人重读限于整理经历、表达问题与增加
自我了解。区分本人说过什么、模型提出了什么解释，以及环境实际改变了什么。
已明确的目的与偏好可以用于调整工具和工作安排；这些记录不构成心理测量、临床
结论或自助干预依据。涉及心理健康问题时，可带着记录向合格专业人员说明情况，
不自行开展心理分析、评估或治疗。[重读自己的模式](../docs/embodied-experimental-philosophy.zh-CN.md#重读自己的模式哲学反思与幻想的松动)
展开有关哲学资源；[用途说明](https://github.com/boluopai-net/Prometheus2Heraclitus/blob/main/README.zh-CN.md#用途与心理健康说明)
交代本项目的评估局限。文件修订和环境变化各自建立其结果，不证明心理状态或机制的改变。

## 用整个阴阳刷新 Skill 与环境

用相连的哲学与个人理解，评估与预期结果有关的 Skills 和安排。它们的目的、指令、例子、
资源与实际行为，是否支持所想要的贡献？提示词、工具与接口的依赖影响结果时，也一同检查。
专门 Skills 保有自己的方法与任务责任。

修复实际的不匹配：相互矛盾的指令、无法取得的上下文、不合适的接口，或已经失去贡献的机制。
移除被替代的指导，保留仍然有效的部分。[环境写作指南](environment.zh-CN.md)展开
实现；使用自己环境中的实际创作、实施与发布路径。

## 发布前让网页修订可见

作者的实践包括一个公共网站。修改其中的图时，模型在对话中展示改动后的图；新增页面或
实质修改页面时，在发布前展示实际未发布版本的可读渲染，并解释重要变化。随后再有实质
修改，就展示那个版本的更新预览。

这样，当事人能够在作品仍可变化时与它相遇。已经获授权的发布继续进行，期间收到反馈时
将其纳入；个人认证、同意与明确停止边界保留原有范围。没有网站的实践，可以采用有关的
对应方式：分享前阅读草稿、试用接口，或检查作品。

## 让结果返回理解

将摘要与证据比较，将生成副本与来源比较，将完成声明与通过实际入口取得的结果比较。
描述无法取得时，需要修复交付；描述得到忠实执行却产生不合适的贡献时，需要检查其含义
或选定关系。

通过受影响的来源与使用处完成获授权变化，再回读目标读者或工作模型实际可取得的版本。
副本依赖创作来源时，沿其实际路径更新。私人材料保留在获授权的受众范围内。

比较预期结果与可观察结果，说明仍未解决的必要差异。证据提出挑战时，返回个人材料、
工作描述或哲学。有用产出、协作是否合适与个人发展具有不同根据；让主张对应修订及后续
使用实际确立的东西。
