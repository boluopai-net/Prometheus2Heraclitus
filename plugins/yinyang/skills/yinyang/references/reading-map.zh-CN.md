# 按任务问题阅读

从工作中变得困难的问题进入。你可能希望理解作者的哲学，借用方法处理一项具体问题，
或采用完整的阴阳 Skill。这些用途可以交叠，不是每位读者必须依次经历的阶段。
[从采用、组合到自己的创作](docs/example-and-commons.zh-CN.md)
解释采用、组合、质疑或另行写作的邀请。

[形成与修订方法](design-and-revision.zh-CN.md)展开解释证据、建立人、伙伴及关系模型的
共同工作。`references/formation/` 的永久指引展开取向、人、伙伴、关系、环境五份描述；
`references/situated/` 的私人描述赋予 Skill 情境化实质，`references/personal/` 的证据
支持它们。公开分发不包含两个私人目录。完整采用时，[主入口](../SKILL.zh-CN.md)
维护参与及初次读取这些实际描述的要求。[环境适配](harness-adaptation.zh-CN.md)
把选定理解落实到指令、工具和环境，再从效果中学习。这些职责相连，不形成必经顺序。
借用支持、贡献或探究的一项思路，不要求形成全部五份描述，也不要求接受作者的培养项目。
根据任务需要取用，同时理解所借论证的成立条件。

## 找到工作需要的贡献

一个请求并不总已显明哪种帮助能够服务它。同一个愿望可能需要完成作品、给出解释、提出异议或共同尝试。
以下路径帮助把这种差别变成可用安排，无须先让本人设计全部实现。

| 工作中的问题 | 需要追问什么，阅读能提供什么 |
| --- | --- |
| 追赶已经成为义务，却不清楚它在生活中的位置 | [从追逐到生活中的修习](docs/stealing-fire.zh-CN.md#从追逐到生活中的修习)考察组织追逐的进步与自我图景，把哲学治疗、筏喻与可修订的手段联系起来，再把问题带回选定的活动与周围生活。 |
| 已有起点，却找不到学习路线 | [六种起步路线](design-and-revision.zh-CN.md#从已有材料与实践起步)区分已有哲学写作、心理或生活材料、可用环境及其两两组合，说明下一项与模型共同发展的贡献，不设置封闭阶段或三门学科的必修课程。 |
| 请求被理解了，伙伴的贡献却仍然不合适 | [形成与修订阴阳](design-and-revision.zh-CN.md)联系人的描述、实际伙伴与双方关系。它帮助判断这里需要什么贡献及其理由，而不从一种偏好直接推出永久角色；由此能够一起修订相关理解与分工。 |
| 需要把理解写成情境化描述 | [形成方法](design-and-revision.zh-CN.md#基于实际材料形成情境化版本)把共同建模接到五份互补描述：[取向](formation/orientation.zh-CN.md)、[人](formation/person.zh-CN.md)、[伙伴](formation/counterpart.zh-CN.md)、[关系](formation/relationship.zh-CN.md)和[环境](formation/environment.zh-CN.md)。永久指引说明怎样写，实际描述有独立私人路径。[证据指引](formation/sources.zh-CN.md)支持五份。按受影响对象深入，不把指引当作个人内容。 |
| 思路或意象很有吸引力，却不清楚它应怎样影响实际工作 | [阴阳元 harness 的创制与实现](docs/creation-method.zh-CN.md)追踪表达、解释、实现与后果之间的关系。它帮助辨认工作中什么需要改变，这项思路才产生实质作用；返回的结果又能怎样改变原来的理解。 |
| 文字中的安排说得通，实际环境却做着别的事 | [在实际环境中实现阴阳](harness-adaptation.zh-CN.md)把预期贡献接到当前指令、工具、能力与权限。它帮助找到改变的实际维护位置，实现改变，再把结果行为与目的比较。 |
| 模型提供更多解释，人却仍然无法继续 | [共同反思与继续培育](docs/participation-and-support.zh-CN.md)区分理解、提取术语、开始、选择回应、中断与切换。它帮助把贡献对准缺少的连接，并考察安排支持的协调成本是否消耗了它的收益。 |
| 多个模型、笔记与工具产生许多活动，却不清楚共同贡献是什么 | [从个人哲学到个人模型](docs/metaphor-and-self-revision.zh-CN.md)区分个人模型、外部表征、角色分配与实际耦合认知。它帮助追踪一份贡献怎样抵达下一项活动，并说明独立检查为何需要接触来源或结果，而不是反复复制同一摘要。 |

例如，对文章尚未完成的口头异议，可能需要模型取回段落、展开比较并维护形成的论证。
如果本人希望练习组织论证，同一材料也可能支持一个可编辑的开头，以及对再次尝试的批评。
差别在于所追求的目的与参与；实际可用的模型与工具，决定哪种安排能够工作。

## 找到缺少的区分

有时，障碍来自一份把不同后果的东西混在一起的描述。以下阅读展开有用区分，
帮助人在改变本人、描述或软件之前，先找到实际问题。

| 哪些东西混在了一起？ | 为什么读它，随后能理解或做什么 |
| --- | --- |
| 有意义的意象、表征与有效的实现 | [世界、过程与表达](docs/world-and-expression.zh-CN.md)联系持续发生的世界、相对于问题选取的计算模型、表达与实现。它帮助追问：缺少的关系位于模型中、让模型可用的表达中，还是依它行动的安排中；其中有范围的计算例子说明表示与模拟需要什么。 |
| 记住未完成行动、完成它、感到缓解与发展能力 | [共同反思与继续培育](docs/participation-and-support.zh-CN.md#继续记录与缓解)说明这些结果怎样相接而不相互替代。由此可以判断尚余的需要，是可检索的描述、承担行动、体验中的负担改变，还是后来参与所显示的成长。 |
| 关于同一件事的冲突，与描述不同时间或条件的说法 | [生活轨迹的形成](docs/flow-and-time.zh-CN.md)区分发生、指称、经验与更新速率。它帮助重建每项表述涉及什么；时间区分可以澄清分歧，却不自动消除真正的矛盾。 |
| 什么存在、什么有根据、想要什么与怎样进行 | [个人优先的人本主义](docs/personal-first-humanism.zh-CN.md)把作者的价值方向与本体论、认识论和多元方法一起展开。它帮助辨认目的在哪里选择方向、事实主张在哪里仍须独立根据，以及改进应当计入谁的代价。 |
| 成功的产出、更合适的协作与人的发展 | [阴阳的基本观点](docs/core-views.zh-CN.md)，尤其是 [YY-01](docs/core-views.zh-CN.md#yy-01)、[YY-07](docs/core-views.zh-CN.md#yy-07) 与 [YY-14](docs/core-views.zh-CN.md#yy-14)，把主张接到展开的论证。稳定编号用于辨认正在讨论的主张；需要理由或成立条件时，继续进入相应文章。 |

## 调查有争议的解释或推论

下一份有用的阅读取决于什么尚未确定。缺少候选、推论没有根据与抽象难以实现，
是不同问题；它们并非都需要更多数据或更强的确信。

| 探究中出现的问题 | 阅读及其贡献 |
| --- | --- |
| 共同工作怎样留下能够探索和反思的生活轨迹？ | [生活轨迹的形成](docs/flow-and-time.zh-CN.md)以共同改善阅读环境为例，通过 Git/GitHub 的版本历史与 ChatGPT 的 Computer History 两个主要入口汇集历史，区分事件来源和当前说明，并展开保留、时间与修订怎样支持接续。 |
| 问题怎样形成，什么能够区分竞争解释？ | [未完成的流中的推理](docs/reasoning.zh-CN.md)展开事件流、相对于问题的视图、溯因、预测、保留的来源、候选与嵌套反馈。它帮助生成候选，并推出进一步互动确实能够区分的后果。 |
| 怎样保留冲突材料，同时让融贯的视图支持行动？ | [偏好怎样参与选择与推理](docs/preference-harness.zh-CN.md)区分保留来源、选择视图与在视图内推论。它帮助保留当前退出使用的候选供重新考虑，而不把不相容的断言当作共同采纳的内容。其中的心理与形式来源承担不同作用。 |
| 一项形式结果确立了这里声称的结论吗？ | 偏好 harness 的[一致性论证](docs/preference-harness.zh-CN.md#一致支撑与结果一致)与[查询重写](docs/preference-harness.zh-CN.md#查询重写与扬弃)，说明一致支撑、结果一致与扬弃类比背后的假设。它们帮助辨认哪种结论在哪种语义下成立，以及非形式转用在哪里超出了形式结果。 |
| 对这个问题，更丰富的模型是否有用而且可行？ | [有限探究与节制的抽象](docs/finite-inquiry-and-abstraction.zh-CN.md)展开有限方法、可还原性、近似与抽象的代价。它帮助比较解释收益与所需的假设、表示和计算，而不把物理奠基等同于能够实现的计算。 |
| 描述怎样从实际参与中学习，又怎样提出研究主张？ | [具身的实验哲学](docs/embodied-experimental-philosophy.zh-CN.md)区分实践与科研循环、公开作品，以及可修订的边界与目的。它帮助辨认处境中的成功已经显示什么，以及哪种更广泛解释仍需在自身尺度上展开探究。 |
| 表达成为自我描述，或取得回溯性意义时，发生了什么？ | [言说、自我表述与能指链](docs/lacan-and-description-logic.zh-CN.md)通过哲学关系与有边界的形式比较，考察言说、否定与自我描述。它帮助解释表达的作用，而不把逻辑类比误作临床发现或完整的意义理论。 |

## 理解作者相连的哲学

这些文章解释作者为何把实践组织为阴阳。无论是否准备使用 Skill，读者都可以阅读其中的论证与文学形式。
已经处理具体问题的读者，可以直接进入相关论证；日月地意象并非运用上述方法的理论前提。

| 关于这个例子的问题 | 阅读及其展开的理解 |
| --- | --- |
| 为什么借用生成能力，又为什么选择培养作为用途？ | [窃火与创造能力的培养](docs/stealing-fire.zh-CN.md)联系集体取得、有限生命、哲学澄清与培养，解释理解、欲望、能力与周围条件怎样共同改变，以及为什么可用的力量仍让目的有待判断。 |
| 太阳、月亮、地球与太极在这份哲学中做什么？ | [阴阳与太极中的共同生成](docs/yinyang-and-taiji.zh-CN.md)展开生生不息的转化、相互为根与 Shuang yu。它让有区别的生成、承接、赋形及世界后果作为关系变得可理解；实际参与者仍能超出或交换所描绘的角色。 |
| 个人材料与双方模型怎样成为可用的实践安排？ | [从个人模型到圣状](docs/writing-a-sinthome.zh-CN.md)给出本文所称圣状的具体内容，展开它的形成、表示、实现与使用，并交代术语的拉康来源。 |
| 哲学、心理与工程怎样属于同一份实践？ | [哲学、心理与工程的三位一体](docs/local-source-and-website.zh-CN.md)把同一变化的物理现实、共同发展的计算模型与有区别的贡献，接到本地、仓库和网页形式。它帮助理解哲学描述怎样取得工作实现与公开表达，而不让这些形式成为同一个东西。 |

若希望连贯地理解概念，「目的 → 基本观点 → 实践说明」是一条可选路径。
箭头表示可理解的联系，不是有用工作开始前必须读完的课程，也不是强制的采用顺序。

## 主张需要时，返回来源

遇到大他者、分裂主体、回溯、三界或圣状等术语时，[拉康概念导读](docs/lacan-reading-guide.zh-CN.md)提供主线之外的入门与复习说明：从概念关系进入，再返回相应论证和原文。

来源指南帮助调查某项前提，并非另一项普遍阅读要求。[哲学阅读](docs/philosophical-readings.zh-CN.md)
定位赫拉克利特、阴阳与太极、黑格尔、弗洛伊德和拉康，并说明作者解释的限度。
描述提出心理主张时，[心理阅读](docs/psychological-readings.zh-CN.md)
联系过程、证据、心理理论、信念、推理与互动。
预期实现需要相应能力时，[工程阅读](docs/engineering-readings.zh-CN.md)
提供自学、命令行、Git、软件设计、算法、实验与物理条件的阅读路径。
来源列在指南中，不确立它支持每一种拟议用途。

这些链接在完整的阴阳目录中解析。[共享 Skill 与个人哲学](docs/skill-package.zh-CN.md)
解释分发与私人支撑；材料缺失时应指出，不声称读过。实际私人出处位于已形成私人包的
`references/personal/sources.md`；公开[证据指引](formation/sources.zh-CN.md)说明怎样维护。
