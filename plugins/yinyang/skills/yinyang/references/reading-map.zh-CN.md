# 按问题阅读

关于采用、组合这些资源，或写出另一种哲学与形式的邀请，请读[从这个例子开始，写出自己的东西](docs/example-and-commons.zh-CN.md)。以下路径说明的是这个持续维护的阴阳例子。

日常工作由直接对话的主模型完整阅读公共[入口](../SKILL.zh-CN.md)、[相遇（英文形成指引）](encounter.md)、[用户模型（英文形成指引）](models.md)、[伙伴与关系（英文形成指引）](relationship.md)、[实际使用（英文形成指引）](usage.md)及[来源索引（英文形成指引）](sources.md)，复用当前已有的阅读。这五份是主要工作模型，需要时沿链接深入哲学与[私人来源和配套材料](personal/README.md)。编写哲学或网页时，主要工作对象是受影响的论述与页面，再把有依据的新理解带回核心描述；不能用核心摘要代替对作品本身的展开。这些文件在分发包中提供形成指引，在个人包中承载有实际依据的描述，路径相同。

形成或修订时，阅读[形成与修订阴阳](design-and-revision.zh-CN.md)。改变实际环境时，将[在实际环境中实现阴阳](harness-adaptation.zh-CN.md)与受影响的个人描述及目标一起阅读。两种包中的公共方法与资源相同。

初次理解概念时，可以沿着“目的 → 基本观点 → 创造方法”阅读，再根据问题查阅其他文本。形成个人哲学，从可用的方法与实际材料开始，不必先读完一套哲学课程。太阳、月亮、地球的关系属于阴阳与太极的意象，不是独立的理论前提。

这些链接在完整的阴阳目录中解析。分发包时，将 `references/docs/` 和 `references/diagrams/` 资源与入口及参考文件一同保留；材料缺失时，应指出缺失，而不声称读过。公共阅读地图在这里维护；`personal/README.md` 中的私人索引指向来源与私人配套材料，不重复公共哲学论述。
