# 个人优先的人本主义

[首页](../../README.zh-CN.md) · [English](personal-first-humanism.md)

*一个人遇到为一般人设计的安排。自己生活中某种重要的东西，在其中没有
位置。让这个差别可以被理解，就可能开始改变安排的工作。*

个人实践的哲学从具体处开始：有人感知、理解、欲求、制作，并生活在后果
之中。用户、工作者、读者、公民等范畴，使一些关系变得可用。人也带来那些
范畴可能尚未表达的处境与可能性。**个人优先的人本主义**，给从具体相遇
出发发展安排以一种伦理方向。

其实践前提是明确的：人的理解的发展、自愿的能动性，以及维持值得过的生活
的能力，应当给工具与合作安排以方向。个人哲学可以帮助阐明这个前提在这里
意味着什么，模型则帮助它取得可工作的形式。实际后果随后可以修订安排，
以及安排对人的理解。

## 真实的人，可修订的描述

认真对待人，并不要求先有一套穷尽人格的形而上学理论。它要求承认描述所要
回应的实际生活：具身条件、经验、关系、承诺，以及继续超出描述的影响。
一个人的模型即使内部融贯，也可能不适切。本人修正可以揭示这种不适切；
后续经验还可以揭示另一种。

框架采用**朴素自然主义**的世界观与**物理主义**的本体立场：人、心理活动、机器与工程
都在同一个自然世界中发生。**当代火一元论**以火表达这个世界的生成与转化。
计算本体则是为具体问题构造的表征；这里用事件、状态、对象、关系与转移组织
**过程本体**，使人的活动及其变化可以被描述、推理和使用。物理基础说明这项活动
怎样属于现实，计算表征说明我们选取什么以及怎样理解它。[物理基础与计算抽象](world-and-expression.zh-CN.md#物理基础与计算抽象)
展开这层联系。

因此，「人是真的」在这里有一种实践力量。范畴、指标或故事，不能穷尽实际
经历其应用的人。应用的后果需要进入评估。同一种力量也适用于他人；相遇
有不止一个关切中心。

## 构造、唯名论与虚构

构造概念的可能性，让我们追问概念表示什么、如何使用。唯名论问题关涉
共相与一般范畴的地位。霍布斯《利维坦》第四章提供一种历史表述，把普遍
名称看作适用于个别事物 [[1]](#source-1)。这种表述并没有让那些个别事物消失。

虚构主义提出另一个问题：一套话语是否可以有用，而不接受它表面主张的字面
真实性？选定的虚构角色可以组织行为；思想实验可以在想象条件下展开后果。
计算本体能够表示这些内容：一个人相信的神、想象的伙伴、创造的卡通形象，
都可以通过信念、期待、叙述和行动进入过程模型。人的想象活动及其影响实际发生，
角色则取得它在想象或故事中的含义。模型因此需要表达「谁想象什么、怎样使用它、
后来发生什么」。[隐喻一文](metaphor-and-self-revision.zh-CN.md)发展表达性构造如何成为
解释与实现。

这些区分给一个更强的条件问题留出空间：**如果许多组织生活的概念是构造的，
或被当作虚构使用，我们应当选择哪些构造？**这个问题让适切性变得重要，
却没有确立一切都是虚构，也没有从本体论标签推导出伦理答案。一项构造可以
服务管理、效率、服从、发现或个人发展。选择方向需要有关什么应当重要的
理由。

个人优先前提提供这样的理由：概念与安排应当支持实际的人的理解与能动性，
并保持对其修正开放。可构造性给修订以空间；伦理前提给修订以方向。两种
贡献应当保持可区分。

## 六个相连的面向

哲学论述展开六个相连的面向及这项实践在其中采用的立场。世界观给出整体图景，本体论说明存在与
表征，真理论说明何谓真，认识论说明怎样形成和修正判断，价值论与方法论则考察
值得追求的目的及探究、行动的做法。

| 面向 | 采用的立场 | 它向实践提出什么问题 |
| --- | --- | --- |
| 世界观 | 朴素自然主义：人、模型与社会共同处于一个变化着的自然世界；当代火一元论表达其生成与转化。 | 怎样把人、技术及其活动放在同一幅世界图景中理解？ |
| 本体论 | 物理主义的现实基础；计算层通过对象、事件、状态、关系与转移构造过程本体，作为问题相关的表征。 | 什么实际存在，模型又选取或构造了哪些对象与关系？ |
| 真理论 | 符合论：关于现实的陈述为真，在于它所说的情形符合事实；模型中的陈述按给定解释确定成立条件。 | 所说的情形是否成立，模型的表述怎样联系其对象？ |
| 认识论 | 以具身经验为起点、由反馈修正的可错论探究。 | 哪些观察支持或挑战解释，什么能够区分替代解释？ |
| 价值论 | 个人优先的人本主义。 | 安排支持谁的理解、能动性与值得从事的活动？ |
| 方法论 | 相对于问题的多元主义。 | 类比、形式化、模拟、参与与实验的哪种组合回答这个问题？ |

这些面向与[基本观点 YY-09](core-views.zh-CN.md#yy-09)采用同一组区分。世界观将它们
联系成整体，价值阐明什么值得追求，**实践**使它们共同进入行动并遭遇后果。
图中的实践节点表达这份共同运用。

<a id="物理层与计算层"></a>

从哲学论述转入具体实践，就要说明所采用的世界观、本体观、真理观、认识观、
价值观与方法观：这项情境化实践怎样理解和组织对象、判断、目的与活动。
关于世界的主张仍向事实与证据负责；把采用的观点写清楚，使其根据与后果能够被考察。
下面把这些观点在物理层和计算层分别展开。物理层关注实际发生的活动及其物质条件；
计算层组织可供人与计算机使用的表征，并使它参与活动。**计算本体先确定表征中的
对象、关系与规则，这里再以过程本体组织它们的持续和变化。**它可以描述现实，
也可以表达假设、可能情形与虚构内容。计算的载体和使用属于物理世界，表征内容
则按它所谈论的对象和情境来理解。

人的活动历史与人机交互历史，可以按事件及其关系组织为事件流。对人的模型则
依据这些历史和其他生活材料，形成关于经验、信念、目的及行动关系的概念表征。
参与者、他的历史与对他的模型，在这里各有位置。

| 面向 | 物理层 | 计算层 |
| --- | --- | --- |
| 世界观 | 人、机器、心理与社会活动处于同一个变化着的自然世界。 | 组织选定的世界图景，表达实际、可能或想象的情境及其联系。 |
| 本体观 | 物理本体：具身的人、机器与物质过程怎样存在、持续并变化？ | 计算本体作为表征，以过程本体组织对象、事件、状态、关系和转移。 |
| 真理观 | 被谈论的对象、事件与关系实际怎样，什么情形成立？ | 陈述在给定解释中何时成立，推断怎样由前提得到，关于现实的表述怎样符合事实？ |
| 认识观 | 经验和观察怎样支持判断，如何发现错误？ | 怎样表示证据、比较候选解释、进行推理与检验？ |
| 价值观 | 什么值得追求，谁的能动性和生活受到影响？ | 怎样明确目标、评价标准、约束与取舍？ |
| 方法观 | 怎样实际进行探究、协作与实验？ | 怎样用方法描述、流程、工具和规则组织选定活动？ |
| 实践 | 具身的人怎样行动并生活在后果之中？ | 怎样运行、使用计算安排，并读回结果？ |

[从世界理解到实践实现](../diagrams/layers.zh-CN.html)把两组「六种采用的观点＋实践」画成上下
两层，分别以**物理本体**和**计算本体**命名其中的本体节点。物理层的身体、机器、
记录、能量和活动使计算安排获得实现；计算层的表征则通过选取、描述、推理、构造和
使用联系世界。价值承诺指导目标设计，方法指导流程组织，反馈使两者能够修订。

真理在这里有清楚的对象。关于实际生活的陈述，考察其是否符合事实；模型内部的
陈述，按对象的解释及给定条件判断是否成立；从前提到结论的推断，考察其是否符合
采用的推理规则。把模型用于现实，还要考察它的假设与对象的对应。人与语言模型
都可以参与这些判断。真理论阐明成立的含义，认识论考察我们据以接受、怀疑或修正
判断的根据。

因此，证据表示仍须接受经验检验，评价指标仍须回到生活目的，流程执行仍须接受
方法是否适切的判断。结构完备的表示可能不善于解释现象；有预测力的模型也可能
服务我们有理由拒绝的目的。把这两组问题分别写清楚，才能检查它们在哪里相接。

「先考虑心理适切性，再做形式精化」，在问题涉及心理现象时表达一种有用的
研究方向：认出需要解释的东西，再让形式工具澄清、检验候选结构。这些
活动可以交织。适切性意味着回应现象，包括某种解释无法解释的差别；它
不意味着通过奉承式赞同让人舒服。数学有效性与经验适切性保留各自的检查。

偏好可以选择问题、引导注意，或指导工作视图的采用。证据则约束有关对象
的哪些内容可以被接受为真。直觉与溯因可以在全部条件明确之前提出候选；
比较与反馈可以发展或推翻它。上面的认识论名称因此强调起点和可修正性。

## 围绕人调整安排

个人优先设计在要求人承受困难之前，先问困难如何产生。一些困难可以通过
合作安排改变：工作何时发生、决策如何共享，或别人需要接收什么。另一些
需要不同软件或界面。人也可以为自己认可的目的，选择学习、练习或改变习惯。

在要求个人适应之前考虑社会安排与软件，是一种有生产力的方向。它打开了
固定环境可能遮住的替代方案。实际依赖可以要求另一种顺序；问题是在具体
条件下，哪种改变服务目的。

例如，一个解释助手可能把每项调查细节都交给读者。双方可以围绕读者需要
作出的判断重新设计解释，而不把负担过重当作要训练掉的缺陷。模型可以
承担检索与实现，同时让理由、替代方案与重要不确定性变得可理解。人通过
辨认、提问与有意义的决策参与。如果目的是学习调查方法，分配也可以改变。

改进应当通过实际工作评估：人能否理解选择，影响方向，并使用产出的东西？
输出数量与模型的安慰，是不同的观察。

## 社会是人与人的相遇

社会包括影响人能做什么的制度与规范，也包括有自身目的、需要与贡献的
其他人。更适合一个个体的哲学，可以通过揭示被忽略的可能性来改善共有
安排；它也可能把成本加给别人。这些影响需要进入评估。

密尔《论自由》第三章为个性与不同生活试验辩护，同时保留不伤害他人的
条件 [[2]](#source-2)。这提供了把独特发展与多元共处相连接的来源。本文通过可修订工具
与模型支持的实践来发展这一连接。

共有框架可以让人合作，而不要求生活完全相同。标准、稳定接口与共有程序
可以保护有用的连续性；当效果挫败其目的时，它们也应当接受批评。个人
异议是调查关系的机会，而非一切社会约束都有害的自动证据。

模型作为理解与生成的对方参与探究。其参与可以扩大人类能动性，同时保留
独立判断。个人优先的人本主义为安排选择目的，而不要求本人创造每个想法
或亲自执行每个步骤。[太阳、月亮与地球](yinyang-and-taiji.zh-CN.md#太阳月亮与地球)中的构图把这些贡献
与独立世界保持在一起。

## 变化世界里的变化的人

人的理解在发展，工具和社会条件也可能改变。适用于早先相遇的表示，可能
因问题、能力或条件改变而需要修订。保持连续性，意味着保留仍服务实践的
东西，同时让这些差别可以被辨认。

卡尔纳普有关框架采用的论述，关注目的、成果，以及使用语言形式所需的
努力 [[3]](#source-3)。它为表示之间的选择提供比较。
[具身的实验哲学](embodied-experimental-philosophy.zh-CN.md)把这种选择与
参与、后续证据相连接。系统可以支持推理；反思也可以检查边界与目标。
动态表示与模型选择是这份工作的资源，而不是任一模型包含整个生活的证明。

回到那个在通用安排里找不到自己生活位置的人。成功未必意味着他终于学会适应
旧范畴。一份解释可以变得清楚，一个工具可以变得可用，另一种合作方式可以变得
能够维系。人也可以选择艰难地改变自己。人本主义给这些变换以尺度：它们使什么
理解、自愿的能动性与值得从事的活动成为可能，又向其他生命要求什么？

来源贡献上文标明的区分；个人优先给出实践的价值方向，并通过实际后果持续展开和修订。
