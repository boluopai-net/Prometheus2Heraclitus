# 具身的实验哲学

[首页](../../README.zh-CN.md) · [English](embodied-experimental-philosophy.md)

*一个安排在纸面上显得清楚。有人实际经历它，一次小小的迟疑便改变了问题。
修订后的问题，给下一个安排以另一种形状。世界进入了论证。*

哲学可以给实践以概念、意象和理由，使它变得可理解。哲学也可以进入它所
描述的实践。一份有关人和模型应当如何合作的理解，可以改造工作环境；随后，
人通过知觉、注意、用力、行动以及其他人的回应，遇到这个安排。这些相遇
可能揭示原来的理解尚未区分的东西。

**具身的实验哲学**是本文提出的方案：构造一种有意义的安排，参与其中，让
后果同时参与修订实现及其背后的哲学。人的身体生活给探究以具体情境。实验
给所提出的关系一条通路，让它遇到超出自身融贯性的东西。反思发展这场相遇
支持什么，以及接下来应当改变什么。

## 参与与解释

参与一种实践与解释它，提出的是不同问题。读者可能理解注意理论，却在使用
界面时发现解释到来的节奏令人疲惫。另一个人可能轻松使用同一界面，却无法
说明为什么。经验可以揭示有关区分；调查可以考察其条件，并发展解释。

杜威的《哲学的改造》把经验与行动及承受行动后果相连接，并主张一种能够
操作、能够实验的哲学 [[1]](#source-1)。这提供一个哲学起点。本文的当代发展涉及模型支持
的工作：想法可以成为提示词、角色、界面或软件，给参与与解释以共同对象，
使两者相互影响。

具身性让理解发生的条件成为探究的一部分。时间、注意、知觉与行动能力，影响
一个人能够接续什么。解释若在使用时无法跟上，就可能需要另一种表达；意外的
易用性也可能提示理论遗漏的关系。这些观察给调查以需要解释的对象。

模型可以承担实现与调查，人则通过结果作品理解，贡献经验并改变探究方向。
[隐喻、类比与个人的自我改写](metaphor-and-self-revision.zh-CN.md)解释表征与情境中的
角色如何连接这些贡献。分工取决于目的。学习某项技能可能需要练习它；理解
并使用一项作品，则可能适合另一种分工。

## 直觉提出，后果区分

直觉可以在完整解释出现之前辨认不相合之处。也许反复提问打断了工作；也许
自主行动遗漏了只有本人才能作出的选择。每一种感知都打开竞争解释。问题
可能涉及措辞、时机、遗漏事实、工具行为，或不适合的责任分配。

溯因提出能够使观察变得可理解的解释。推理展开其后果。小型构造随后可以使
重要差别变得可遇到。如果假说涉及时机，只改变措辞可能没有检查到它。如果
假说涉及责任，新界面可能因为改变了由谁决策而成功。明确的关系，让实验
能够区分解释，而不只是产生另一个令人印象深刻的输出。

后果需要回应主张。减少打断后任务有所改善，支持的是这份安排在那些条件下
有用；它还不能说明改善来自时机、措辞还是责任变化，也不能说明本人发展了
新能力。要区分这些主张，应考察候选解释预测不同结果的情形。有效推导展开
前提，经验帮助判断前提是否贴合现象；解释和考察解释的方式都可能需要修订。

## 两个相连的循环

**实践循环**连接具体方案、实现、参与与修正。**反思循环**重新考察怎样理解这项
活动：哪些概念与目的在组织它，解释有什么依据，另一种解释会改变什么。它在
当前问题与判断标准下工作，按需要取用哲学论证、工程调查或经验探究。这些名称
组织本文的方案，并不定义双环学习或二阶控制论的技术传统。

实践可以在一次具体失败后改变界面。反思则可以问，失败取决于任务、
呈现，还是人的处境。它可能比较案例或构造更明确的模型。发现可以返回
实践安排。反思进行时，实践也在改变，因此早先结果有其条件与历史，而
不是没有限度的保证。

调查者也参与其中。解释改变读者注意什么；工具改变人可以做什么；提问可以
改变回应。因此，探究需要保留自身干预的有关记录，而不只是接收的结果。
描述这种参与，有助于区分实践的变化与我们对实践理解的变化。

这里的「实验」包括通过制作、参与和反思进行哲学试验。当代实验哲学还有
一种具体的经验研究传统：Knobe 与 Nichols 描述了对哲学直觉背后过程的
系统研究 [[2]](#source-2)。在方法适合时，这类研究可以贡献。尝试个人安排并取得回应，
则构成一种更局部的成就。

## 在当前双环之外推理

两个循环及其关系本身也可以成为探究对象。在已有问题下改善实践，或在已接受的
标准下改善反思，仍保留了一些组织选择。在**当前双环安排之外**推理，则追问
这些选择的理由：为什么这样划分活动，什么应当算作证据，哪些目的应当引导反思？
这种推理能够修订反思循环，重新连接它与实践，或替换这份安排。

形式或计算系统给探究以选定对象、规则、状态和可能的变迁。这种选择使推理
可处理。Ashby 对耦合与循环影响的论述解释动态系统各部分之间的反馈 [[3]](#source-3)；
动态逻辑使行动与变化的状态成为形式推理的对象 [[5]](#source-5)。这些资源帮助理解选定
系统内的工作。本文还把这种选择本身，以及用来评估它的反思安排，一起交给
重新考察。这一步是本文的哲学提议，而非那些技术论述已经确立的主张。

假设助手最大化完成输出的数量，而反思循环比较改善这一指标的方法。
更好的排程改变实践；更好的比较改变反思。但整份安排仍可能把本人一天填满
不再想要的工作。在这一整对循环之外采取一个立场，使人与模型能够追问：
为什么输出数量组织了两个循环，实践与反思的划分是否服务这份生活，哪些
经验应当进入判断？双方由此可以改变反思循环的目的、证据标准或它与实践的
关系，同时改变助手的行为。修订后的安排再次通过后果与世界相遇。

「之外」相对于当前正在考察的框架而言。这份推理仍然借助具体经验、语言、
其他表征与世界。它不提供一个处于所有可能框架之外的位置，也不必被安装为
固定的第三个循环，再成为另一份不受追问的包围。关键是让当前组织方式保持
可被判断和变换。

卡尔纳普对语言框架内部问题与框架的实际选择的区分，提供邻近资源 [[4]](#source-4)。
这里，这一比较帮助区分使用安排进行探究，与重新考察安排及其反思循环的
探究。把这一区分连接到干预和后果，是本文的提议；比较本身不能确立任何
具体修订将如何发挥作用。

## 公开作品作为具体实验

考虑一个假设例子：从持续维护的 GitHub 源，在 Web 上发布一篇哲学文章。
读者沿着图示阅读，发现一条重要箭头像是在表达因果，文字却想表达类比。
他的修正给作者与模型一个具体差别来考察。双方在源处修订关系、解释及
图示，再检查网站实际呈现的结果。若同一误解也影响了助手行为，双方还会
修订有关指令，并检查实际表现。

公开作品已取得足够独立性，使它能够以创作者未曾预料的方式被理解。这个差别
是有关表达的证据；进一步的含义，要看同一关系是否也在组织实际实践。
[三位一体](local-source-and-website.zh-CN.md)把这些返回放进哲学、心理与工程的联系之中。

当一个人选择在微信朋友圈分享作品时，回应同样可能揭示问题或意外解释。这个
圈子提供具体线索，沉默也有多种可能解释，不能当作社会的代表性样本。

## 完成一个版本，留出返回空间

融贯版本给相遇以真实对象。快速迭代在这样的条件下有用：每个版本保留目的
所需的关系，检查针对可能实质改变结果的不确定性。等待总体理论，可能
阻止发展它所需的相遇；发布未经检查的构造，则可能只是在传播错误。可用
版本与适度核验，把速度和学习相连接。

完成与可修订性相互支持。作品可以为当前目的完成，随后在新问题或后果
给出理由时修订。[个人优先的论证](personal-first-humanism.zh-CN.md)解释，为什么
人的理解与能动性的发展给工作以方向。

实验的抱负，是给哲学以接触：让理由成为安排，让安排进入具身生活，让实际
发生的事情返回为理解的材料。世界通过后果参与论证；这些后果不是人和
模型达成共识就可以确定的。

## 来源与范围

双循环组织与例子是本文的综合，不是
已完成实验的报告，也不是模型辅助人类发展的一般性证明。

1. <a id="source-1"></a> John Dewey（1920），**Reconstruction in Philosophy**，尤其第四、五章。[原文](https://www.gutenberg.org/files/40089/40089-h/40089-h.htm)。行动、承受与可操作的哲学探究。
2. <a id="source-2"></a> Joshua Knobe 与 Shaun Nichols（2008），**An Experimental Philosophy Manifesto**，收入 *Experimental Philosophy*，第 3–14 页。[作者托管校样](https://campuspress.yale.edu/joshuaknobe/files/2016/02/manifesto-1qhrtmk.pdf)。当代经验研究传统；链接文件是未校正校样。
3. <a id="source-3"></a> W. Ross Ashby（1956），**An Introduction to Cybernetics**，第四章，尤其第 4/11 节。[遗产管理方授权文本](https://ashby.info/Ashby-Introduction-to-Cybernetics.pdf)。动态系统内部的耦合与反馈。
4. <a id="source-4"></a> Rudolf Carnap（1950），**Empiricism, Semantics, and Ontology**。[公开重印](https://ditext.com/carnap/carnap.html)。框架相关的探究与实际框架采用，在此作为哲学比较。
5. <a id="source-5"></a> David Harel、Dexter Kozen 与 Jerzy Tiuryn（2000），**Dynamic Logic**。[作者导言](https://www.weizmann.ac.il/math/harel/dynamic-logic)。有关程序及其对状态的影响的形式推理。
