# 偏好如何参与选择与推理

[首页](../../README.zh-CN.md) · [核心观点](core-views.zh-CN.md#yy-10) · [English](preference-harness.md)

人遇到的说法、印象与可能性，常常多于当下能够判明的部分。有些相互冲突，有些尚不确定。为了继续，他会判断暂时采用哪些依据、发展哪些可能；偏好已经参与这种判断，却未必已经成为他能够明确说出的自我认识。

YinYang 从人与模型及环境的共同活动中理解这种偏好。模型展开可能性并把选择做成作品，软件、工具与安排使选择获得持续的形式。它们留下的历史，能够让尚未被本人描述的选择方式变得可见。一旦可见，这种方式本身也可以成为检视和改变的对象。

## 选择与推理

描述逻辑的容纳不一致语义，为一种基本判断提供了精确的对照。知识库区分一般公理 $T$ 与断言 $A$。当断言在这些公理下冲突时，修复保留相对于 $T$ 一致、且按包含关系极大的断言子集。冲突断言之间的优先关系可以影响考虑哪些修复；另一个回答规则决定从这些依据中接受什么结论。修复是断言集合，并不是一个解释或可能世界。

例如，假设 $P$ 与 $N$ 互斥，两者都蕴涵 $Q$，而信源同时给出 $P(a)$ 与 $N(a)$。两个修复分别保留其中之一，却都蕴涵 $Q(a)$，所以这个结论可以跨两种依据成立。若偏好只选中前一种依据，还可以据此接受 $P(a)$；这个选择本身并未证明实际对象符合哪一种描述。这一区分依据 [Meghyn Bienvenu 与 Camille Bourgaux 的修复与查询定义，§3](https://arxiv.org/html/2003.05746v5#S3)。

这里借用的是判断结构：暂时接受什么作为依据，这些依据又支持什么。它不描述人怎样进行计算。在实际探究中，信源可靠性的判断、任务中什么更重要、对某种结果的偏好，都可能参与选择，但理由不同；希望某个结果出现，不会使支持它的证据因此变强。尚不能判清全部材料时，可以有条件地采用一部分，保留几个备选，也可以悬置某个结论而继续别处的工作。

这里的**工作视图**指当前为一个问题采用的相关依据与关系，可以用自然语言表达。称它为视图，不等于它已经是形式修复；只有明确了断言、公理、一致性与选择方式，这个形式对照才具有相应内容。

## 偏好通过环境得到扩展

个人环境可以参与偏好，而不只是传递一个早已完整地存在于人内部的偏好。例如，一个人重视阅读的连续性，让模型整理资料库，采用直接通往段落的链接，并在使用中继续修改界面。由此获得的选择和持续阅读能力，通过人、模型、文档与软件共同实现。这套安排又影响接下来什么容易被注意、选择和做成。

在这个意义上，模型参与的活动可以成为**扩展了的人的偏好在运作**。人不必知道每一项实现细节，一套合适的安排也能承接他的方向。要理解的对象就是这种包含工具和条件的选择方式；先剥离环境，反而会删去对象的一部分。

在同一个关系内部，仍然可以区分已经运作的安排、对它的解释，以及本人现在是否认同它。一个默认设置可能已经成为有用的习惯，也可能被重新发现为不想要的限制；模型可能很好地实现了方向，也可能误解了它。这些区别让人能够检视自己的环境，改变偏好通过环境发挥作用的方式，而不必先寻找一个脱离环境的「纯粹偏好」。

## 选择留下什么历史

选中一种说法或设计，会让其他内容退出当前注意。有些印象没有被展开，有些被否决的段落从现行文本中删掉。如果原来的表达或版本已经保存，它们仍属于轨迹。当前视图与它形成的历史，因此承担不同的作用。

Git/GitHub 保存已提交的版本及其父子关系。提交图是版本祖先关系构成的有向无环图，见 [Git 术语表](https://git-scm.com/docs/gitglossary#def_DAG)。分支与差异可以显出当前文件遮蔽的备选与改动。Computer History 则在实际记录范围内，把这些作品与阅读、对话和使用联系起来。[形成一条生命轨迹](flow-and-time.zh-CN.md)展开两者的互补关系。

图中的边表示版本沿革，并不表示「更偏好」。一次合并记录了沿革，却不单凭自己说明选择的理由；从未留下记录的可能性，也不能仅凭图恢复。人可以重新采用旧想法，同时在历史中产生一个新事件。这样，历史能够支持对选择的理解，而无需把历史图直接当作偏好关系。

保留足以理解重要选择的材料：实际遇到哪些备选，采用或搁置了什么，当时的目的与条件，以及对结果的回应。已有来源和版本历史可以承载这些内容，不必把每个一闪而过的可能性都另建成永久文件。

## 让未明说的选择方式变得可见

模型可以比较这些痕迹，归纳本人尚未说清的模式。例如，几次改动都把复杂导航换成直达段落的入口；结合相应请求和使用经过，可能看出一种通过环境维持思路连贯的偏好。模型把具体差异和解释呈现出来，人便有了可以辨认、细化或质疑的对象。

这不只是在收集「我喜欢什么」的直接陈述。选择方式可能早已在仓库、提示词、默认设置或反复采用的工作方法中起作用，而本人尚未清楚认识其内容。模型的理解让这些活动可被检视。这个说明仍然可以修订：同一结果可能有不止一种解释，新的历史也可能改变哪种关系最重要。

材料应足以辨认有关差别。在一篇长论证中选择直接链接，不必意味着不喜欢所有概览。模型的提议、人的纠正和最后采用的安排，显示扩展偏好中的不同贡献。归纳出的模式应始终能回到这些痕迹，而不是经过反复概括就变成没有来由的人格标签。

## 返回偏好，修订选择方式

让模式可见，也改变了什么能够被判断。人可以问：这种偏好还服务于自己的生活吗？它经常排除了什么可能？它的实现带来了什么代价？自己是否想发展另一种选择方式？随后，修改界面或指令可以改变偏好的实际实现，修改目的则可以改变环境要支持什么。

与 Lacan 的接近之处，在这里获得具体内容。在[《主体的颠覆与欲望在弗洛伊德无意识中的辩证法》](https://recherche-lacan.gnipl.fr/2015/07/05/les-ecrits-subversion-du-sujet-et-dialectique-du-desir-dans-linconscient-freudien-1960/)中，后来的能指联系可以参与确定早先的意义。这里，人与自己先前选择的比较相遇，可能发现原来没有表述出的关系，也可能改变对一次旧选择的理解。原事件仍有记录，它在当前说明中的位置却改变了。把这个问题用于模型协助整理的历史，是本文的展开；归纳出一种偏好，并不自动等于作出诊断或找到了隐藏欲望。

<a id="从冲突视图到前提的重构"></a>

这种返回也可以改变组织备选的前提。例如，一个人最初把接受帮助与保留方向看成互斥；自己的合作实践使另一个问题成为可能：怎样组织帮助，让自己能够参与塑造它？这重构了问题，而不只是在旧前提下换一个答案。[言说、对立与自我形成](speech-opposition-and-self-formation.zh-CN.md#模型之间的冲突与问题的重构)展开这种辩证运动。

<a id="冲突中的统一一致视图与共同后果"></a>

共同后果与前提重构仍然是不同的成就。前面的例子中，两种不相容的依据都支持 $Q(a)$，原规则并未改变；重新考虑规则则改变了问题。两种判断都不是人的发展过程的数学描述。YinYang 的核心[交叉参与与返回](yinyang-and-taiji.zh-CN.md)关心的是人和伙伴通过彼此能够重新承担什么，同时保留生成与审查两种可能。

## 偏好、心理与个人条件

偏好材料关心选择、重视、保留和改变了什么，以及这种选择怎样通过环境运作。心理材料关心体验、情绪、认知、关系，以及叙述和测评提供的证据。个人条件包括身体事实、习惯、资源、地点与日常限制。它们彼此联系，同时回答不同的问题。

例如，一个人可能偏好移动工作的安排，在长时间静止时体验疲劳，又有一些任务依赖特定设备。把这些贡献分清，才更容易理解和修订它们的关系。量表结果不决定本人应当重视什么；偏好不单独说明其心理原因；身体条件需要自己的日期与事实依据。

私有的 **Personal** 可以按这些主题组织材料，并保留有根据的解释和来源。六个工作文件再依各自对象取用：方向、人、伙伴、关系、环境与修订。人的文件可以同时考虑偏好、心理材料与生活条件，而不把人缩减为其中一类。[工作模型的形成与修订](../design-and-revision.zh-CN.md)说明怎样让这种理解进入实际合作。

## 在规范与世界变化中完成具体任务

一些备选仍未解决时，具体任务也可以完成。关键在于选定的工作是否回答实际目的，以及未解决的差别是否改变这个结果。历史保留重要的排除，供以后重新检视；它不必阻止当下行动。

## 面向更有能力的模型向前演进

偏好的实现可以随模型能力改变。更有能力的伙伴，可能承担以前依赖额外提示、中间程序或本人监督的工作。让目的保持可理解，并替换已不再有贡献的手段。通过实际使用判断新安排，包括它是否使另一种参与方式成为可能。偏好本身，以及偏好借以扩展的环境，都可以继续修订。
