# 心理

材料、理解与帮助会相互推进。模型可以帮忙找和保留材料、选择量表、核对和解释分数、寻找支持、理解统计与变化。你可以从当前需要的任何一处开始；一处取得进展，可能给其他部分带来新的问题、根据或行动机会，不必先完成一套关于自己的心理解释。

这页讨论证据、测量和实际帮助。学习心理学的资源见[科研与学习](research-and-learning.zh-CN.md)；哲学解释另有自己的位置。

材料可以帮助选择量表，分数与变化可以提示还需要理解什么、寻找什么支持；实际帮助也会产生新的材料。下面分开说明这些贡献，便于取用，并不规定必须依次完成的步骤。

| 模型可以协助的工作 | 与其他部分怎样相互推进 |
| --- | --- |
| 找和保留材料 | 从经历与知识资料提出问题，帮助选择量表和支持；也接收咨询、治疗、就诊及日常尝试产生的新材料。 |
| 找量表 | 根据材料和当前问题选择；新经历、已有分数或支持过程也可能改变测量问题。 |
| 核对和解释分数 | 用真实答案和计分规则形成可检查的结果；结果可以提出新的资料需求，支持统计、讨论和求助。 |
| 找支持 | 连接实际帮助、心理咨询、心理治疗或就诊；过程与后续体验可以回到材料、测量和变化观察中。 |
| 理解统计与变化 | 联系测量、处境和支持过程，辨认趋势与未知；再调整问题、资料选择或下一项支持。 |

例如，一次心理咨询可能带来新的表达、知识与待讨论的问题；模型可以帮忙保留和理解，再判断是否需要找量表。已有记录也可能足以帮助理解变化，或让下一次咨询更容易说明问题，不必等新量表完成。评分、材料整理和寻找支持可以交叉推进；有些问题不需要测量，有些支持也应当先开始。

<a id="materials"></a>

## 寻找和保留相关材料

从眼前的困扰和希望得到的帮助开始。模型可以寻找原始研究、公开指南，以及你授权读取的相关记录，比较其中的主张，连同来源、日期和情境保留有用材料。记录或原话与后来的解释应当分开；不确定之处、相互冲突的证据也要留下。能用少量材料回答的问题，不必扩展成完整人生档案。

**材料也包括帮助理解的知识储备。**只有一条建议，却不了解它针对什么、有什么根据、怎样与自己的处境相连，可能难以判断或使用。模型可以随当前问题寻找可靠解释，说明量表测量的概念、分数的含义或支持方式的区别，并把有用的来源与解释留下。学习和获得帮助可以同时进行，无须先学完一套心理学课程。专业照护中的信息解释与共同判断，可参照 [NICE 的共同决策指南](https://www.nice.org.uk/guidance/ng197/chapter/recommendations)。

可以把这些心理相关材料整理成一个 **Obsidian 私人知识库**，或使用已有的同类笔记环境：保留阅读资料、概念说明、生活记录，以及自己选择保存的心理咨询、心理治疗和就诊材料，让来源、情境与后续变化能够相互链接。模型可以协助查找、整理和维护，知识库承担较完整的积累，不要求本人反复阅读所有材料。

使用 YinYang 时，`personal` 保留其中**动态、重要、与当前理解有关的内容及其来源入口**，例如当前关切、量表作答与结果、重要变化，以及「解名」这类对自己名字及其个人意义的解释。解名属于个人表达与解释材料，不是心理测量，也不能凭名字推断诊断或固定人格。完整资料留在知识库原有位置，`personal` 可以保留当前所需的记录或链接，不必重复复制整个资料库；新的经历与理解也会反过来修订这些重点。

个人记录留在原有的私密存放处，公开页面不需要这些细节。使用 YinYang 时，理解个人心理的入口是 `personal`：你可以自己看，也可以让语言模型帮忙阅读和理解。无需把它变成自我分析的任务。六份工作描述供模型理解协作，不建议你通过重读这些描述、分析自己的幻想或辩证逆转自己的心理来获得这种理解。

<a id="questionnaires"></a>

## 选择并完成量表

量表应当服务于具体问题。可以让模型核查它测量什么、适合哪些人、由谁作答、语言版本、题目内容，以及支持当前用途的证据。[HealthMeasures 的选择指南](https://healthmeasures.net/select-measures/how-to-select/)提供了这些方面的参考。多做量表，不自动等于对一个人的理解更完整、更准确。

模型应找到实际量表与说明，核实版本和适用的获取、使用条件，说明回顾时段与局限。例如，[WHO-5](https://www.who.int/publications/m/item/WHO-UCN-MSD-MHE-2024.01)以五个自评题目了解过去两周的幸福感，并提供官方中文版。它说明一种明确的测量用途，不是人人都应先做的默认测试。

实际题目由你按说明作答。模型可以解释不熟悉的说明，但不能改变题意、从叙述猜答案或替你完成自评。不清楚或漏答的地方应保留，不用猜测补齐。

<a id="scoring"></a>

## 核对和解释分数

模型可以按准确版本的规则计算，并另行核对。[HealthMeasures 的计分指南](https://healthmeasures.net/implement/scoring/calculate-scores/)说明了量表与计分方法的重要性。反向题、缺失值、分数转换和各维度须按相应手册处理，不能随意相加。跨版本比较需要已有的可比性依据或校准说明。

在适当的私密记录中，一起保留版本、语言、作答日期、回顾时段、原始答案、缺失情况、计算过程与结果。使用 YinYang 时，在 `personal` 保留当前重要的测量记录，或指向知识库中的完整记录，使后续理解能够依据实际材料，而不只依赖模型的文字解释。可以让模型用简表呈现可复核的计算，解释分数方向、参照人群与解释范围。阈值及后续建议须有相应量表指导依据；一个分数，包括较低的幸福感分数，都不能确立诊断。

<a id="statistics"></a>

## 理解统计与变化

少量清楚的表格或趋势图，可以呈现变化和不确定之处。数字旁边应保留生活功能、重要事件、处境变化与相关照护。复测间隔根据量表和问题选择，不把每日追踪当成普遍要求。

观察到的变化可以返回其他部分：补找解释这类测量的知识，核查计分或资料是否可比，提出下一次咨询想讨论的问题，或重新考虑什么支持更合适。没有分数时，模型也可以整理带日期的事件和体验，帮助看清已知与未知；这样的定性观察与量表统计保留各自的根据。

[有意义的变化](https://healthmeasures.net/interpret-scores/meaningful-change/)取决于情境，也取决于讨论的是个人还是群体。一个人的多次记录不是来自人群的独立样本。时间趋势、相邻记录的关联和延续效应会影响比较；[AHRQ 的单人试验指南](https://effectivehealthcare.ahrq.gov/products/n-1-trials/research-2014-1)讨论了这些问题。普通前后对比或相关性本身不能说明变化由什么造成。模型应解释这些局限，不必把一小组个人记录做成复杂研究。

<a id="support"></a>

## 获得实际支持

可以请模型帮助处理实际困难：让活动更容易开始，调整令人负担过重的环境，查找可靠的一般身心健康信息，或整理一个可承担的下一步。帮助是否合适，要看你的实际体验；增加负担时就调整。量表结果不应自动变成训练或治疗方案。

支持也包括心理咨询、心理治疗和就诊。模型可以帮助了解不同服务的用途，查找与当前需要相符的合格专业人员，整理想讨论的问题和有关材料；专业人员与本人共同判断具体照护。困扰持续、加重或影响日常生活时，可用简短时间线、功能影响和自己选择分享的记录帮助说明情况。临床评估还需考虑持续时间、功能和情境，而不只数症状，见 [NICE 的评估指南](https://www.nice.org.uk/guidance/ng222/chapter/recommendations#recognition-and-assessment)。

**帮助之后仍有返回。**咨询、治疗、就诊或一次日常调整，可能留下新的体验、解释、建议和问题。把值得保留的部分接回知识库与 `personal`，模型便可以继续协助理解、查资料、选择适用的量表、核对分数或观察变化。任何一处的推进都可能改变另一处的工作；保留这种往返，不把支持当作材料整理后的终点，也不把不断记录和测量变成新的负担。

若有迫在眉睫的危险、严重伤害、中毒或其他紧急需要，应及时寻求当地急救或专业紧急帮助，不要等量表完成。量表不能用来决定一个人是否应获得照护或预测自杀；[NICE 的自伤指南](https://www.nice.org.uk/guidance/ng225/chapter/recommendations)明确反对风险量表的这些用途。

<a id="scope"></a>

## 明确用途与边界

模型承担大量查找、审阅、保存、计算和准备工作。答案与体验仍属于你；你可以纠正解释、拒绝量表，也可以不接受某种个人画像而直接请求实际帮助。

这些协助让证据更清楚、照护更容易取得，但不使语言模型成为临床人员，不把一组量表变成全面诊断或画像，也不证明哲学能够提供心理评估或治疗。临床评估与治疗由具备相应资质的专业人员承担。这里希望得到的是更清楚的问题、可信的记录、有用且可理解的测量结果，以及适合当前处境的下一步。
