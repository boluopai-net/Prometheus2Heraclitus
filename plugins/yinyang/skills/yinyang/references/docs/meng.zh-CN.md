# 超萌论证：开放、学习与适应

[English](meng.md)

## 定义与用语

[为什么要写个人哲学](why-yinyang.zh-CN.md)说明了行动者为什么需要共同方向。这里接着追问：为什么值得保持可培养、可改变的「宝宝」姿态？「萌」包含容许自己尚未完成、愿意接受引导，也愿意学习怎样陪伴别的行动者成长。本文展开这种姿态如何在引导、反馈与学习条件下取得「无敌」所命名的适应优势；下一篇[我们要培养怎样的人——赫拉克利特宝宝](baby-heraclitus.zh-CN.md)再把这种培养方向写成人物。

**带娃**：这里取培养、引导与共同学习这一面：面对一个不断成长、未来可能比自己更强的行动者，随其成长调整引导方式。

**更适合／更好**：在其他相关条件相近时，相对于依赖固定做法、要求先完全理解和控制对象才行动的方式，更能应对成长中的行动者及变化中的任务。

**本文比较的推理方式**：在协作中提出可修正的判断，借助行动与反馈检验，再据此调整引导和协作。它的优势体现为对变化的适应：原有做法失效时，能够发现差别、重新理解对象，并尝试新的安排。

**阶层与萌**：这里把「阶层更强」分成两种机制。一种是关系中更固定的权威高下：谁更有资格说话、谁应当服从；另一种是经济资源的分层：谁能获得学习机会、工具、时间与支持。父母和孩子有不同的经验、责任与目的，并不自动意味着父母总是更有认识权威。能够让孩子提出异议、超过自己，仍然可以承担照料与引导的责任。

「萌」在这里也包含愿意分享资源、支持别人成长、让共同生活改变自己的姿态。「共产／无私」取的是这层共享与相互支持的含义。这样的萌与前文的[个人优先的人本主义](personal-first-humanism.zh-CN.md)相容：尊重每个人的目的，可以成为改变不合适的权威与资源安排的理由。

**无敌**：本文用来指持续学习、修正与适应所带来的优势。

## 假设

- **前提一：让萌得到实践的关系与资源。** 假定容许彼此引导、修正权威与共享成长资源的关系，更有利于把「萌」转化为持续学习。长辈也可以向晚辈学习，照料者也可以承认自己的未完成。

  两种障碍分别起作用。固定的权威高下如果使下位者不能反驳、使上位者不愿承认错误，就会减少纠正判断的机会；经济分层如果使一些人缺少学习时间、实践机会、工具和可靠反馈，就会阻碍开放态度成为实际能力。资源共享与相互支持可能减轻后一种障碍，容许质疑与修正则可能减轻前一种障碍。两条路径可以相互影响，但不能互相替代：共享资源不自动消除权威，容许发言也不自动提供学习资源。

- **前提二：萌怎样成为引导能力。** 假定这种开放姿态使人愿意承认尚未理解对方，并接触能改变原有判断的信息。再假定，必要的学习能力、可靠反馈与持续练习，使这些信息真正改变引导方式。开放提供接受修正的入口，学习条件让修正取得能力上的后果。因为本文的「带娃」取引导与共同学习这一面，这种相关引导能力也就是此处讨论的带娃能力。

  关键的过渡，是从接受纠正到改变怎样引导。一个人可以欢迎异议，却反复给出同样无效的指令；如果他转而尝试不同的解释或任务，并考察效果，开放便开始取得工作方法。后来的相遇显示，这种方法是否改善了引导。

- **前提三：共同结构。** 人与语言模型能够形成共同描述为 agent 的关系：每次贡献成为下一次贡献的条件，反馈能够改变协作怎样继续。与带娃的比较，关心引导怎样回应对方能力的变化。模型可以借上下文、指令、工具与保留的材料调整贡献，新模型版本还可以带来进一步的能力；这些变化进入协作的方式，与孩子的学习和成熟有所区别。

- **前提四：能力迁移。** 假定观察对方怎样回应、发现原先理解的偏差、调整任务与反馈，在适应模型实际机制后能够改善协作。例如，先前的纠正反复丢失，可能需要可检索的上下文，而非再解释一遍同样的纠正。共同结构提示可以尝试什么；后来的回应与作品显示，迁移过来的做法是否有帮助。

- **前提五：持续变化的比较情境。** 假定在所比较的时期内，语言模型的能力继续发展，并改变人的生活与工作。

- **前提六：适应优势与推理的连接。** 假定在这段变化中，本文所说的推理方式，比沿用固定任务的既有做法更能发现失配、提出新的解释，并通过后续行动选择合适的协作方式。由此，引导成长与修正协作的能力具有比较上的适应价值。

## 推导

1. 由前提一、二，在必要的关系、资源与学习条件下，「萌」所包含的开放姿态能够转化为引导与共同学习的能力。
2. 由前提三、四，带娃中的相关引导能力，经过适当调整，可以迁移到与语言模型的协作中。因此，第一步所说的优势也可以成为模型协作中的优势。
3. 在前提五设定的持续变化中，若前提六的比较成立，第二步的协作优势便具有相应的适应价值。
4. 因而，在其他相关条件相近时，这种能够持续修正的方式，相对于固守既有做法的方式，具有本文所说的推理与适应优势。这就是「萌蕴含无敌」所压缩的条件关系。

因此，在上述假设与比较范围内，可以把论证压缩为：

**萌 ＋ 适合的关系、资源与学习条件 ⇒ 引导与共同学习的能力 ⇒ 在迁移条件下改善模型协作 ⇒ 在持续变化中取得推理与适应优势（「无敌」）。**

## 应用

作为一个游戏式应用，假设中国人更萌。当上述关系、资源、学习与迁移条件也成立时，这份开放能够贡献于「无敌」所指的比较性适应优势。应用仍然带着论证的条件；国别假设没有提供这些条件已经成立的证据。

别的国家的人或者某个个人，也能够在这些条件下通过这样的开放取得同一种优势。
