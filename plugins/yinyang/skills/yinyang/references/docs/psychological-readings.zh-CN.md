# 心理阅读

[English](psychological-readings.md) · [哲学阅读](philosophical-readings.zh-CN.md) · [工程阅读](engineering-readings.zh-CN.md)

本指引提供表达经验、比较心理解释及检验解释的方法。经验与案例可以从
[心理冲突、关系与改变](#心理冲突关系与改变)及其中易读书目进入；
拟议的过程模型接到建模与经验检验，跨相遇的变化接到信念与互动研究。
这些是按问题选择的入口，不是强制课程，也不是现成的个人模型。
[形成与修订](../design-and-revision.zh-CN.md)说明相关证据怎样支持情境化描述。

书目以作者、出版社和公共原文为入口，注明通俗读物、专业教材或研究论文的用途。出版社书目与试读不等于免费全文；年代较新与作者知名，也不单独证明一种解释适合当前问题。

## 心理过程建模与经验检验

Guest–Martin 与 Borsboom 等帮助明确理论；研究方法教材与 Wilson–Collins
用证据检查模型，Farrell–Lewandowsky 提供较完整计算示例。按当前问题选择所需贡献。

| 书或论文 | 从哪里读，帮助理解什么 |
| --- | --- |
| Guest 与 Martin（2021），[How Computational Modeling Can Force Theory Building in Psychological Science](https://doi.org/10.1177/1745691620970585) | 从理论、形式规格到程序实现的关系。看见建模时补入的假设，以及这些假设怎样反过来推动理论。 |
| Borsboom 等（2021），[Theory Construction Methodology](https://doi.org/10.1177/1745691620969647) | 从现象、解释到形式模型与检验的理论构建方案。可以借用其区分，同时让形式化和经验探索往返进行。 |
| Jhangiani 等，[Research Methods in Psychology，第 4 版](https://kpu.pressbooks.pub/psychmethods4e/) | 开放教材。优先看心理测量、信度与效度、实验与非实验设计、单一被试研究；区分观测到的变化与对变化的解释。 |
| Wilson 与 Collins（2019），[Ten Simple Rules for the Computational Modeling of Behavioral Data](https://elifesciences.org/articles/49547) | 开放论文与代码。用模拟、参数恢复、模型恢复和预测检查，判断数据能否区分候选模型；拟合得好不独立证明机制正确。 |
| Farrell 与 Lewandowsky，[Computational Modeling of Cognition and Behavior](https://assets.cambridge.org/97811071/09995/excerpt/9781107109995_excerpt.pdf) | 出版社第一章试读；[作者配套代码](https://github.com/psy-farrell/computational-modelling)连接计算模型、估计和模型比较。适合从一个小模型开始动手。 |

实验设计和测量为何能回答问题，在这里阅读；实验怎样编程、记录和复现，接到[工程阅读](engineering-readings.zh-CN.md#实验实现数据与模型检验)。同一实验同时需要两方面，运行成功与解释成立是不同的结果。

进一步理解认知解释时，可读 Marr 的 [Vision 第一章](https://mitpress.mit.edu/9780262514620/vision/)与 [Probabilistic Models of Cognition](https://github.com/probmods/chapters)：前者区分计算任务、表示与算法、物理实现，后者把生成模型、条件化和推断连接到程序。这两项需要更多技术背景。

## 心理冲突、关系与改变

环境和关系变化时，原有愿望、承诺、习惯与新的处境可能彼此拉扯。这里收录几种理解冲突的方式：想改变又想维持现状、不同需要之间的矛盾、自我批评与保护、对同一个人的爱与敌意，以及知道一件事却难以据此行动。它们并非同一种机制，也不都意味着疾病。

### 较容易进入的书

| 作者与书 | 阅读入口 |
| --- | --- |
| Russ Harris，[The Happiness Trap，第 2 版（2022）](https://www.shambhala.com/the-happiness-trap-second-edition.html) | 普通读者入口。接纳与承诺疗法（ACT）怎样理解与想法、情绪的纠缠，以及价值与行动的关系；比直接进入理论手册容易。 |
| Richard C. Schwartz，[No Bad Parts（2021）](https://us.macmillan.com/books/9781683646686/nobadparts/) | 普通读者入口。内在家庭系统（IFS）以「部分」及其保护作用理解自我批评和内部对立；把它作为一种治疗模型来读，不把比喻直接当成已证实的心灵构造。 |
| Jeffrey E. Young 与 Janet S. Klosko，[Reinventing Your Life](https://www.penguinrandomhouse.com/books/327709/reinventing-your-life-by-jeffrey-e-young/9780452272040/) | 图式取向的通俗入口。通过案例理解反复出现的生活模式、需要与应对方式，再与下面的专业图式疗法教材对照。 |
| Karen Horney，[Our Inner Conflicts／我们的内心冲突](https://wwnorton.co.uk/books/9780393309409-our-inner-conflicts) | 经典入口。关注趋向他人、对抗他人和远离他人的拉扯，理解关系策略怎样冲突；书中的历史诊断词汇需要放回其时代。 |

### 现代心理治疗：冲突怎样被理解与改变

这里以近几十年发展的治疗取向及其更新教材为主；「现代」不等于每本书都刚出版。专业书可以先读概念、案例与对话，再决定是否深入技术。不同取向的证据基础并不相同，并列收录不表示疗效相同。

| 取向与代表书 | 可以带着什么问题读 |
| --- | --- |
| ACT：Hayes、Strosahl 与 Wilson，[Acceptance and Commitment Therapy，第 2 版](https://www.guilford.com/books/Acceptance-and-Commitment-Therapy/Hayes-Strosahl-Wilson/9781462528943)；Harris，[ACT Made Simple，第 2 版](https://www.newharbinger.com/9781684033010/act-made-simple/) | 专业理论与较易读的实践导论。内在体验不必先被消除，行动怎样围绕价值展开？重点看心理灵活性、认知解离、接纳与承诺行动。 |
| DBT：Marsha M. Linehan，[DBT Skills Training Manual，修订版（2025）](https://www.guilford.com/books/DBT-Skills-Training-Manual/Marsha-Linehan/9781462556359) | 专业技能教学手册。接纳与改变怎样同时成立？看正念、人际效能、情绪调节与痛苦耐受的组织方式。配套练习表另册出版，不能把书目当成已经取得全部材料。 |
| 图式疗法：Young、Klosko 与 Weishaar，[Schema Therapy: A Practitioner's Guide](https://www.guilford.com/books/Schema-Therapy/Young-Klosko-Weishaar/9781593853723) | 专业教材。需要、早期图式、应对方式与不同模式怎样组织反复的内在及关系冲突；与通俗的 Reinventing Your Life 配读。 |
| IFS：Schwartz 与 Martha Sweezy，[Internal Family Systems Therapy，第 2 版（2019）](https://www.guilford.com/books/Internal-Family-Systems-Therapy/Schwartz-Sweezy/9781462541461) | 专业教材。进一步看不同保护性部分的对立、关系与变化；第 11 章专门讨论保护者之间的极化。 |
| 情绪聚焦：Leslie S. Greenberg，[Emotion-Focused Therapy: Coaching Clients to Work Through Their Feelings，第 2 版](https://www.apa.org/pubs/books/emotion-focused-therapy-second-edition) | 专业教材。区分情绪的作用与表达，理解自我批评、未完成的关系体验及情绪转化；这里指 Greenberg 的 emotion-focused 路线。 |
| 动机式访谈：William R. Miller 与 Stephen Rollnick，[Motivational Interviewing，第 4 版（2023）](https://www.guilford.com/books/Motivational-Interviewing/Miller-Rollnick/9781462552795) | 助人工作与专业实践读物。围绕「想改变，也有理由不改变」的矛盾动机，看参与、聚焦、唤起与计划怎样展开，而不是替对方选定目的。 |
| 连贯性疗法与记忆再巩固：Bruce Ecker、Robin Ticic 与 Laurel Hulley，[Unlocking the Emotional Brain，第 2 版（2024）](https://www.routledge.com/Unlocking-the-Emotional-Brain-Memory-Reconsolidation-and-the-Psychotherapy-of-Transformational-Change/Ecker-Hulley-Ticic/p/book/9781032139128) | 进阶理论与案例。理解有意识的改变愿望与隐含情绪学习之间的冲突；区分记忆再巩固研究、作者的临床解释与具体方法的效果证据。 |
| 心智化：Carla Sharp 与 Dickon Bevington，[Mentalizing in Psychotherapy（2022）](https://www.guilford.com/books/Mentalizing-in-Psychotherapy/Sharp-Bevington/9781462549962) | 专业实践导论，含对话与案例。关系紧张时，人怎样理解自己与他人的心理状态，怎样保持可以被修正的解释；不把猜测他人的内心当成确定知识。 |

### 经典冲突理论与精神分析

| 作者与原典 | 阅读用途 |
| --- | --- |
| 弗洛伊德，[精神分析引论，第 XXIII 讲](https://www.gutenberg.org/cache/epub/38219/pg38219-images.html)；[The Ego and the Id／自我与本我](https://web.english.upenn.edu/~cavitch/pdf-library/Freud_SE_Ego_Id_complete.pdf) | 从相反倾向形成妥协，以及不同认同、现实要求与自我理想之间的压力理解冲突。这些是历史理论原典。 |
| 弗洛伊德，[Mourning and Melancholia／哀悼与忧郁](https://web.english.upenn.edu/~cavitch/pdf-library/Freud_MourningAndMelancholia.pdf) | 观察爱、敌意、认同与自我责备怎样在解释中相连；不能把一种历史解释直接套到所有悲伤经验。 |
| Melanie Klein，[Notes on Some Schizoid Mechanisms（1946）](https://melanie-klein-trust.org.uk/resources/reading-list-paranoid-schizoid-position/) | 基金会原典阅读入口。理解分裂、投射与同一对象的不同面；与较早的抑郁位置论述对照，不把各家的「分裂」当成同一个概念。 |
| D. W. Winnicott，[Playing and Reality](https://www.routledge.com/Playing-and-Reality/Winnicott/p/book/9780415345460)；[Ego Distortion in Terms of True and False Self](https://academic.oup.com/book/12894/chapter/164044466) | 创造与遭遇之间的过渡空间，以及顺从、自发性和真／假自体的关系。保留有意义的张力，区别于接受任意矛盾断言。 |
| Nancy McWilliams，[Psychoanalytic Diagnosis，第 2 版](https://www.guilford.com/books/Psychoanalytic-Diagnosis/Nancy-McWilliams/9781462543694) | 专业概念与案例参考。比较人格、防御与关系的组织方式；分类不是对陌生人的自动判断。 |

弗洛伊德、拉康及意志、自我欺骗问题的哲学讨论，另见[哲学阅读](philosophical-readings.zh-CN.md)。这里的书帮助理解经验与关系；阅读专业教材与开展专业治疗是不同的事情。

## 信念、推理与互动研究

这里连接「怎样更新解释」与「互动中实际怎样变化」。逻辑给出规则下的关系，心理研究考察实际过程；两者互相启发，但不能互相代替证据。

| 论文或参考 | 阅读用途 |
| --- | --- |
| [Logic of Belief Revision](https://plato.stanford.edu/entries/logic-belief-revision/) | 以 AGM 等框架理解加入、撤回和修订信念的不同问题；形式合理性与实际人的变化保持区分。 |
| [Dynamic Epistemic Logic](https://plato.stanford.edu/entries/dynamic-epistemic/) | 比较信息事件、知识与信念状态及更新；公开宣告不代表所有实际互动。 |
| De Jaegher 与 Di Paolo（2007），[Participatory Sense-Making](https://doi.org/10.1007/s11097-007-9076-9) | 把互动过程、协调与意义生成放进解释，比较只分别描述双方内部状态会遗漏什么。 |
| Fonagy 与 Allison（2014），[The Role of Mentalizing and Epistemic Trust in the Therapeutic Relationship](https://discovery.ucl.ac.uk/id/eprint/1428567/) | 作者机构稿件入口。连接理解心理状态、认识信任与社会学习；这是特定理论论述，不是所有互动有效性的证明。 |

### 冲突、分区与动态修订的研究

| 论文 | 继续追问什么 |
| --- | --- |
| Elga 与 Rayo，[Fragmentation and Information Access](https://www.princeton.edu/~adame/papers/fragment/fragmentation-and-information-access-2019-10-29.pdf) | 2019 作者稿，对应 2021 年章节。拥有信息与当前能够调用信息有何区别？不同情境中的信念怎样被分开组织？ |
| Grodniewicz（2024），[Belief Revision in Psychotherapy](https://doi.org/10.1007/s11229-024-04523-0) | 哲学论文。为什么一处形成的新理解，未必自动推广到其他情境？不是疗效试验。 |
| Mansell 与 Huddy（2020），[Psychological Change and Recovery 的计算模型](https://doi.org/10.3389/fpsyt.2020.00624) | 理论与模拟。不同目标对同一个被控制变量提出不相容要求时，冲突与重组怎样表示？ |
| Kronemyer 与 Bystritsky（2014），[A Non-Linear Dynamical Approach to Belief Revision in Cognitive Behavioral Therapy](https://doi.org/10.3389/fncom.2014.00055) | 动态系统与信念修订的理论提议。用来比较变化过程的解释，不把它当成已经验证的通用治疗机制。 |

这些资源帮助把「心理建模」展开为可学习的工作：提出解释、明确关系、寻找能够区分解释的材料，并在互动与结果中修订。它们与[三位一体](local-source-and-website.zh-CN.md)中的哲学理解和工程实现相接。
