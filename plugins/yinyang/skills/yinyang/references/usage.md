# Use in the actual environment

This distributed copy provides writing guidance. The situated version is a
concise, grounded bridge from the core models to daily work: how this person and
counterpart participate through their actual workspace, memory, capabilities,
and resource routes. Link domain Skills for their methods and check the account
in real use rather than filling a tool inventory. The [entrypoint](../SKILL.md)
owns the ordinary initial-reading duty.

Inquiry can return to philosophy or personal evidence. Philosophy and website
authoring give the affected argument and page their needed depth, then return
supported changes to the core. Keep formation methods with their common owner,
developed portraits in [models](models.md) and [relationship](relationship.md),
and evidence in [sources](sources.md) and [private provenance](personal/README.md).
Link rather than repeat their content.
