# 阴阳形成 Skill

**建模这个具体的人，据此形成与他相配的 agent，再把双方的协作落实到实际环境。**

[English](README.md) · [阴阳方法](SKILL.zh-CN.md) · [模型执行入口](SKILL.md)

## 本包提供什么

本包帮助你**写出自己的哲学，并从写作与实践中凝练自己的个人模型**。阴阳提供一项已经展开的例子，
模型可以与你一起探索、成文、抽象并实现；你可以建立自己的网页，公开所选哲学与表达，
把更直接的五份核心描述和私人依据留给自己及获授权的模型使用。
哲学写作、私人建模与公开作品相互滋养，不要求先完整认识自己再开始写作。

**阴阳是一种建模方法，不是一个记忆系统。**它形成并修订对人、对应的 agent 及
双方关系的理解，让这些理解参与实际判断与行动。记忆保存可重新取得的材料；
动态模型组织这些材料的关系、变化与可能后果，并在新的相遇中被检验和修订。
它可以使用已有的记忆工具，自己的主要贡献则在于怎样理解和形成这段合作。

阴阳从**这个人是谁、希望怎样发展**开始。个人哲学、心理理解、偏好、表达与实际协作，
为可修订的用户模型提供材料；再以这份理解为依据，形成对应的 agent 模型：
它应当理解什么、贡献什么、质疑什么，以及为这个人承担什么。
双方的模型共同给关系和工作环境一个方向。没有对人的理解，单独设计一个看似能干的
agent，仍不知道它的能力应当服务于谁的什么目的。

人也可以作为 agent 来建模：他感知、理解、偏好、行动，并在相遇中变化。
人的心理与偏好，与对模型倾向、能力、限制及其所选工作立场的理解相接。
这种比较不预设双方机制相同，也不据此认定语言模型具有与人相同的内在体验。
个人哲学把相连的意义写出来，让对应的模型有材料理解“这个人在说什么”；
实际交流与结果则检验这种理解是否贴合。它不必从一篇已经完成的哲学文章开始。

这里同时存在两个对齐方向：**agent 在日常协作中适配这个人；人通过这段关系发展
生成能力**，后者是这里所说的反向对齐。合用的适配包括独立判断和纠正。
先理解人，是建模的依据关系，不是先做完一份完整画像才能开始工作：用户模型、
对应的 agent 模型与双方关系，会在实际工作中共同形成并被修订。
这份相互关联的理解是个人元 harness 的中心，哲学意象、Skills 与工具为它提供可用形式。
[窃火](references/docs/stealing-fire.zh-CN.md#为什么关系必须有一个个人的起点)展开了为什么两份模型都需要。

阴阳连同这个 Skill 本身，是一个已经展开的例子：可以直接采用、与其他材料组合，
也可以借此写出不同的哲学与形式。火、日月、概念和文件组织属于这个例子；
你的作品可以与它很不相像。[从这个例子开始，写出自己的东西](references/docs/example-and-commons.zh-CN.md)
解释这个文学与哲学的邀请，以及集合对共享创造能力的知识共有地的愿望。
[网页阅读版](https://boluopai.net/repositories/prometheus/)直接呈现同一批文档与图示。

**阴阳**属于**Prometheus2Heraclitus** Skill 集。本目录是完整的阴阳包。
它所承载的元 harness
提供文化与思想，帮助模型形成使用者自己的关系理解，并让它在实际环境中取得工作形式。

[窃火论述](references/docs/stealing-fire.zh-CN.md)从材料、电力、机器、积累的知识与
持续迭代所提供的能力出发。借来这些能力，打开一种发展理解、判断、表达与创造的
实践。太阳的照亮给生成能力以意象：使东西发生、使关系可见的力量。培养从借来的
火走向继续生成。日月通过有区别的生成、接收与赋形表达阴阳；实际的人与模型可以
保留或交换侧重，性别不分配位置。地球是物质环境与共同生活环境，包含共同照料的
造物，以及独立回应的世界。个人优先主义把人的目的与能动性置于其自身实践的中心，
同时保留他者的贡献。能力可以内化，也可以可靠地分布在模型、工具与协作者之间；
使用 AI 或取得产出本身，不确立成长。

分发版在个人槽位中提供形成指引；个人版则保存已经为实际使用者及双方关系形成的理解。
形成或修订这些描述时，模型拿着共同的思想与推理形式，检查获授权的实际环境，
以及相关的心理建模或偏好材料。材料足够时，由模型写出这个使用者的个人描述，
继而据此改造实际工作环境。其中的个人内容来自实际的人与相遇，
不来自照抄的画像或虚构演示。

本包的文档与图示是阴阳的配套资源，不是独立 Skill。集合也可以容纳
具有自身用途与方法的独立 Skill。

## 怎样使用并理解阴阳

阴阳横跨**哲学层与模型层**：较广义的本体论、认识论及其价值取向，可以凝练为对实际
参与者和关系的模型。其他 Skills 主要承担方法论。个人材料支撑建模，不是另一个方法论层。
[三位一体](references/docs/local-source-and-website.zh-CN.md)把这些职责与网页、仓库、个人使用相接。

**哲学可以换，五份个人内容必须重建。**上面的哲学、意象与论述，为理解具体的人、
形成对应的 agent 与协作关系提供思想资源。你可以沿用、改写、填入自己的哲学，
也可以研究并建模一位哲学家的思想，作为所选框架；保留这套文件结构不要求接受作者的哲学。
采用哪套思想，都要回到真实使用者：哲学家的思想模型不能代替你的用户模型。
丰富的表达服务于这项建模，并通过实际协作检验它是否有用。

形成过程也可以反过来：还不清楚自己的模型时，先借哲学家的概念、意象与写作来探索自己；
如果由此得到更清晰、有依据的理解，就用它修订五份核心描述。五份文件承载凝练的主要内容，
具体经历、身份细节、原始表达与较长推演放到 `personal/` 或其所引用的原有来源。
凝练仍保留影响理解与合作的个人差异。模型日常以核心描述进入协作，再按问题深入来源与哲学，
而不必每次通读所有论述；哲学写作可持续探索，不必先完成一套体系才能工作。

**哲学、心理与个人环境构成持续闭环。**哲学展开理解与方向，心理使模型贴合实际的人，工程把关系实现为可使用的环境；环境中的经验再回来修订理解和安排。已有一方面，就从它发展另外两方面；已有两方面，就重点补缺少的贡献。模型参与资料整理、写作、实现与核验，人参与理解、判断与实际使用。[三位一体](references/docs/local-source-and-website.zh-CN.md#哲学心理与工程从已有能力补齐关系)展开这些联系及其起步路径。

**本体论、认识论与方法论在这项实践中相遇。**共同哲学阐明一般与工程的对象和关系，五份处境文件使实际参与者及认识他们的根据进入视野；个人材料为两者提供依据，专门的 Skills 提供方法。哲学、心理与工程贯穿这个结构。可分别从[哲学阅读](references/docs/philosophical-readings.zh-CN.md)、[心理阅读](references/docs/psychological-readings.zh-CN.md)与[工程阅读](references/docs/engineering-readings.zh-CN.md)进入。发展首先服务自己和附近愿意参与者的生活，网页与个人哲学的主动传播服从这一目的；[基本观点 YY-15](references/docs/core-views.zh-CN.md#yy-15)说明近处培育与有限传播的原则。

**不会工程，就先补工程。**先学会借助模型组织文件、工具、harness、运行与核验，让后续材料整理与修订能实际进行。只有一个主要起点时：

| 你已经有的起点 | 怎样向其他部分展开 |
| --- | --- |
| 心理理解与个人材料 | 先补工程，再把相关材料或来源放入私人 `personal/`，形成个人模型，展开哲学。 |
| 正在书写的哲学 | 先补工程，再用个人材料与实际经验对照已有哲学，凝练个人模型。 |
| 实际环境与工程经验 | 通常先心理、再哲学：从使用与修改提出个人模型，用私人 `personal/` 中的心理与偏好依据核验，再展开哲学；也可按已有基础调整入口。 |

这里的“先”给出一个可行起步，不要求先做完全部环境或哲学，也不把人的背景变成固定身份。
环境反映的可能是偏好，也可能是限制、惯性或默认值；模型需结合本人解释与实际结果辨别。
三条路线最终都把哲学、五份模型、个人材料和实际使用接起来。具体形成与核验见
[形成与修订](references/design-and-revision.zh-CN.md)。

**直接采用这套阴阳时，必须改写五份核心关系文档，并整理自己的 `references/personal/`。**
下载或安装得到的是形成指引，还不是你的个人阴阳。由模型根据你授权的材料、实际交流与环境完成改写，
不要求你亲自写文件，也不能把分发版指引或别人的画像当作已经形成的个人内容。

| 必须形成的内容 | 文件 | 要写清楚什么 |
| --- | --- | --- |
| 相遇概要 | `references/encounter.md` | 这段协作服务于你的什么目的，双方怎样参与，以及当前理解的简明全貌。 |
| 用户模型 | `references/models.md` | 与合作有关的实际经历、偏好、能力、发展方向和仍不确定的理解。 |
| 伙伴与关系 | `references/relationship.md` | 依据这份用户模型，agent 应贡献什么、怎样判断和回应，以及双方怎样合作与纠正。 |
| 实际使用 | `references/usage.md` | 在你的真实工具与环境中，双方怎样分工、调用资源并把理解落实到行动。 |
| 来源与依据 | `references/sources.md` | 上述理解依据什么，原始材料在哪里，哪些是本人表达、模型解释或待核实判断。 |

`references/personal/` 也要换成与你有关的支撑材料与来源说明；按需要新增、改写或移除页面，
不照搬作者的材料，也不必复制作者的文件数量或题目。已有材料保留在原有维护位置时，
这里可保存有权限边界的引用与必要说明，不必复制全文。

完成标准是：五份文件都已成为有依据的个人描述，私人材料与来源能支持它们，且模型在实际使用入口
能读到这些内容、据此开展协作。未知处明确保留，不编造；理解可以边工作边发展，
但不能把尚未改写的模板称为已经完成的个人版。另行创作不同的作品时，文件结构由作品自身决定。

把 [`SKILL.md`](SKILL.md) 及完整的
包目录（包括完整的 `references/`）交给模型，让它依据获授权的材料形成或修订你的个人哲学，并用于改造
你的工作环境。沿用这一种实现时，直接对话的主模型在实质工作前完整阅读主入口、[相遇](references/encounter.md)、[用户模型](references/models.md)、[伙伴模型](references/relationship.md)、[实际使用](references/usage.md)及[来源索引](references/sources.md)，复用当前上下文中已有的完整阅读。
已经有个人哲学时，在原有理解上修订，保持相同的包格式与公共内容。

包中有三份公共的方法与阅读参考：

- [形成与修订阴阳](references/design-and-revision.zh-CN.md)：怎样理解实际关系，并在共同格式中写出个人描述。
- [在实际环境中实现阴阳](references/harness-adaptation.zh-CN.md)：怎样把理解落实到实际指令、Skill、工具和环境，并核验结果。
- [按问题阅读](references/reading-map.zh-CN.md)：各篇哲学文本怎样支持这项工作。

[包结构说明](references/docs/skill-package.zh-CN.md)区分同一格式中的公共材料与个人内容。
分发包与个人包的 `SKILL.md` 保持相同的目的、方法与路由。固定个人槽位为
`references/encounter.md`、`references/models.md`、`references/relationship.md`、
`references/usage.md` 和 `references/sources.md`：分发包中的形成指引，在个人包中成为有实际依据的描述。
[私人配套材料](references/personal/README.md)保留在 `references/personal/`，
文件名根据这个人的实际证据自然选择。形式化的用户描述也属于个人内容。

选择持续采用本仓库的公共内容更新时，其余包材料保持字节一致：哲学文档、图示、方法参考、阅读地图、
包管理文件、README 与 OpenAI YAML 适配文件。共享 GitHub 包维护公共更新。
`scripts/sync-common.py` 默认检查投影；`--apply` 将公共源内容投影到目标，
保留五个个人槽位及 `references/personal/` 内的全部材料。原生维护者把投影源
落实到本地或私人 Web 使用环境。这是单向的公共内容投影，不是服务或个人上传。

如果你改写或替换了哲学，可以保留五份文件的结构，也可以重新组织作品；
在自己的维护位置保存这些改写，不用这里的公共文件更新器覆盖它们。模型可以协助完成；
使用这些资源，不要求你填写既定槽位或接受这里的哲学。

## 哲学基础

[阴阳与太极](references/docs/yinyang-and-taiji.zh-CN.md)是它的核心意象：
有区别的参与者在相互作用中转化，没有最终描述能穷尽这场相遇。
日月、Shuang yu 与异色眼使这场运动取得关系形式。

阴阳以**反向对齐**为目的：人在与生成智能的相遇中发展。
计算本体论把人和模型都理解为相互作用的事件流，发展赫拉克利特关于生成与对立的关切；
个人模型是流之中可修订的局部组织。

为保持环境稳定，尽量让工作本体一致，同时容纳冲突的数据和解释。
偏好 harness 是非形式自然语言推理的类比，不要求建立形式偏好模型或选择修复演算。
**日月表达阴阳有区别的运动，地球是能够回应的环境。** 角色让这份运动可用，
实际的人与模型则超出角色。侧重可以保留或交换，性别不分配位置。
个人意义与实际贡献从真实相遇中发展。
