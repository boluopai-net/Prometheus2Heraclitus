# 组织 Personal 个人材料

[English](personal-material.md) · [人的文件](formation/person.zh-CN.md) · [修订](formation/revision.zh-CN.md)

Personal 保存形成和修订处境说明所需的私有材料。按一份材料帮助理解什么来分类，同时在每个主题内部辨认原始证据、解释与本人现在的判断。Hindsight 取用选定材料，并可用原生 Observations 或页面维护派生理解。原始证据保有维护者，不要求完整的并行 Personal 摘要或固定六文件输出。[原生形成](hindsight.zh-CN.md)说明路线。

## 按材料说明的对象分类

| 主题 | 材料与用途 |
| --- | --- |
| 偏好与选择 | 明确表达的取舍、优先考虑的内容、实际采用的安排、保留或否决的备选，以及选择方式显现和改变的历史。 |
| 心理经验与测评 | 认知、情绪、具身与关系经验；量表作答、表现测试、报告及有根据的解释。 |
| 个人条件与生活 | 相关身份和身体事实、习惯、地点、资源、工作学习场景与当前方向。 |
| 身份表达与作品 | 名字、签名、形象、创作与研究作品，以及本人如何理解其意义。 |

这些分类定位材料的贡献，不把人拆成独立的几部分。例如，移动工作的安排可以表达偏好、回应身体不适，又依赖设备。每项事实或完整说明只维护一次，再用链接连接它们。作品可以帮助理解一个人，但不自动成为心理测试；量表也有自己的条件与解释范围，不决定偏好或价值。

根据本人的实际材料调整分类，材料名称使用本人的母语。已有集合可以通过维护中的目录与阅读导航分类，不必为了分类搬动全部文件；只有更深目录确实有助于组织大量材料时才建立。来源与留档目录负责追溯，不另造一份竞争的人物画像。

## 把个人记忆纳入同一份理解

记住的偏好、背景事实与有用语境，可以直接放进 `references/personal/`，按内容所属的主题维护。已有 Personal 文件已经讨论这个对象时，就把有用含义整合进去，不必因为它来自某个聊天工具的记忆文件夹而另留一份。其余日常语境也按本人的实际材料组织，使它们便于一起维护。

材料也可以留在已有的私有来源，由 Personal 文件引用。引用应说明这份记录贡献什么、当前模型可以从哪里读取，以及内容变化时应修改哪一处。这样能够一起管理材料，而不必复制每份原件。保留日期、来源与不确定性；旧观察搬到新位置，不等于已经核实为当前事实。凭据与敏感原件仍保留各自的访问边界。

如果某个宿主会把选定记忆注入对话，就把注入文本看作从维护中的材料选出的简要工作语境：保留足以帮助行动的含义，完整依据和适用条件仍可追到。在已授权的修订中，模型可以更新相应说明、调整选入内容，撤掉过时摘要或重复入口。改变来源后，要检查实际宿主能否检索或注入。保存文件、发布 Skill 与修改产品原生记忆是不同操作，不能互相代替，也不会自动启动个人资料收集服务。个人记忆及其引用仍属于私有材料。

## 理解偏好在环境中的扩展实现

考察偏好如何通过人、模型、工具和个人环境运作。环境可以参与构成要理解的选择能力，而不只是辨认内部偏好之前需要排除的噪声。模型参与的选择、采用的默认安排和后续修订，可以在本人尚未说清时显出一种模式。

比较实际备选、请求、实现、使用与纠正，用具体例子使模式可见，并说明解释为何合适。在同一实践内部辨认已经运作的选择、对它的解释与本人现在的认同：人可以辨认有用的安排、拒绝不想要的限制，也可以改变曾经有用的偏好。不要把一次孤立的模型错误等同于采用的方向，也不要假定系统的每一处细节都已得到本人认同。

Git/GitHub 保存已提交作品与沿革，Computer History 提供不同范围的使用证据。两者的联系支持可追溯的轨迹。重要的排除与旧解释保留在已有来源，不必让每个旧版本继续活跃。历史的祖先图不是优先关系，容纳不一致语义描述的基本判断也不是人的计算机制。[偏好一文](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/preference-harness.zh-CN.html)展开这些关系。

## 查清需要什么材料、已经有什么

从相连模型的实际用途开始检查已有材料：哪些分类有相关根据，哪些信息过时或不确定，哪些缺口会改变说明。材料齐备意味着足以支持这些判断，不是穷尽传记或建立一个永远完成的档案。

[修订方法](formation/revision.zh-CN.md#选择本次修订的侧重)负责选择每次更新的侧重。分类提供可用的根据，
不是每次全量刷新的清单：一类或几类可以成为重点，其他材料通过会改变判断的条件或后果
进入考察。问题或证据改变时，调整侧重，只维护受到影响的材料。

先检索已有记录，再向本人询问。必要的事实、经验或判断仍无法取得时，用聚焦的问题说明缺什么、会影响什么。本人提供来源后，就检查来源并更新缺口，不要像没有收到回答一样重复询问。继续不依赖答案的写作，保留依赖它的判断。缺少测量就保持未知，不因此自动安排新的心理测试。

身体测量保留日期与单位，方向写成意图而不是已发生的事实，测评结果保留工具、版本、场次与作答背景。尽量通过链接复用已有权威记录。凭据与敏感身份证件仍由其实际来源保管，基本档案只取用相关事实及来源入口。

## 通过相连内容视角指导原生融合

在维护的 YinYang 中，交叉参与与辩证返回仍是组织关系；偏好、心理材料和个人条件赋予它处境内容。

- **立场与方向**说明采用的价值、目的，以及想维持或重新考虑哪些偏好。
- **人**用相互区分又连接的段落，组织偏好模式、心理根据、能力与生活条件。
- **伙伴**说明模型的实际贡献，包括使模式可见并承担已授权的改变。
- **关系**说明生成、判断、纠正与偏好修订怎样在参与者之间发生。
- **环境**说明工具与条件如何实现选择，并塑造后续可能。
- **修订**说明新材料、比较、本人回应与实际使用怎样改变说明及其实现。

只在某类材料改变一个文件的对象时使用它，不写成六份重复清单。原始证据保有既有维护者，更充分的派生解释可以放在原生 Observations 或页面中。来源缺口限制相应主张；明确保留缺口优于补造材料。当当前目的需要解决它时，继续查到实际来源或取得本人回答，再判断完成。
