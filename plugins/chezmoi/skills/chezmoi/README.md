# chezmoi

Persist authorized stable configuration through source capture, isolated preview, protected publication and runtime readback.

[中文说明](README.zh-CN.md) · [Model instructions](SKILL.md)

For Skill resource changes, download **prompt-and-skill-lifecycle**. This package distributes the method; the recipient must provide a verified executable publication/convergence owner. The original full macos-publish service is not included.

Resolve the actual chezmoi source/destination and publication owner before choosing one of the three capture routes. Use isolated candidates first. Missing publication/mutex/runtime adapters remain a live-execution boundary, even when the method is downloaded.

Download the **complete directory** from this repository or GitHub's native archive, preserving scripts and executable modes. Relative resources and companion relationships are part of the package. There are no personal accounts, subscriptions, vault lists, credentials or host defaults to inherit. Configure your own real targets; a downloaded method is not proof of a configured runtime service.
